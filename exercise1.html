VehicleBASE CLASS

Attributes

+ total_built : int = 0
# _model : str
# _plate : str
# _serial : int

+ odometer : float = 0.0

Methods

+ __init__(model: str, plate: str)
Creates a vehicle, bumps the shared total_built counter and uses it as the serial number.
+ model : str property get / set
The getter returns the model wrapped in angle brackets, and the setter trims it and rejects an empty value.
+ plate : str property get / set
The getter returns the plate in parentheses, and the setter trims it and rejects an empty value.
+ summary(verbose: bool = False) : str
Returns a one-line text with the serial, model and plate, plus paint and odometer when verbose is True.
+ drive(km: float) : float
Adds the distance to the odometer and returns the new total, raising ValueError for a negative distance.
+ repaint(new_paint: str) : None
Replaces the vehicle's paint colour with the given one.
+ parse(line: str, sep: str = ";") : Vehicle @classmethod
Builds a new object of the calling class from text such as "Corolla;12-345-67" split on the separator.
+ __str__() : str
Returns the printable form "Vehicle <serial>, <model>, <plate>".

Attributes (added)

+ battery_kwh : float new
+ efficiency : float new
Kilometres driven per kWh.
+ charge_pct : float = 50.0 new
Current battery level, 0 to 100.

Methods

+ __init__(model: str, plate: str, battery_kwh: float, efficiency: float = 6.0, paint: str = "white") override
Calls the parent constructor, then stores the battery size, efficiency and paint, which the parent does not take.
+ summary(verbose: bool = False, unit: str = "km") : str override
Extends the parent's text with the battery level and the remaining range in the chosen unit ("km" or "mi").
+ drive(km: float, eco: bool = False) : float override
Drains the battery for the trip (15% less in eco mode) and then lets the parent update the odometer.
+ max_range() : float new
Returns how many kilometres the current charge can still cover.
+ plug_in(hours: float, kw: float = 7.4) : float new
Charges for the given time at the given power and returns the new battery percentage, capped at 100.
+ __str__() : str override
Prefixes the parent's text with "Electric" and appends the battery size and charge level.
