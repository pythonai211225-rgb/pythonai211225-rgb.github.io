Light switch — State pattern

LightSwitch holds a State object and passes every action to it; OnState, OffState and BrokenState decide what happens.

OnStateCONCRETE STATE
+ name : str overrideReturns "on".
+ light_on(switch: LightSwitch) : None overridePrints "Switch is already on..." and stays on.
+ light_off(switch: LightSwitch) : None overrideMoves the switch to OffState and prints "Switch On".
+ light_fix(switch: LightSwitch) : None overridePrints "Switch is already fixed!" and stays on.
OffStateCONCRETE STATE
+ name : str overrideReturns "off".
+ light_on(switch: LightSwitch) : None overrideMoves the switch to OnState and prints "Switch On".
+ light_off(switch: LightSwitch) : None overrideMoves the switch to BrokenState and prints "Switch is now broken".
+ light_fix(switch: LightSwitch) : None overridePrints "Switch is already fixed!" and stays off.
BrokenStateCONCRETE STATE
+ name : str overrideReturns "broken".
+ light_on(switch: LightSwitch) : None overridePrints "Switch already broken" and stays broken.
+ light_off(switch: LightSwitch) : None overridePrints "Switch already broken" and stays broken.
+ light_fix(switch: LightSwitch) : None overrideMoves the switch to OffState and prints "Switch fix, now off".
