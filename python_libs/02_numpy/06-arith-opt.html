Operation 01 / 09 · Arithmetic
np.subtract()
Element-wise difference — a minus b
a - b  /  np.subtract(a, b) a aThe first (left-hand) array or scalar. Each element of b is subtracted from the corresponding element of a. b bThe second (right-hand) array or scalar. Must match the shape of a, or be broadcast-compatible with it. element-wise → ndarray

Subtracts each element of b from the corresponding element of a. Both arrays must have the same shape — or compatible shapes for broadcasting. The operator a - b and np.subtract(a, b) produce identical results.

python
a = np.array([[1,2,3],[4,5,6]])
b = np.array([[1.5,2,3],[7,8,9]])
print(a - b)
# [[-0.5  0.   0. ]
#  [-3.  -3.  -3. ]]

Operation 02 / 09 · Arithmetic
np.add()
Element-wise sum — a plus b
b + a  /  np.add(b, a) b bThe first addend — an array or scalar. Order does not affect the sum for addition but may matter for broadcasting when shapes differ. a aThe second addend — added element-wise to b. Must be the same shape as b, or broadcast-compatible with it. element-wise → ndarray

Adds corresponding elements. Fully commutative — a + b == b + a. Supports broadcasting: adding a scalar or a 1D array to a 2D array works automatically, stretching the smaller shape to fit.

python
print(b + a)
# [[ 2.5  4.   6. ]
#  [11.  13.  15. ]]

# broadcast: add scalar to array
print(a + 10)  # [[11 12 13] [14 15 16]]

Operation 03 / 09 · Arithmetic
np.divide()
Element-wise division — always float output
a / b  /  np.divide(a, b) a aThe numerator array or scalar. Each element is divided by the corresponding element of b. b bThe denominator array or scalar. Division by zero produces inf — not an exception. Must be broadcast-compatible with a. element-wise → ndarray (float)

Divides each element of a by the corresponding element of b. Always returns float64 even if inputs are integers. Division by zero produces inf or nan — not an exception. Use // for integer (floor) division.

python
print(a / b)
# [[0.667 1.    1.   ]
#  [0.571 0.625 0.667]]

# floor division keeps integers
print(a // 2)   # [[0 1 1] [2 2 3]]

Operation 04 / 09 · Arithmetic
np.multiply()
Element-wise product — not matrix multiply!
a * b  /  np.multiply(a, b) a aFirst factor — array or scalar. Each element is multiplied by the corresponding element of b. This is element-wise, not matrix multiplication. b bSecond factor — array or scalar. Must match the shape of a or be broadcast-compatible. For matrix multiply use .dot(). element-wise (Hadamard) → ndarray

Multiplies corresponding elements — this is the Hadamard product, not matrix multiplication. Every element of a is scaled by the matching element of b. For true matrix multiplication use .dot() or the @ operator.

python
print(a * b)
# [[ 1.5  4.   9. ]
#  [28.  40.  54. ]]

# scale all elements by 3
print(a * 3)   # [[ 3  6  9] [12 15 18]]

Operation 05 / 09 · Math Function
np.exp()
e raised to every element — the growth engine
np.exp(x) x xInput array. Every element xi becomes e^xi where e ≈ 2.718. Works on scalars too. → ndarray (float)

Computes ex for each element. The exponential function explodes quickly — exp(10) ≈ 22026. It is the foundation of the softmax and sigmoid activations in neural networks and models compound growth.

python
np.exp(np.array([1, 2, 3]))
# [ 2.718  7.389 20.086]

# sigmoid activation
sigmoid = lambda x: 1 / (1 + np.exp(-x))

Operation 06 / 09 · Math Function
np.sqrt()
Square root of every element
np.sqrt(x) x xArray of non-negative values. Negative inputs return nan (not an error). Pass complex arrays to get complex square roots. → ndarray (float)

Returns √x for every element. Negative inputs silently produce nan with a warning. Used in distance calculations (Euclidean distance), normalisation, and signal processing. Equivalent to x ** 0.5.

python
np.sqrt(np.array([4, 9, 16, 25]))
# [2. 3. 4. 5.]

# Euclidean distance
d = np.sqrt(np.sum((a - b)**2))

Operation 07 / 09 · Math Function
np.sin() / np.cos()
Trig on every element — radians, not degrees
np.sin(x)  /  np.cos(x) x xAngles in radians — not degrees. Convert degrees first: np.sin(np.deg2rad(90)) gives 1.0. → ndarray in [-1, 1]

Computes sine or cosine for each element. Input must be in radians. Use np.deg2rad() to convert first. These are heavily used in signal processing, Fourier transforms, and generating smooth animation curves.

python
np.sin(np.array([0, np.pi/2, np.pi]))
# [0. 1. 0.]

x = np.linspace(0, 2*np.pi, 200)
y = np.sin(x)   # full sine wave

Operation 08 / 09 · Math Function
np.log()
Natural logarithm — the inverse of exp
np.log(x) x xArray of positive values. Zero gives -inf, negative values give nan. Use np.log2() or np.log10() for other bases. → ndarray (float)

Computes the natural logarithm (base e) of each element. The inverse of np.exp() — so np.log(np.exp(x)) == x. Widely used in information theory, cross-entropy loss, and probability calculations. Use np.log2() for bits.

python
np.log(np.array([1, np.e, np.e**2]))
# [0. 1. 2.]

np.log2(np.array([1, 2, 4, 8]))
# [0. 1. 2. 3.]

Operation 09 / 09 · Matrix Math
.dot()
True matrix multiplication — rows × columns
a.dot(b)  /  a @ b a aThe left matrix. Its column count must equal the row count of b. For 1D vectors, computes the inner (scalar) dot product. b bThe right matrix. Its row count must match the column count of a. The output shape is (a.rows, b.cols). matrix multiply → ndarray

Computes the dot product — each output cell is the sum of row × column element products. For 2D arrays this is standard matrix multiplication. The @ operator is the modern Python syntax for the same operation.

python
e = np.full((2,2), 7)
f = np.eye(2)
print(e.dot(f))
# [[7. 7.]
#  [7. 7.]]

# @ operator — same result
print(e @ f)
