Intro to NumPy

NumPy — Numerical Python — is the fundamental library for scientific computing in Python. Fast multi-dimensional arrays, math, statistics, linear algebra, and random numbers.

NumPy Numerical Python pip install import numpy as np
What is NumPy?

NumPy — Numerical Python

NumPy (short for Numerical Python) is a Python library that provides support for fast, efficient operations on large arrays and matrices of numbers. It is the foundation on which almost all scientific Python libraries are built — Pandas, Matplotlib, Scikit-learn all depend on NumPy internally.

Core concept: NumPy introduces the ndarray — an N-dimensional array object that stores numbers of the same type in a compact, efficient structure. Operations on NumPy arrays are written in C and are much faster than regular Python lists.
What NumPy is Used For

NumPy Use Cases

➕

Mathematical Operations

Add, subtract, multiply, divide arrays element-by-element. Apply math functions like sin(), cos(), sqrt(), log(), exp() to entire arrays at once.

📐

Linear Algebra

Matrix multiplication, dot products, determinants, matrix inverses, eigenvalues — all with np.linalg.

📊

Statistics

Mean, median, standard deviation, variance, correlation — np.mean(), np.std(), np.median().

🎲

Random Numbers

Generate random integers, floats, normal distributions, shuffles. Essential for simulations, machine learning, and testing.

🖼️

Image Processing

Images are just 2D (or 3D for color) arrays of pixel values. NumPy lets you load, slice, crop, and transform images directly as arrays.

⚡

Performance

NumPy operations are 10–100x faster than equivalent Python loops because they run optimized C code. Critical for large datasets.

Installing NumPy

How to Install NumPy with pip

pip is Python's built-in package manager — it downloads and installs libraries from the internet (PyPI — Python Package Index). If you installed Anaconda, NumPy is already included. But if you need to install it manually:

Terminal / Command Prompt 
# Install NumPy using pip
pip install numpy

# Or with a specific version
pip install numpy==1.26.0

# Upgrade to latest version
pip install --upgrade numpy
With Anaconda? You can also use conda install numpy from the Anaconda Prompt. Both pip and conda work, but if you use Anaconda, conda is recommended to keep package compatibility.
📦

pip vs conda

pip installs from PyPI (all Python packages). conda installs from Anaconda channels — includes non-Python dependencies. Use conda when on Anaconda.

✅

Verify Installation

Run import numpy as np; print(np.__version__) in Python or Jupyter. If you see a version number, NumPy is installed.

Importing NumPy

How to Import NumPy

Before using NumPy, you must import it at the top of your notebook or script. The standard convention is to import it with the alias np:

Python 
import numpy as np

# Now you can use all NumPy functions with np.
print(np.__version__)   # prints something like 1.26.4
Why as np? This creates an alias — instead of typing numpy.array() every time, you just type np.array(). It's the universal convention. Every Data Scientist on the planet uses import numpy as np.
Import Statement How You Call It Convention
import numpy numpy.array([1,2,3]) Works but verbose
import numpy as np np.array([1,2,3]) ✅ Standard — always use this
from numpy import * array([1,2,3]) ⚠️ Avoid — pollutes namespace
