Comparison 01 / 03 · Boolean Mask
a == b
Element-wise equality — a mask of True and False
a == b  /  np.equal(a, b) a aThe first array to compare. Each element is tested against the matching element of b. Must be broadcast-compatible with b. b bThe second array compared element-wise against a. Can also be a scalar to test every element of a at once. element-wise → bool ndarray

Compares each element of a with the matching element of b and returns a boolean array of the same shape. The result is a mask — use it directly to filter values: a[a == b] extracts only the matching elements.

python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([1, 5, 3])
print(a == b)      # [ True False  True]
print(a != b)      # [False  True False]

# use mask to filter
print(a[a == b])   # [1 3]

Comparison 02 / 03 · Scalar Filter
a < 2 / a > 2
Compare every element to a threshold
a < n  /  a > n  /  a <= n  /  a >= n a aThe array to filter. Every element is independently compared against the threshold n. The result is a boolean mask of the same shape. n nThe scalar threshold. NumPy broadcasts it against every element of a. Can also be another array for element-wise comparison. broadcasts scalar → bool ndarray

Compares every element against a single scalar and returns a boolean mask. This is the basis of boolean indexing — the single most powerful filtering technique in NumPy. Chain conditions with & and | for multiple filters.

python
a = np.array([1, 2, 3])
print(a < 2)          # [ True False False]
print(a >= 2)         # [False  True  True]

# filter values above threshold
vals = np.array([5, 12, 3, 8, 1])
print(vals[vals > 5])  # [12  8]

Comparison 03 / 03 · Array-Wise
np.array_equal()
Are two entire arrays identical?
np.array_equal(a1, a2) a1, a2 a1 / a2Two arrays to compare. Both shape and values must match for the result to be True. Works for any number of dimensions. → bool (single value)

Returns a single True or False — not an array. Both the shape and every value must match. Useful in tests and assertions. For approximate float comparison use np.allclose(a, b) instead.

python
np.array_equal(np.array([1,2]), np.array([1,2]))   # True
np.array_equal(np.array([1,2]), np.array([1,9]))   # False

# shape mismatch → False
np.array_equal(np.array([1,2]), np.array([[1,2]]))  # False

# floats — use allclose instead
np.allclose(np.array([0.1+0.2]), np.array([0.3]))   # True

Aggregation 04 / 12 · Sum
.sum()
Add everything up — or just one axis
array.sum(axis=None) axis axisWhich axis to reduce. None (default) sums all elements. axis=0 collapses rows (sum per column), axis=1 collapses columns (sum per row). → scalar or ndarray

Reduces all elements to a total. On a 2D array, axis=0 gives one sum per column (collapse rows), axis=1 gives one sum per row (collapse columns). Also available as np.sum(a).

python
a = np.array([1, 2, 3, 4])
print(a.sum())            # 10

b = np.array([[1,2,3],[4,5,6]])
print(b.sum(axis=0))      # [5 7 9]  — per column
print(b.sum(axis=1))      # [6 15]  — per row

Aggregation 05 / 12 · Extremes
.min() / .max()
Smallest and largest — flat or per axis
array.min(axis=None) / array.max(axis=None) axis axisNone finds the global min/max across the whole array. axis=0 finds the min/max of each column; axis=1 for each row. → scalar or ndarray

Returns the minimum or maximum value. On 2D arrays, use axis=0 to get the max/min for each column, or axis=1 for each row. Use .argmin() / .argmax() to get the index of the extreme value instead.

python
b = np.array([[1,5,3],[4,2,6]])
print(b.min())           # 1  — global
print(b.max(axis=0))    # [4 5 6]  — per column
print(b.min(axis=1))    # [1 2]  — per row
print(b.argmax())       # 5  — flat index of 6

Aggregation 06 / 12 · Index of Extreme
.argmin() / .argmax()
Not the value — the position of the extreme
array.argmin(axis=None) / array.argmax(axis=None) axis axisNone returns the flat index of the min/max across the whole array. axis=0 gives the row index of the extreme per column; axis=1 gives the column index per row. → int or ndarray

Returns the index of the minimum or maximum value — not the value itself. Pair with .min() / .max() to get both the value and its location. On 2D arrays, pass axis to get the position per row or column.

python
a = np.array([4, 1, 9, 2, 7])
print(a.argmin())     # 1  — index of 1
print(a.argmax())     # 2  — index of 9

b = np.array([[1,5,3],[4,2,6]])
print(b.argmax(axis=0))  # [1 0 1]  — row idx of max per col
print(b.argmax(axis=1))  # [1 2]    — col idx of max per row

Aggregation 07 / 12 · Cumulative
.cumsum()
Running total — each cell carries the history
array.cumsum(axis=None) axis axisNone flattens first then accumulates. axis=1 accumulates left-to-right along each row, keeping the original 2D shape. → ndarray (same shape)

Each output element is the sum of all previous elements up to that position. The output is the same shape as the input. Useful for building price curves, probability distributions, and rolling totals.

python
b = np.array([[1,2,3],[4,5,6]])
print(b.cumsum(axis=1))
# [[ 1  3  6]
#  [ 4  9 15]]

a = np.array([1, 2, 3, 4])
print(a.cumsum())   # [ 1  3  6 10]

Aggregation 08 / 12 · Average
.mean()
The centre of mass of your data
array.mean(axis=None) axis axisNone returns the mean of all elements. axis=0 returns the mean of each column; axis=1 returns the mean of each row. → float or ndarray

Returns the arithmetic mean — sum / count. Sensitive to outliers; a single large value can pull the mean far from the "typical" value. Compare with np.median() to spot skewed data.

python
a = np.arange(0, 10)
print(a.mean())   # 4.5

b = np.array([[1,2,3],[4,5,6]])
print(b.mean(axis=0))   # [2.5 3.5 4.5]
print(b.mean(axis=1))   # [2.  5. ]

Aggregation 09 / 12 · Middle Value
np.median()
The true middle — outlier-resistant
np.median(a, axis=None) a aThe input array. Values are sorted internally to find the middle. For even-length arrays, the median is the average of the two central values. axis axisAxis along which to compute the median. Default None flattens the array first. Pass 0 for column-wise, 1 for row-wise. → float or ndarray

The value at the exact middle after sorting. Half the values are above, half below. Unlike .mean(), a single giant outlier barely moves the median — making it the preferred measure for skewed data like salaries or house prices.

python
a = np.array([1, 3, 2, 5, 4])
print(np.median(a))    # 3.0

# outlier barely moves median
b = np.array([1, 3, 2, 5, 4, 1000])
print(np.median(b))    # 3.5
print(b.mean())        # 169.17  ← pulled far!

Aggregation 10 / 12 · Correlation
np.corrcoef()
How closely do two arrays move together?
np.corrcoef(x, y) x, y x / yTwo 1D arrays of the same length. Returns a 2×2 correlation matrix — the off-diagonal values are the Pearson correlation coefficient between x and y. → 2×2 ndarray

Returns a 2×2 matrix. The diagonal is always 1.0 (each array correlates perfectly with itself). The off-diagonal value is the Pearson r — ranging from -1 (perfectly inverse) to +1 (perfectly aligned).

python
x = np.array([1, 2, 3])
y = np.array([4, 5, 6])
print(np.corrcoef(x, y))
# [[1. 1.]
#  [1. 1.]]  ← r=1, perfectly correlated

# off-diagonal is the useful r value
r = np.corrcoef(x, y)[0, 1]

Aggregation 11 / 12 · Spread
np.std()
How widely scattered are your values?
np.std(a, axis=None, ddof=0) a aThe input array. Standard deviation is computed over its elements. Use axis to operate along a specific dimension instead of the whole array. axis axisAxis along which to compute. Default None flattens the array. Pass 0 for column std, 1 for row std. ddof ddofDegrees of freedom correction. Default 0 gives population std. Use ddof=1 for sample std (Bessel's correction) — needed for unbiased estimates from a sample. → float or ndarray

The standard deviation measures average distance from the mean. A small std means values cluster tightly; a large std means they spread far. It is the square root of variance: std = √var. Use ddof=1 when working with a sample, not the full population.

python
a = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(np.std(a))        # 2.0
print(np.std(a, ddof=1)) # 2.138  sample std
print(a.mean())         # 5.0

Aggregation 12 / 12 · Variance
np.var()
Spread squared — std without the root
np.var(a, axis=None, ddof=0) a aThe input array. Variance is computed over its elements. Use axis to operate along a specific dimension instead of the whole array. axis axisAxis along which to compute. Default None flattens the array. Pass 0 for column variance, 1 for row variance. ddof ddofSame as in np.std() — use ddof=1 for sample variance. Note: var = std², so the units of variance are the square of the original data units. → float or ndarray

Variance is standard deviation squared — the mean of squared deviations from the mean. Because the units are squared, it is harder to interpret directly than std, but it's additive across independent sources of variation, making it useful in statistics.

python
a = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(np.var(a))         # 4.0   — std² = 2²
print(np.std(a)**2)      # 4.0   — same thing
print(np.var(a, ddof=1)) # 4.571 — sample var

Combining · Join Arrays
np.concatenate()
Join any number of arrays along an existing axis
np.concatenate((a1, a2, ...), axis=0) sequences sequencesA tuple (or list) of arrays to join. All arrays must have the same shape except along the concatenation axis. axis axisaxis=0 (default) stacks along rows — adds more rows. axis=1 appends columns. axis=None flattens all arrays first, then joins. → ndarray

np.concatenate joins a sequence of arrays into one. The key rule: all arrays must agree in every dimension except the axis you're joining along. For 1-D arrays, axis=0 simply appends end-to-end. For 2-D arrays, axis=0 stacks rows, axis=1 appends columns.

python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(np.concatenate((a, b)))          # [1 2 3 4 5 6]

# ── 2-D: axis=0 stacks rows
m1 = np.array([[1, 2], [3, 4]])
m2 = np.array([[5, 6], [7, 8]])
print(np.concatenate((m1, m2), axis=0))
# [[1 2]
#  [3 4]
#  [5 6]
#  [7 8]]   shape: (4, 2)

# ── 2-D: axis=1 appends columns
print(np.concatenate((m1, m2), axis=1))
# [[1 2 5 6]
#  [3 4 7 8]]   shape: (2, 4)
