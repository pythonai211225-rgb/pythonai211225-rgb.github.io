Views & Copies 01 / 02 · Shared Memory
.view()
A window into the same memory — changes ripple back
h = a.view() dtype dtypeOptional. Reinterpret the raw bytes under a different data type. Omit (the common case) to get a view with the same dtype. Changes to the view affect the original array. shallow — linked → ndarray (same data)

A view shares the same underlying memory as the original. It looks like a copy but isn't. Writing to h[0] writes straight through to a[0]. This is NumPy's default for most slicing — fast and zero extra memory, but watch out for accidental mutations.

python
import numpy as np

a = np.arange(5)         # [0 1 2 3 4]
h = a.view()

h[0] = 99
print(a)  # [99  1  2  3  4]  ← original changed!
print(h)  # [99  1  2  3  4]

# check if arrays share memory
np.shares_memory(a, h)   # True

Views & Copies 02 / 02 · Deep Copy
np.copy() / .copy()
Fully independent — the original is safe
h = np.copy(a) h = a.copy() a aThe source array to copy. All data is duplicated into a new memory buffer, so changes to the copy never affect the original. order orderMemory layout of the copy: 'C' (row-major, default), 'F' (column-major), or 'K' (match source). Rarely needed in everyday use. deep — independent → new ndarray

np.copy(a) and a.copy() are identical — both allocate fresh memory and duplicate every value. Mutating the copy has zero effect on the original. Prefer .copy() style for clarity. Always copy before sorting or modifying if you need the original intact.

python
a = np.arange(5)         # [0 1 2 3 4]
h = a.copy()

h[0] = 99
print(a)  # [0 1 2 3 4]  ← original unchanged ✓
print(h)  # [99 1 2 3 4]

np.shares_memory(a, h)   # False

Sorting 01 / 02 · In-Place
.sort()
Sort the array in-place — no copy made
array.sort() kind kindSorting algorithm: 'quicksort' (default), 'mergesort', or 'heapsort'. Quicksort is fastest on average; mergesort is stable (preserves relative order of equal elements). in-place — modifies original → None (modifies arr)

Sorts the array in-place (ascending by default) and returns None. The original array is overwritten. To get a sorted copy without changing the original use np.sort(a) instead.

python
a = np.array([3,1,4,1,5,9,2,6])
a.sort()
print(a)   # [1 1 2 3 4 5 6 9]

# np.sort returns a NEW sorted copy
b = np.sort(a)    # original a is unchanged

Sorting 02 / 02 · 2D Sort
.sort(axis=0)
Sort each column or each row independently
array.sort(axis=0) axis axisaxis=0 sorts each column independently (values move up/down). axis=1 sorts each row independently (values move left/right). in-place

On a 2D array, axis determines the direction of sorting. axis=0 sorts down each column — rows are mixed up but columns become ascending. axis=1 sorts across each row independently. Rows/columns are never merged with each other.

python
c = np.array([[3,1,2],
              [9,4,7],
              [5,8,6]])

c.sort(axis=0)
# [[3 1 2]   ← each column sorted
#  [5 4 6]
#  [9 8 7]]

c.sort(axis=1)
# [[1 2 3]   ← each row sorted
#  [4 7 9]
#  [5 6 8]]

Indexing 01 / 07 · Element Access
a[i]
Grab a single element by its 0-based index
a[i] i i0-based integer index. Negative values count from the end: a[-1] is the last element, a[-2] second-to-last, etc. → scalar

NumPy uses zero-based indexing like Python lists. The first element is at index 0, the last at n-1. Negative indices wrap around from the end — a[-1] always gives the last element without needing to know the length.

python
a = np.array([1, 2, 3])
print(a[2])    # 3
print(a[-1])   # 3  (last element)
print(a[-2])   # 2  (second to last)

Indexing 02 / 07 · 2D Element
b[row, col]
Pinpoint a single cell in a 2D array
b[row, col] row rowRow index (0-based, top to bottom). Equivalent to choosing which sub-array in a list of lists. Supports negative indexing. col colColumn index (0-based, left to right). Combined with row, this uniquely identifies one element. Equivalent to b[row][col]. → scalar

Comma notation b[row, col] is faster and more readable than chained b[row][col] — it avoids creating an intermediate 1D array. Think of it as giving the coordinates on a grid: row = down, col = right.

python
b = np.array([[1.5,2,3],
              [4,5,6],
              [7,8,9]])
print(b[1, 2])  # 6   (row 1, col 2)
print(b[0, 0])  # 1.5 (top-left)
print(b[-1,-1]) # 9   (bottom-right)

Indexing 03 / 07 · Range Slice
a[0:2]
Select a contiguous range — end is excluded
a[start:stop] start startFirst index to include (inclusive). If omitted, defaults to 0 (the beginning). Supports negative values to count from the end. stop stopFirst index to exclude (exclusive). The slice goes up to but not including this index. If omitted, goes to the end of the array. → ndarray (view)

The stop index is exclusive — a[0:2] returns elements at indices 0 and 1, not 2. A slice returns a view (shared memory) unless you call .copy(). Omit either boundary to go to the beginning or end.

python
a = np.array([10,20,30,40,50,60])
print(a[0:2])   # [10 20]
print(a[2:])    # [30 40 50 60]  — to end
print(a[:3])    # [10 20 30]     — from start
print(a[1:4])   # [20 30 40]

Indexing 04 / 07 · 2D Slice
b[0:2, 1]
Select a row range at a fixed column
b[row_start:row_end, col] row_start:row_end row_start : row_endA slice along axis 0. Selects rows from row_start (inclusive) to row_end (exclusive). Omit either end to mean “from beginning” or “to end”. col colAn integer index along axis 1, selecting one specific column. Reduces the 2D slice to a 1D column vector. 2D slice → ndarray (view)

Combine row slicing with a fixed column (or vice versa). The comma separates the row selector from the column selector. Either can be a range or a single index. b[:, 1] gets the entire second column as a 1D array.

python
b = np.array([[1.5,2,3],[4,5,6],[7,8,9]])
print(b[0:2, 1])  # [2. 5.]   — rows 0-1, col 1
print(b[:, 1])    # [2. 5. 8.] — all rows, col 1
print(b[0:2, :])   # first 2 rows, all columns

Indexing 05 / 07 · Reverse
a[::-1]
Reverse the entire array in one line
a[::-1] step stepThe slice step value. -1 walks the array backwards one element at a time. Use -2 to skip every other element while reversing. step = -1 → ndarray (view)

The full slice syntax is a[start:stop:step]. A step of -1 means "go backwards", and omitting start/stop means "the whole array" — so a[::-1] returns a reversed view. Use a[::-2] to take every second element in reverse.

python
a = np.array([1, 2, 3, 4, 5])
print(a[::-1])   # [5 4 3 2 1]
print(a[::-2])   # [5 3 1]  — every 2nd, reversed
print(a[4::-1])  # [5 4 3 2 1]  — same

Indexing 06 / 07 · Boolean Mask
a[a < 2]
Filter elements by condition — boolean indexing
a[condition] condition conditionA boolean array the same shape as a. Elements where True are selected; False elements are discarded. Typically created by a comparison like a < 2. boolean mask → 1D ndarray (copy)

A boolean condition like a < 5 produces a True/False array of the same shape. Using that as an index returns only the elements where the condition is True. Unlike slicing, this returns a copy, not a view. Chain conditions with & (and) and | (or).

python
a = np.array([1, 2, 3, 4, 5])
print(a[a < 3])             # [1 2]
print(a[(a > 1) & (a < 5)]) # [2 3 4]
print(a[a % 2 == 0])        # [2 4]  — even only

Indexing 07 / 07 · Fancy Indexing
b[[r…],[c…]]
Pick any combination of elements by coordinate lists
b[[rows], [cols]] rows rowsA list (or array) of row indices to select. NumPy pairs each row index with the matching column index — it does not form a grid. cols colsA list (or array) of column indices paired with rows. Element i of the result is b[rows[i], cols[i]]. fancy — always a copy → 1D ndarray

Fancy indexing uses lists of indices instead of slices. Each pair (rows[i], cols[i]) picks one element. The result is always a flat 1D array. This can't be done with slices alone and is a copy, not a view.

python
b = np.array([[1.5,2,3],[4,5,6]])
# pick (row=1,col=0), (row=0,col=1), (row=1,col=2), (row=0,col=0)
print(b[[1,0,1,0], [0,1,2,0]])
# [4.  2.  6.  1.5]
