Quest 01 of 05
Weather Watch
A weather station recorded temperatures for 7 consecutive days. Use NumPy to extract insights from the data.
Easy 3 Stages ~3 min
Your Data
python
import numpy as np

# Daily temperatures (°C) — Monday to Sunday
temps = np.array([18.5, 22.3, 19.8, 25.1, 23.6, 17.2, 21.0])
STAGE 1Weekly Average
Find the average temperature across all 7 days. What was the typical temperature this week?
💡np.mean(temps)
avg = np.mean(temps)
21.071428571428573 # ≈ 21.07 °C
STAGE 2Peak Heat
Find the highest temperature recorded during the week. Which value is the peak?
💡np.max(temps)
peak = np.max(temps) day_idx = np.argmax(temps) # bonus: which day?
25.1 # Thursday (index 3)
STAGE 3Cold Snap
Find the coldest temperature of the week and also calculate the temperature range (max − min).
💡np.min(temps)  ·  np.max(temps) - np.min(temps)
cold = np.min(temps) spread = np.max(temps) - np.min(temps)
cold = 17.2 # Saturday (index 5) spread = 7.9 # 25.1 − 17.2
Quest 02 of 05
Shopping Cart
An online store has 5 items in a cart. Calculate the per-item totals, the grand total, and apply a loyalty discount.
Easy 3 Stages ~4 min
Your Data
python
import numpy as np

# Item prices (£) and quantities ordered
prices = np.array([12.99, 5.50, 8.75, 22.00, 3.25])
qty    = np.array([2,     5,    1,     3,     10   ])
STAGE 1Per-Item Totals
Multiply each item's price by its quantity to get the total cost per item. You should get a new array of 5 values.
💡np.multiply(prices, qty)  —  or simply: prices * qty
item_totals = np.multiply(prices, qty) # same as: prices * qty
array([25.98, 27.5 , 8.75, 66. , 32.5 ])
STAGE 2Grand Total
Sum up all the per-item totals from Stage 1 to get the grand total of the order.
💡np.sum(item_totals)
grand_total = np.sum(item_totals)
160.73
STAGE 3Loyalty Discount
Apply a 15% loyalty discount to the grand total. Multiply by 0.85 to keep 85% of the price. What is the final price?
💡grand_total * 0.85  —  broadcasting a scalar
discounted = grand_total * 0.85 # or: np.multiply(grand_total, 0.85)
136.6205 # £136.62 after 15% off
Quest 03 of 05
Race Podium
Seven athletes just finished a race and their scores have been recorded. Sort the results, crown the champion, and extract the podium.
Medium 3 Stages ~5 min
Your Data
python
import numpy as np

# Race scores — higher is better
scores  = np.array([342, 187, 456, 298, 511, 223, 399])
players = ['Alice', 'Bob', 'Carlos', 'Diana', 'Eve', 'Frank', 'Grace']
STAGE 1Sort the Scores
Sort the scores array in descending order (highest first). Tip: sort ascending first, then reverse with [::-1].
💡np.sort(scores)[::-1]  —  sort then reverse the slice
ranked = np.sort(scores)[::-1]
array([511, 456, 399, 342, 298, 223, 187])
STAGE 2Who Won?
Find the index of the highest score in the original array. Use this to look up the winner's name from the players list.
💡np.argmax(scores) → gives the index → use it to index players list
winner_idx = np.argmax(scores) # → 4 winner_name = players[winner_idx]
winner_idx = 4 winner_name = 'Eve' # score: 511
STAGE 3The Top-3 Podium
Using np.argsort(), get the indices that would sort the array, then use them to extract the names and scores of the top 3 players.
💡np.argsort(scores)[::-1][:3] → top-3 indices → index into players & scores
top3_idx = np.argsort(scores)[::-1][:3] top3_scores = scores[top3_idx] top3_names = [players[i] for i in top3_idx]
top3_idx = [4, 2, 6] top3_scores = [511, 456, 399] top3_names = ['Eve', 'Carlos', 'Grace']
Quest 04 of 05
Sensor Grid
A lab has 3 sensors, each recording 4 time readings stored flat in one array. Reshape, analyse per-sensor, and normalise the data.
Medium 4 Stages ~7 min
Your Data
python
import numpy as np

# 12 readings stored flat — 3 sensors × 4 time steps
readings = np.array([22, 18, 35, 29, 41, 37, 26, 31, 19, 44, 28, 33])
STAGE 1Reshape to a Grid
Transform the flat array into a 3×4 matrix — rows = sensors, columns = time steps. What is the resulting shape?
💡readings.reshape(3, 4)  →  .shape gives you (3, 4)
grid = readings.reshape(3, 4) print(grid.shape)
array([[22, 18, 35, 29], # Sensor A [41, 37, 26, 31], # Sensor B [19, 44, 28, 33]]) # Sensor C shape: (3, 4)
STAGE 2Per-Sensor Average
Calculate the average reading for each sensor (i.e. the mean of each row). You should get 3 values — one per sensor. Use the axis parameter.
💡np.mean(grid, axis=1)  —  axis=1 means "collapse columns, keep rows"
sensor_avg = np.mean(grid, axis=1)
array([26. , 33.75, 31. ]) # Sensor A: 26.0 Sensor B: 33.75 Sensor C: 31.0
STAGE 3Hottest Sensor
Using the per-sensor averages, find which sensor index has the highest average. Is it Sensor 0, 1, or 2?
💡np.argmax(sensor_avg) → returns the index of the max value
hottest = np.argmax(sensor_avg)
1 # Sensor B (index 1) with avg 33.75
STAGE 4Normalise
Normalise the entire flat readings array to the range [0, 1] using min-max normalisation: (x − min) / (max − min). Round to 2 decimal places.
💡(readings - np.min(readings)) / (np.max(readings) - np.min(readings))
norm = (readings - np.min(readings)) / (np.max(readings) - np.min(readings)) np.round(norm, 2)
array([0.12, 0. , 0.62, 0.38, 0.88, 0.73, 0.27, 0.46, 0. , 1. , 0.35, 0.54]) # min=18 maps to 0.0, max=44 maps to 1.0
Quest 05 of 05
Factory Analysis
A factory has 5 machines. Each machine logged its hourly output over 4 hours. Your job: inspect the data, rank performance, and flag the weakest machine.
Hard 5 Stages ~10 min
Your Data
python
import numpy as np

# Units produced per hour — rows = machines, cols = hours
output = np.array([
    [120, 135, 118, 142],   # Machine A
    [98,  102, 115, 88 ],   # Machine B
    [145, 151, 139, 158],   # Machine C
    [87,  94,  90,  96 ],   # Machine D
    [130, 128, 134, 141]    # Machine E
])
STAGE 1Inspect the Array
Inspect the array: what are its .shape, .ndim, .size, and .dtype? How many total readings are there?
💡output.shape  ·  output.ndim  ·  output.size  ·  output.dtype
output.shape # → (5, 4) output.ndim # → 2 output.size # → 20 output.dtype # → int64 (or int32)
shape: (5, 4) — 5 machines, 4 hours each ndim: 2 — a 2-D matrix size: 20 — 20 total readings dtype: int64
STAGE 2Average Output per Machine
Calculate each machine's average hourly output. You need one number per machine (one per row). Which axis do you collapse?
💡np.mean(output, axis=1) — collapse columns (axis=1), keep rows
machine_avg = np.mean(output, axis=1)
array([128.75, 100.75, 148.25, 91.75, 133.25]) # A B C D E
STAGE 3Worst Performer
Find the index and name of the worst performing machine — the one with the lowest average output. Machine names are: A, B, C, D, E.
💡np.argmin(machine_avg) → gives index → "ABCDE"[idx]
worst_idx = np.argmin(machine_avg) worst_name = "ABCDE"[worst_idx]
worst_idx = 3 worst_name = 'D' # avg 91.75 units/hr
STAGE 4Output Spread
Calculate the standard deviation per machine (how consistent is each one?). A low std = consistent machine. Which is the most consistent?
💡np.std(output, axis=1)  ·  np.argmin(std_vals)
machine_std = np.std(output, axis=1) most_consistent = np.argmin(machine_std)
std: A=9.40 B=9.78 C=7.03 D=3.77 E=4.97 most_consistent = 3 ('D') ← lowest spread # Ironically the worst avg is also the most consistent!
STAGE 5Above-Average Machines
Calculate the factory-wide average (all machines, all hours). Then create a boolean mask of which machines beat this overall average. How many machines are above average?
💡np.mean(output) → scalar · machine_avg > factory_avg → bool array · np.sum() counts Trues
factory_avg = np.mean(output) # overall mean above_avg = machine_avg > factory_avg # boolean mask count_above = np.sum(above_avg)
factory_avg = 120.5 above_avg = [True, False, True, False, True] count_above = 3 # machines A, C, E beat factory avg
