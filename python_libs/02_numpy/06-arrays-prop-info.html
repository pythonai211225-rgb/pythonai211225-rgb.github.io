Property 01 / 06 · Inspection
.shape
The skeleton — every array's dimension blueprint
array.shape read-only attribute → tuple of int

Returns a tuple describing the size of each axis. A 1D array of 5 elements gives (5,) — note the trailing comma. A 2D array of 3 rows × 4 columns gives (3, 4). Assign a new tuple to .shape to reshape in-place.

python
import numpy as np

b = np.array([(1.5,2,3),(4,5,6)])
print(b.shape)   # (2, 3)

a = np.zeros((3, 4, 2))
print(a.shape)   # (3, 4, 2)

v = np.array([1, 2, 3, 4, 5])
print(v.shape)   # (5,)

Property 02 / 06 · Inspection
len()
How many rows? The first axis only
len(array) array arrayThe ndarray to measure. len() only looks at the first dimension — equivalent to a.shape[0]. For a 2D matrix it returns the row count. → int

Python's built-in len() works on arrays but only counts the first axis. For a 1D array of 5 elements it returns 5. For a 3×4 matrix it returns 3 (rows). Use .size for the total element count across all axes.

python
a = np.array([1, 2, 3])
print(len(a))        # 3   — first (only) axis

b = np.zeros((4, 5))
print(len(b))        # 4   — row count only
print(b.shape[0])   # 4   — same thing
print(b.size)       # 20  — total elements

Property 03 / 06 · Inspection
.ndim
How many axes? 1D, 2D, or beyond
array.ndim read-only attribute → int

The number of axes (dimensions) in the array. A plain list becomes a 1D array (ndim=1). A list of lists is 2D (ndim=2). A list of lists of lists is 3D — useful in image stacks and video data. Equal to len(array.shape).

python
a1 = np.array([1, 2, 3])          # 1-D
a2 = np.zeros((2, 3))             # 2-D matrix
a3 = np.ones((2, 3, 4))           # 3-D tensor

print(a1.ndim)  # 1
print(a2.ndim)  # 2
print(a3.ndim)  # 3

Property 04 / 06 · Inspection
.size
Every single element — counted in full
array.size read-only attribute → int

The total number of elements across all dimensions. For a (2, 3) array that's 2 × 3 = 6. For a (3, 4, 2) array: 3 × 4 × 2 = 24. Equivalent to the product of all values in .shape.

python
b = np.ones((2, 3))
print(b.size)    # 6

c = np.zeros((3, 4, 2))
print(c.size)    # 24  (3 × 4 × 2)

# size == product of shape
import math
print(math.prod(c.shape))  # 24

Property 05 / 06 · Inspection
.dtype
What type lives in every cell?
array.dtype read-only attribute → dtype object

The data type stored in each element. NumPy infers it from the input — integers become int64, floats become float64. Use .dtype.name to get a plain string. Knowing the dtype matters for memory, precision, and interoperability with C/GPU code.

python
b = np.array([1.5, 2.0])
print(b.dtype)        # float64
print(b.dtype.name)   # 'float64'

i = np.array([1, 2, 3])
print(i.dtype)        # int64

flags = np.array([True, False, True])
print(flags.dtype)    # bool

Method 06 / 06 · Conversion
.astype()
Recast — same values, different type
array.astype(dtype, copy, casting) dtype dtypeThe target type to cast every element to. Can be a NumPy type like np.float32, a Python type like int, or a string like 'bool'. copy copyWhen True (default) a new array is always returned. Set to False to skip the copy if the type already matches — saves memory on large arrays. casting castingControls how strict the conversion is. 'unsafe' allows any cast; 'same_kind' (default) only allows casts within the same category (e.g. float→float). Raises an error on unsafe casts if stricter. → ndarray (new type)

Converts all elements to a new type and returns a new array (original is untouched). Floats cast to int are truncated — not rounded. Useful before passing arrays to APIs or saving memory with a smaller type like float32.

python
b = np.array([1.7, 2.9, 3.1])
print(b.astype(int))    # [1 2 3]  ← truncated!
print(b.astype(bool))   # [ True  True  True]

z = np.array([0, 1, 2.5])
print(z.astype(bool))   # [False  True  True]
