Missing Data & New Columns

Real data is messy — learn to detect and handle NaN values with dropna and fillna, and build new columns from existing ones with assign and direct assignment.

dropna fillna df.assign pd.qcut
Detect Missing Values

Finding NaN in a DataFrame

python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'name':   ['Alice', 'Bob', 'Carol', 'David'],
    'score':  [88, np.nan, 75, np.nan],
    'dept':   ['Eng', 'HR', None, 'Eng']
})

# check which cells are NaN
print(df.isnull())
#     name  score   dept
# 0  False  False  False
# 1  False   True  False
# 2  False  False   True
# 3  False   True  False

# count NaN per column
print(df.isnull().sum())
# name     0
# score    2
# dept     1
Drop Missing

df.dropna() — Remove Rows with NaN

python
# drop any row that has at least one NaN
print(df.dropna())
#     name  score dept
# 0  Alice   88.0  Eng

# drop only rows where a specific column is NaN
print(df.dropna(subset=['score']))
#     name  score   dept
# 0  Alice   88.0    Eng
# 2  Carol   75.0   None

# drop rows where ALL values are NaN (more lenient)
df.dropna(how='all')
Fill Missing

df.fillna() — Replace NaN with a Value

python
# fill all NaN with a constant
print(df.fillna(0))             # numeric NaN → 0
print(df.fillna('Unknown'))     # string NaN → 'Unknown'

# fill each column with a different value
df.fillna({'score': df['score'].mean(), 'dept': 'Unknown'})

# forward-fill: copy value from the previous row
df.ffill()

# backward-fill: copy value from the next row
df.bfill()
fillna vs interpolate: fillna(df['col'].mean()) replaces with the column mean. df['col'].interpolate() fills by linear interpolation between surrounding values — useful for time-series data.
New Columns

Adding New Columns

python
df = pd.DataFrame({
    'length': [10, 20, 15],
    'width':  [5,  8,  6 ],
    'depth':  [2,  3,  4 ]
})

# ── direct assignment ──
df['area']   = df.length * df.width
df['volume'] = df.length * df.width * df.depth
print(df)
#    length  width  depth  area  volume
# 0      10      5      2    50     100
# 1      20      8      3   160     480
# 2      15      6      4    90     360

# ── df.assign — returns new DataFrame, original unchanged ──
df2 = df.assign(
    area   = lambda d: d.length * d.width,
    volume = lambda d: d.length * d.width * d.depth,
    label  = lambda d: pd.Series(['small','large','medium'])
)
print(df2)
Binning Values

pd.qcut() — Bin into Quantile Buckets

python
scores = pd.Series([45, 60, 72, 80, 88, 91, 95, 99])

# pd.qcut — equal-frequency bins (same number of items per bin)
bins = pd.qcut(scores, q=4, labels=['D','C','B','A'])
print(bins)
# 0    D
# 1    D
# 2    C
# 3    C
# 4    B
# 5    B
# 6    A
# 7    A

# pd.cut — equal-width bins (same range per bin)
bins2 = pd.cut(scores, bins=4, labels=['D','C','B','A'])
print(bins2)
qcut vs cut: pd.qcut(q=4) puts the same number of observations into each quartile. pd.cut(bins=4) divides the value range into equal-width intervals — fewer items may fall in sparse regions.
Exercises

Practice — Missing Data & New Columns

Q1

Create the DataFrame below and fill the NaN in temperature with the column mean. Fill the NaN in city with 'Unknown'.

df = pd.DataFrame({
    'city':        ['Paris', None, 'Rome', 'Berlin'],
    'temperature': [18.0, 22.0, np.nan, 15.0]
})
Show answer 
df['temperature'] = df['temperature'].fillna(df['temperature'].mean())
df['city']        = df['city'].fillna('Unknown')
print(df)
#       city  temperature
# 0    Paris         18.0
# 1  Unknown         22.0
# 2     Rome         18.3  ← mean of 18, 22, 15
# 3   Berlin         15.0
Q2

Add a new column revenue = price * qty and a column discount_price = price * 0.9 using df.assign().

df = pd.DataFrame({'product':['A','B','C'], 'price':[10,25,8], 'qty':[5,2,10]})
Show answer 
df2 = df.assign(
    revenue       = lambda d: d.price * d.qty,
    discount_price = lambda d: d.price * 0.9
)
print(df2)
#   product  price  qty  revenue  discount_price
# 0       A     10    5       50             9.0
# 1       B     25    2       50            22.5
# 2       C      8   10       80             7.2
Q3

Use pd.qcut to assign each score into one of 3 equal-frequency tiers: 'low', 'mid', 'high'. Add it as a new column tier.

df = pd.DataFrame({'student':['A','B','C','D','E','F'], 'score':[55,65,70,80,88,95]})
Show answer 
df['tier'] = pd.qcut(df['score'], q=3, labels=['low','mid','high'])
print(df)
#   student  score  tier
# 0       A     55   low
# 1       B     65   low
# 2       C     70   mid
# 3       D     80   mid
# 4       E     88  high
# 5       F     95  high
