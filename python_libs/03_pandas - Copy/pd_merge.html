Merge command patterns

    
The commands you will use most

    

      

        
Basic merge

        
Use when both DataFrames share the same key column name.

        
pd.merge(left, right, on="id", how="inner")

      

      

        
Different key names

        
Use when the key columns mean the same thing but have different names.

        
pd.merge(
    orders,
    customers,
    left_on="customer_id",
    right_on="id",
    how="left"
)

      

      

        
Keep source labels

        
indicator=True adds _merge: both, left_only, or right_only.

        
pd.merge(a, b, on="id", how="outer", indicator=True)

      

      

        
Handle duplicate column names

        
If both tables have a non-key column with the same name, use suffixes.

        
pd.merge(
    orders,
    customers,
    on="customer_id",
    suffixes=("_order", "_customer")
)

      

      

        
Validate relationships

        
Catch accidental many-to-many merges before they multiply your rows.

        
pd.merge(
    orders,
    customers,
    on="customer_id",
    validate="many_to_one"
)

      

      

        
Index merge

        
Join using row indexes instead of ordinary columns.

        
pd.merge(left, right, left_index=True, right_index=True)

      

    

  


  

    
Join type examples

    
What each how= value means

    

      

        
inner

        
Return only keys that appear in both DataFrames. This is the default.

        
pd.merge(orders, customers, on="customer_id")

      

      

        
left

        
Keep every row from the left DataFrame, and fill missing right-side values with NaN.

        
pd.merge(orders, customers, on="customer_id", how="left")

      

      

        
right

        
Keep every row from the right DataFrame, and fill missing left-side values with NaN.

        
pd.merge(orders, customers, on="customer_id", how="right")

      

      

        
outer

        
Keep all keys from both DataFrames. Missing values appear wherever one side has no match.

        
pd.merge(orders, customers, on="customer_id", how="outer")

      

    

    

      Important: duplicates multiply rows. If a key appears 2 times on the left and
      3 times on the right, the merge creates 6 combined rows for that key. Use
      validate= when you expect one-to-one or many-to-one behavior.
