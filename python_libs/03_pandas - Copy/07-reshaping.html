Reshaping Data

Transform the layout of a DataFrame: melt wide tables into long form, pivot long tables into wide form, stack DataFrames with concat, and clean up with sort, rename, and drop.

pd.melt df.pivot pd.concat sort / rename / drop
Wide → Long

pd.melt() — Gather Columns into Rows

Useful when you have one column per measurement but need a single variable column and a single value column (tidy data format).

python
import pandas as pd

wide = pd.DataFrame({
    'name':  ['Alice', 'Bob'],
    'math':  [88, 92],
    'english': [76, 84]
})
print(wide)
#     name  math  english
# 0  Alice    88       76
# 1    Bob    92       84

long = pd.melt(wide,
              id_vars='name',          # column(s) to keep as-is
              var_name='subject',      # name for the new variable col
              value_name='score')      # name for the new value col
print(long)
#     name  subject  score
# 0  Alice     math     88
# 1    Bob     math     92
# 2  Alice  english     76
# 3    Bob  english     84
Long → Wide

df.pivot() — Spread Rows into Columns

The opposite of melt — takes a "long" table and spreads one column's unique values into separate columns.

python
# using the 'long' DataFrame from above
wide2 = long.pivot(index='name',
                   columns='subject',
                   values='score')
print(wide2)
# subject  english  math
# name
# Alice         76    88
# Bob           84    92

# clean up the column axis name
wide2.columns.name = None
wide2 = wide2.reset_index()   # move 'name' back to a regular column
pivot vs pivot_table: df.pivot() requires unique row/column combinations. If you have duplicates (e.g. multiple rows for the same person+subject), use df.pivot_table(aggfunc='mean') to aggregate them.
Stacking DataFrames

pd.concat() — Append Rows or Columns

python
df1 = pd.DataFrame({'name':['Alice','Bob'],   'score':[88,92]})
df2 = pd.DataFrame({'name':['Carol','David'], 'score':[75,61]})

# ── axis=0: stack rows (default) ──
combined = pd.concat([df1, df2], ignore_index=True)
print(combined)
#     name  score
# 0  Alice     88
# 1    Bob     92
# 2  Carol     75
# 3  David     61

# ── axis=1: add columns side-by-side ──
extra = pd.DataFrame({'grade':['B','A'], 'age':[22,25]})
df_wide = pd.concat([df1, extra], axis=1)
print(df_wide)
#     name  score grade  age
# 0  Alice     88     B   22
# 1    Bob     92     A   25
Sort, Rename & Drop

Cleaning Up the Layout

python
df = pd.DataFrame({
    'name':['Carol','Alice','Bob'],
    'score':[75,88,92],
    'dept':['HR','Eng','Eng']
})

# sort ascending (default)
print(df.sort_values('score'))

# sort descending
print(df.sort_values('score', ascending=False))

# sort by multiple columns
print(df.sort_values(['dept', 'score'], ascending=[True, False]))

# rename columns
df2 = df.rename(columns={'score': 'points', 'dept': 'department'})
print(df2.columns.tolist())  # ['name', 'points', 'department']

# drop columns
df3 = df.drop(columns=['dept'])
print(df3)

# reset_index — turn index into a regular column
df_sorted = df.sort_values('score').reset_index(drop=True)
print(df_sorted)  # clean 0-based index after sorting
