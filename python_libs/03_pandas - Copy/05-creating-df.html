Creating DataFrames

Every pandas workflow starts by getting data into a DataFrame. You can build one from a Python dict, a list of lists, a CSV file, or even a MultiIndex structure.

pd.DataFrame pd.Series read_csv MultiIndex
Method 1 — From dict

Specify Values per Column

Pass a Python dictionary where each key is a column name and each value is a list. All lists must have the same length.

python
import pandas as pd

df = pd.DataFrame({
    "name":   ["Alice", "Bob", "Carol"],
    "score":  [88, 92, 75],
    "passed": [True, True, False]
}, index=[1, 2, 3])

print(df)
#     name  score  passed
# 1  Alice     88    True
# 2    Bob     92    True
# 3  Carol     75   False

print(df.dtypes)
# name      object
# score      int64
# passed      bool
Method 2 — From list of lists

Specify Values per Row

Pass a list of rows. Each inner list is one row. Specify column names separately with the columns parameter.

python
df = pd.DataFrame(
    [["Alice", 88, True],
     ["Bob",   92, True],
     ["Carol", 75, False]],
    columns=["name", "score", "passed"],
    index=[1, 2, 3]
)
print(df)
#     name  score  passed
# 1  Alice     88    True
# 2    Bob     92    True
# 3  Carol     75   False
Dict vs List of lists: Dict is more readable when you know column names upfront. List of lists is handy when you have rows coming from an API or a loop.
Method 3 — From CSV

Read from a CSV File

The most common way to load data. Download the sample CSV below, then read it with pd.read_csv().

python
# ── Option A: read from file ──
df = pd.read_csv("students.csv")

# ── Option B: create the same data inline (no file needed) ──
import io
csv_data = """name,score,grade
Alice,88,B
Bob,92,A
Carol,75,C
David,61,D
Eve,95,A"""
df = pd.read_csv(io.StringIO(csv_data))
print(df)
#     name  score grade
# 0  Alice     88     B
# 1    Bob     92     A
# 2  Carol     75     C
# 3  David     61     D
# 4    Eve     95     A

print(df.shape)    # (5, 3)  — 5 rows, 3 columns
print(df.dtypes)   # name object, score int64, grade object
Method 4 — MultiIndex

DataFrame with a MultiIndex

A MultiIndex lets you have hierarchical row labels — useful for panel data (data across time and categories).

python
idx = pd.MultiIndex.from_tuples(
    [('Math', 2023), ('Math', 2024),
     ('Science', 2023), ('Science', 2024)],
    names=['subject', 'year']
)
df = pd.DataFrame(
    {'avg_score': [82, 85, 78, 81],
     'students':  [30, 32, 28, 31]},
    index=idx
)
print(df)
#                  avg_score  students
# subject year
# Math    2023        82        30
#         2024        85        32
# Science 2023        78        28
#         2024        81        31

# Access by outer and inner index level
print(df.loc['Math'])   # all Math rows
Inspect a DataFrame

Quick Inspection Commands

python
df.head(3)          # first 3 rows
df.tail(3)          # last 3 rows
df.shape            # (rows, cols) tuple
df.dtypes           # dtype of each column
df.info()           # concise summary (non-null count + dtypes)
df.describe()       # stats: count, mean, std, min, max…
len(df)             # number of rows
df.columns.tolist() # list of column names
