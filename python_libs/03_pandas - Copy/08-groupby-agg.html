GroupBy & Aggregation

Split a DataFrame into groups by one or more columns, then apply an aggregation function — sum, mean, count, std, or a custom lambda — to each group independently.

groupby() agg() sum / mean / count size()
Sample Data

The DataFrame Used in All Examples

python
import pandas as pd

df = pd.DataFrame({
    'dept':   ['Eng','Eng','HR','HR','Eng','HR'],
    'name':   ['Alice','Bob','Carol','David','Eve','Frank'],
    'salary': [90000,85000,60000,65000,95000,62000],
    'years':  [5,3,7,2,6,4]
})
Basic GroupBy

df.groupby() — Split, Apply, Combine

python
# mean salary per department
print(df.groupby('dept')['salary'].mean())
# dept
# Eng    90000.0
# HR     62333.3

# sum, min, max, count, std
df.groupby('dept')['salary'].sum()
df.groupby('dept')['salary'].min()
df.groupby('dept')['salary'].max()
df.groupby('dept')['salary'].count()
df.groupby('dept')['salary'].std()
df.groupby('dept')['salary'].median()

# size() — number of rows per group
print(df.groupby('dept').size())
# dept
# Eng    3
# HR     3
Multiple Columns

Group by Multiple Columns + Multi-Column Stats

python
df2 = pd.DataFrame({
    'dept':  ['Eng','Eng','HR','HR'],
    'level': ['Senior','Junior','Senior','Junior'],
    'salary':[95000,70000,70000,50000]
})

# group by two columns
print(df2.groupby(['dept','level'])['salary'].mean())
# dept  level
# Eng   Junior    70000.0
#       Senior    95000.0
# HR    Junior    50000.0
#       Senior    70000.0

# stats on all numeric columns at once
print(df.groupby('dept')[[ 'salary', 'years']].mean())
agg()

Multiple Aggregations at Once with agg()

python
# same function for all selected columns
df.groupby('dept')[[ 'salary','years']].agg(['mean','min','max'])

# different function per column
result = df.groupby('dept').agg({
    'salary': ['mean', 'max'],
    'years':  'sum'
})
print(result)
#        salary              years
#          mean    max         sum
# dept
# Eng   90000.0  95000          14
# HR    62333.3  65000          13

# custom function with lambda
df.groupby('dept')['salary'].agg(lambda x: x.max() - x.min())
# dept
# Eng    10000
# HR      5000
Named aggregations (pandas ≥ 1.1): Use agg(new_col=('source_col', 'func')) to get clean output column names instead of a MultiIndex. 
df.groupby('dept').agg(
    avg_salary=('salary', 'mean'),
    max_salary=('salary', 'max'),
    total_years=('years', 'sum')
)

Q2

How many employees are in each department? Use .size() and also .count() — what is the difference?

Show answer 
print(df.groupby('dept').size())     # total rows per group (incl. NaN)
print(df.groupby('dept').count())    # non-NaN values per column per group
# size() returns a Series; count() returns a DataFrame
# size() includes NaN rows; count() excludes them
