Combining Data Sets

Join two DataFrames on a shared key with pd.merge(). Choose left, right, inner or outer join depending on which rows you want to keep. Also: filtering joins with isin and set-like operations.

pd.merge() inner / outer left / right isin
Sample Data

Two DataFrames Used in All Examples

python
import pandas as pd

employees = pd.DataFrame({
    'id':   [1, 2, 3, 4],
    'name': ['Alice', 'Bob', 'Carol', 'David'],
    'dept_id': [10, 10, 20, 30]  # David's dept 30 has no match
})

departments = pd.DataFrame({
    'dept_id': [10, 20, 40],  # dept 40 has no employees
    'dept_name': ['Engineering', 'HR', 'Marketing']
})
Standard Joins

The Four Types of Merge

Inner Join (default)

Keep only rows with a match in both DataFrames. David (dept 30) and Marketing (dept 40) are dropped.

Left Join

Keep all rows from the left DataFrame. David gets NaN for dept_name. Marketing is dropped.

Right Join

Keep all rows from the right DataFrame. Marketing gets NaN for employee columns. David is dropped.

Outer Join

Keep all rows from both DataFrames. Unmatched rows get NaN on the missing side.

python
# inner join — only matching rows
inner = pd.merge(employees, departments, how='inner', on='dept_id')
print(inner)
#    id   name  dept_id    dept_name
# 0   1  Alice       10  Engineering
# 1   2    Bob       10  Engineering
# 2   3  Carol       20           HR

# left join — all employees, NaN if no dept match
left = pd.merge(employees, departments, how='left', on='dept_id')
print(left)
#    id   name  dept_id    dept_name
# 0   1  Alice       10  Engineering
# 1   2    Bob       10  Engineering
# 2   3  Carol       20           HR
# 3   4  David       30          NaN  ← no dept match

# right join — all departments, NaN if no employee match
right = pd.merge(employees, departments, how='right', on='dept_id')

# outer join — everything, NaN where no match
outer = pd.merge(employees, departments, how='outer', on='dept_id')
print(outer)
#     id   name  dept_id    dept_name
# 0  1.0  Alice       10  Engineering
# 1  2.0    Bob       10  Engineering
# 2  3.0  Carol       20           HR
# 3  4.0  David       30          NaN
# 4  NaN    NaN       40    Marketing
Filtering Joins

isin() — Keep or Exclude Based on Another DataFrame

python
valid_depts = pd.DataFrame({'dept_id': [10, 20]})

# keep only employees whose dept_id is in valid_depts
matched = employees[employees.dept_id.isin(valid_depts.dept_id)]
print(matched)
#    id   name  dept_id
# 0   1  Alice       10
# 1   2    Bob       10
# 2   3  Carol       20

# keep only employees whose dept_id is NOT in valid_depts (~ = NOT)
unmatched = employees[~employees.dept_id.isin(valid_depts.dept_id)]
print(unmatched)
#    id   name  dept_id
# 3   4  David       30
Set-like Operations

Intersection, Union, Set Difference

python
ydf = pd.DataFrame({'x1':['A','B','C'], 'x2':[1,2,3]})
zdf = pd.DataFrame({'x1':['B','C','D'], 'x2':[2,3,4]})

# intersection — rows in BOTH
print(pd.merge(ydf, zdf))
#   x1  x2
# 0  B   2
# 1  C   3

# union — rows in EITHER or both
print(pd.merge(ydf, zdf, how='outer'))

# set difference — rows in ydf but NOT in zdf
diff = (pd.merge(ydf, zdf, how='outer', indicator=True)
          .query('_merge == "left_only"')
          .drop(columns=['_merge']))
print(diff)
#   x1  x2
# 0  A   1
