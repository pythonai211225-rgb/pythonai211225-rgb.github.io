Creating DataFrames

Creating DataFrames

Specify values per column (dict)
python
df = pd.DataFrame({
    "a": [4, 5, 6],
    "b": [7, 8, 9],
    "c": [10, 11, 12]},
    index=[1, 2, 3])
Specify values per row (list of lists)
python
df = pd.DataFrame(
    [[4, 7, 10],
     [5, 8, 11],
     [6, 9, 12]],
    index=[1,2,3], columns=['a','b','c'])
MultiIndex DataFrame
python
df = pd.DataFrame(
    {"a":[4,5,6], "b":[7,8,9]},
    index=pd.MultiIndex.from_tuples(
        [('d',1),('d',2),('e',2)],
        names=['n','v']))
Reshaping Data

Reshape, Sort & Rename

Reshape functions
pd.melt(df)Gather columns into rows (wide → long)
df.pivot(columns='var', values='val')Spread rows into columns (long → wide)
pd.concat([df1, df2])Append rows of DataFrames
pd.concat([df1, df2], axis=1)Append columns of DataFrames
Sort, Rename & Clean
df.sort_values('col')Order rows by column values (low → high)
df.sort_values('col', ascending=False)Order rows by column values (high → low)
df.rename(columns={'y':'year'})Rename columns
df.sort_index()Sort by the DataFrame index
df.reset_index()Reset index to row numbers, moving old index to a column
df.drop(columns=['A', 'B'])Drop columns from the DataFrame
Subsetting Data

Subset Rows, Columns & Both

Subset Rows
df[df.Length > 7]Rows meeting a logical condition
df.drop_duplicates()Remove duplicate rows
df.sample(frac=0.5)Randomly select 50% of rows
df.sample(n=10)Randomly select 10 rows
df.nlargest(n, 'col')Top n rows by column value
df.nsmallest(n, 'col')Bottom n rows by column value
df.head(n)First n rows
df.tail(n)Last n rows
Subset Columns
df[['w', 'l', 's']]Select multiple named columns
df['width'] or df.widthSelect single column (returns Series)
df.filter(regex='regex')Columns whose name matches a regex
Rows & Columns
df.iloc[10:20]Rows by position 10–19
df.iloc[:, [1,2,5]]Columns at positions 1, 2, 5
df.loc[:, 'x2':'x4']All columns between x2 and x4
df.loc[df['a']>10, ['a','c']]Rows meeting condition, specific columns
df.iat[1, 2]Single value by row/col position
df.at[4, 'A']Single value by row/col label
Logic & Query

Boolean Logic & Query Syntax

Logic operators in pandas
<Less than
>Greater than
==Equal to
!=Not equal to
&, |, ~And, or, not (use instead of and/or)
df.col.isin(values)Group membership
pd.isnull(obj)Is NaN
pd.notnull(obj)Is not NaN
query() — cleaner filters
python
df.query('Length > 7')
df.query('Length > 7 and Width < 8')
df.query('Name.str.startswith("abc")',
         engine="python")
Method Chaining
python
df = (pd.melt(df)
     .rename(columns={
         'variable':'var',
         'value':'val'})
     .query('val >= 200')
     )
