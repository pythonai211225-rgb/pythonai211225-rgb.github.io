Index & Access

The Index — Accessing Values

Every Series has an index. Access values by label with [] or .loc[], or by integer position with .iloc[].

python
s = pd.Series({'math':88, 'english':76, 'science':92, 'history':81})
python
# access by label
print(s['math'])          # → 88
print(s.loc['english'])   # → 76

# access by integer position
print(s.iloc[0])           # → 88  (first element)
print(s.iloc[-1])          # → 81  (last element)

Label vs position: When the index is integers (default), s[0] accesses by label, not position. To be explicit and safe, always use .loc[] for labels and .iloc[] for positions.

Practice — Series

Q1

Create a Series of monthly temperatures (use any 6 values you like) with a custom string index ['Jan','Feb','Mar','Apr','May','Jun']. Print the dtype, the max temperature, and the name of the month with the highest temperature.

Show answer 
temps = pd.Series(
    [7, 9, 14, 18, 23, 28],
    index=['Jan','Feb','Mar','Apr','May','Jun'],
    name='temp_c'
)
print(temps.dtype)         # int64
print(temps.max())         # 28
print(temps.idxmax())      # Jun  ← label of max value
Q2

Given the two Series below, compute their element-wise sum. Then use .add(fill_value=0) to handle the fact that their indices only partially overlap.

a = pd.Series({'x':10, 'y':20, 'z':30})
b = pd.Series({'y':5,  'z':10, 'w':15})
Show answer 
print(a + b)    # w NaN / x NaN / y 25 / z 40  â† NaN for unmatched
print(a + b)    # w NaN / x NaN / y 25 / z 40  ← NaN for unmatched
print(a.add(b, fill_value=0))
# w    15.0   ← b['w'] + 0
# x    10.0   ← a['x'] + 0
# y    25.0
# z    40.0
Q3

The Series below contains product prices as strings. Convert it to float using astype. Then apply a 10% discount and round to 2 decimal places.

prices = pd.Series(['12.50', '8.99', '25.00', '4.75'])
Show answer 
prices_f = prices.astype(float)
discounted = (prices_f * 0.9).round(2)

# 0    11.25
# 1     8.09
# 2    22.50
# 3     4.27
