Reshaping Data

Transform the layout of a DataFrame: melt wide tables into long form, pivot long tables into wide form, stack DataFrames with concat, and clean up with sort, rename, and drop.

pd.melt df.pivot pd.concat sort / rename / drop
Wide → Long

pd.melt() — Gather Columns into Rows

Useful when you have one column per measurement but need a single variable column and a single value column (tidy data format).

python
import pandas as pd

wide = pd.DataFrame({
    'name':  ['Alice', 'Bob'],
    'math':  [88, 92],
    'english': [76, 84]
})
wide

1Bob9284
python
long = pd.melt(wide,
               # column(s) to keep as-is
              id_vars='name',
              # name for the new variable col
              var_name='subject',
              # name for the new value col
              value_name='score')

Long → Wide

df.pivot() — Spread Rows into Columns

The opposite of melt — takes a "long" table and spreads one column's unique values into separate columns while keeping important identifier columns.

python
long = pd.DataFrame({
    'student': ['Alice', 'Alice', 'Alice', 'Bob', 'Bob', 'Bob',
                'Alice', 'Alice', 'Alice', 'Bob', 'Bob', 'Bob'],
    'term': ['Fall', 'Fall', 'Fall', 'Fall', 'Fall', 'Fall',
             'Spring', 'Spring', 'Spring', 'Spring', 'Spring', 'Spring'],
    'subject': ['math', 'english', 'science'] * 4,
    'score': [88, 76, 91, 92, 84, 79,
              90, 81, 94, 87, 89, 83]
})

pivot vs pivot_table: df.pivot() requires unique row/column combinations. If you have duplicates (e.g. multiple rows for the same person+subject), use df.pivot_table(aggfunc='mean') to aggregate them.

Exercises

Practice — Reshaping

Q1

Create this wide DataFrame and melt it so each row represents one student + one subject + one score:

df = pd.DataFrame({'student':['Ana','Leo'], 'physics':[80,70], 'chemistry':[90,85]})
Show answer 
long = pd.melt(df, id_vars='student', var_name='subject', value_name='score')
print(long)
#   student    subject  score
# 0     Ana    physics     80
# 1     Leo    physics     70
# 2     Ana  chemistry     90
# 3     Leo  chemistry     85
Q2

Concatenate the two DataFrames below into one (stacking rows), and reset the index.

a = pd.DataFrame({'x':[1,2], 'y':['a','b']})
b = pd.DataFrame({'x':[3,4], 'y':['c','d']})
Show answer 
result = pd.concat([a, b], ignore_index=True)
print(result)
#    x  y
# 0  1  a
# 1  2  b
# 2  3  c
# 3  4  d
Q3

Sort the DataFrame below by dept ascending then salary descending. Rename salary to pay. Drop the id column.

df = pd.DataFrame({'id':[1,2,3,4], 'dept':['Eng','HR','Eng','HR'], 'salary':[90000,60000,85000,65000]})
Show answer 
result = (df
    .sort_values(['dept','salary'], ascending=[True,False])
    .rename(columns={'salary':'pay'})
    .drop(columns=['id'])
    .reset_index(drop=True)
)
print(result)
