GroupBy & Aggregation

Split a DataFrame into groups by one or more columns, then apply an aggregation function — sum, mean, count, std, or a custom lambda — to each group independently.

groupby() agg() sum / mean / count size()

Exercises

Practice — GroupBy & Aggregation

Q1

Using the sample DataFrame (df at the top), compute the total salary and average years per dept.

Show answer 
result = df.groupby('dept').agg(
    total_salary=('salary', 'sum'),
    avg_years=('years', 'mean')
)
print(result)
#       total_salary  avg_years
# dept
# Eng         270000        4.67
# HR          187000        4.33
Q2

How many employees are in each department? Use .size() and also .count() — what is the difference?

Show answer 
print(df.groupby('dept').size())     # total rows per group (incl. NaN)
print(df.groupby('dept').count())    # non-NaN values per column per group
# size() returns a Series; count() returns a DataFrame
# size() includes NaN rows; count() excludes them
Q3

Compute the salary range (max − min) per department using a lambda inside agg().

Show answer 
result = df.groupby('dept')['salary'].agg(lambda x: x.max() - x.min())
print(result)
# dept
# Eng    10000
# HR      5000
