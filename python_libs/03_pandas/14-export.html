Export / I/O

Pandas can read and write many file formats. Each format has trade-offs between human readability, file size, and speed.

to_csv / read_csv to_excel to_json to_parquet
CSV

to_csv() and read_csv()

python
import pandas as pd

df = pd.DataFrame({
    'name':   ['Alice', 'Bob', 'Carol'],
    'dept':   ['Eng', 'HR', 'Eng'],
    'salary': [75000, 52000, 81000]
})

# write — index=False omits the row numbers
df.to_csv('employees.csv', index=False)

python
# useful read_csv options
pd.read_csv('data.csv',
    sep=';',                   # different delimiter
    usecols=['name', 'salary'], # load only these columns
    nrows=100,                 # read first 100 rows only
    dtype={'salary': 'int32'}, # specify column dtypes
    parse_dates=['date'],      # parse these cols as datetime
    skiprows=1                 # skip first N rows
)
index=False matters: without it, to_csv writes the integer index as an extra column. When you read it back, you'll get an unnamed column Unnamed: 0. Always pass index=False unless the index carries meaning.
Excel & JSON

to_excel() and to_json()

python
# requires openpyxl: pip install openpyxl
df.to_excel('employees.xlsx', index=False, sheet_name='Staff')

# read back
df2 = pd.read_excel('employees.xlsx', sheet_name='Staff')

# write multiple sheets
with pd.ExcelWriter('report.xlsx') as writer:
    df.to_excel(writer, sheet_name='Employees', index=False)
python
# orient='records' → list of dicts (most common for APIs)
df.to_json('employees.json', orient='records', indent=2)

# read JSON back
df3 = pd.read_json('employees.json')

# common orient values:
# 'records'  — list of {col: val} dicts
# 'split'    — {index, columns, data}
# 'columns'  — {col: {index: val}} (default)
# 'index'    — {index: {col: val}}

Format comparison:
  • CSV — human-readable, slow, loses dtypes
  • Excel — good for sharing with non-coders
  • JSON — great for APIs, can store nested data
  • Parquet — fast, compressed, preserves dtypes — best for large data pipelines
Exercises

Practice — Export / I/O

Q1

Write the DataFrame to a CSV file without the index, then read it back and verify the shape is (3, 3).

df = pd.DataFrame({
    'city':  ['Paris', 'London', 'Berlin'],
    'pop':   [2_161_000, 8_982_000, 3_669_000],
    'country': ['FR', 'UK', 'DE']
})
Show answer 
df.to_csv('cities.csv', index=False)
df2 = pd.read_csv('cities.csv')
print(df2.shape)    # (3, 3)
print(df2.columns.tolist())  # ['city', 'pop', 'country']
Q2

Read data.csv but load only the name and salary columns, and only the first 10 rows.

Show answer 
df = pd.read_csv(
    'data.csv',
    usecols=['name', 'salary'],
    nrows=10
)
Q3

Export the DataFrame as JSON using orient='records' so the output is a list of dictionaries.

df = pd.DataFrame({'product':['A','B'], 'price':[10,25]})
Show answer 
json_str = df.to_json(orient='records')
print(json_str)
# [{"product":"A","price":10},{"product":"B","price":25}]

# or write directly to a file with indentation
df.to_json('products.json', orient='records', indent=2)
