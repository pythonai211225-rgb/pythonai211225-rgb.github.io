query()

Readable Filters with query()

query() accepts a string expression — cleaner than nested boolean conditions for complex filters.

What syntax is this? query() is a pandas method, not SQL. The expression inside the string is a pandas query expression: it looks like Python, uses DataFrame column names directly, and supports comparisons such as >, ==, and, or, and in. To use a normal Python variable inside the string, prefix it with @, like @threshold.

Official reference: pandas.DataFrame.query()

Q1

Using the sample DataFrame above, filter all rows where score is between 70 and 90 (inclusive). Print only the name and score columns.

Show answer 
result = df[(df.score >= 70) & (df.score <= 90)][['name', 'score']]
print(result)
#     name  score
# 0  Alice     88
# 2  Carol     75
Q2

Use df.loc to select rows where grade is 'A', and return only the name and age columns.

Show answer 
result = df.loc[df.grade == 'A', ['name', 'age']]
print(result)
#   name  age
# 1  Bob   25
# 4  Eve   24
Q3

Write the same filter from Q2 using query(). Then also add a second condition: age must be less than 25.

Show answer 
# same as Q2
df.query('grade == "A"')[['name', 'age']]

# with extra condition
df.query('grade == "A" and age < 25')[['name', 'age']]
#   name  age
# 4  Eve   24
Q4

Use df.iloc to select the value at the 3rd row and 2nd column (zero-based). What is the value?

Show answer 
print(df.iloc[2, 1])   # row index 2, col index 1 → score of Carol
# 75
