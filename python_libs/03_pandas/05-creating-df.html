Creating DataFrames

Every pandas workflow starts by getting data into a DataFrame. You can build one from a Python dict, a list of lists, a CSV file, or even a MultiIndex structure.

pd.DataFrame pd.Series read_csv MultiIndex
Method 1 — From dict

Specify Values per Column

Pass a Python dictionary where each key is a column name and each value is a list. All lists must have the same length.

python
import pandas as pd

df = pd.DataFrame({
    "name":   ["Alice", "Bob", "Carol"],
    "score":  [88, 92, 75],
    "passed": [True, True, False]
}, index=[1, 2, 3])
df

Method 2 — From list of lists

Specify Values per Row

Pass a list of rows. Each inner list is one row. Specify column names separately with the columns parameter.

python
df = pd.DataFrame(
    [["Alice", 88, True],
     ["Bob",   92, True],
     ["Carol", 75, False]],
    columns=["name", "score", "passed"],
    index=[1, 2, 3]
)
df
indexnamescorepassed
1Alice88True
2Bob92True
3Carol75False
Dict vs List of lists: Dict is more readable when you know column names upfront. List of lists is handy when you have rows coming from an API or a loop.

Method 4 — MultiIndex

DataFrame with a MultiIndex

A MultiIndex lets you have hierarchical row labels — useful for panel data (data across time and categories).

python
idx = pd.MultiIndex.from_tuples(
    [('Math', 2023), ('Math', 2024),
     ('Science', 2023), ('Science', 2024)],
    names=['subject', 'year']
)
df = pd.DataFrame(
    {'avg_score': [82, 85, 78, 81],
     'students':  [30, 32, 28, 31]},
    index=idx
)

Practice — Creating DataFrames

Q1

Create a DataFrame with columns city, population and country containing 4 rows of real or made-up cities. Print the shape and dtypes.

Show answer 
df = pd.DataFrame({
    'city':       ['Tokyo', 'Delhi', 'London', 'Paris'],
    'population': [13960000, 11034555, 8982000, 2148000],
    'country':    ['Japan', 'India', 'UK', 'France']
})
print(df.shape)   # (4, 3)
print(df.dtypes)  # city object, population int64, country object
