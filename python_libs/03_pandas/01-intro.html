Intro to Pandas

Pandas is the go-to library for working with tabular data in Python. Think of it as Excel — but scriptable, infinitely scalable, and built on top of NumPy.

pandas DataFrame Series pip install import pandas as pd
What is Pandas?

Pandas — Panel Data

Pandas (short for Panel Data) is an open-source Python library built on top of NumPy that provides high-performance, easy-to-use data structures for data analysis. It was created by Wes McKinney in 2008 and is now the standard tool for data wrangling in Python.

Core idea: Pandas gives you two key data structures — the DataFrame (a table with labelled rows and columns) and the Series (a single labelled column). Everything is indexed, aligned, and designed for real-world messy data.
📊

DataFrame

A 2D table — rows and named columns. Think of it as a spreadsheet or SQL table. Each column is a Series.

📈

Series

A 1D labelled array — like a single column in a spreadsheet. Has an index, can hold any data type.

🔢

Built on NumPy

Under the hood every column is a NumPy array. All NumPy speed and vectorized operations are available.

🏷️

Labelled Data

Unlike NumPy, rows and columns have names. You slice by label (df['price']) not just by index.

🧹

Handles Messy Data

Missing values (NaN), mixed types, date parsing, string operations — pandas handles real-world data gracefully.

📂

I/O Everywhere

Read and write CSV, Excel, JSON, SQL, Parquet, HTML, clipboard and more — all with one-liners.

DataFrame vs Series

The Two Core Objects

python
# ── Series: one column with an index ──
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s)
# a    10
# b    20
# c    30
# dtype: int64

# ── DataFrame: multiple columns, shared index ──
df = pd.DataFrame({
    'name':  ['Alice', 'Bob', 'Carol'],
    'score': [88, 92, 75],
    'grade': ['B', 'A', 'C']
})
print(df)
#     name  score grade
# 0  Alice     88     B
# 1    Bob     92     A
# 2  Carol     75     C

# Each column is a Series
print(type(df['score']))   # <class 'pandas.core.series.Series'>
Rule of thumb: A DataFrame is a dictionary of Series objects that share the same index. df['col'] returns a Series; df[['col']] (double brackets) returns a one-column DataFrame.
