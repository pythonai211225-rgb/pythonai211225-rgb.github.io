Creating a Series

Creating Pandas Series

Use pd.Series() to create a one-dimensional labelled array. You can pass a Python list, a list with a custom index, or a dictionary.

Function / DescriptionExample
pd.Series(list)
Create a Series from a Python list. Pandas automatically assigns integer indexes starting at 0. Printing shows the index on the left and the value on the right, followed by the dtype.
import pandas as pd s = pd.Series([10, 100, 15, 35]) print(s) # 0 10 # 1 100 # 2 15 # 3 35 # dtype: int64
pd.Series(list, index=)
Pass an index parameter with a list of labels to replace the default integer index with custom string labels (label indexing). Label indexes are unique — no duplicates allowed.
data = [1776, 1867, 1821] labels = ['USA', 'CANADA', 'MEXICO'] s = pd.Series(data=data, index=labels) print(s) # USA 1776 # CANADA 1867 # MEXICO 1821 # dtype: int64
pd.Series(dict)
Pass a Python dictionary. Dictionary keys become the index and values become the data — no need for a separate index parameter.
countries = { 'USA': 1776, 'CANADA': 1867, 'MEXICO': 1821 } s = pd.Series(countries) print(s) # USA 1776 # CANADA 1867 # MEXICO 1821 # dtype: int64
Accessing Data

Indexing and Keys

Access values by label or by integer position. Both approaches work on the same Series.

Syntax / DescriptionExample
series['label']
Get a single value by its label index. Works like accessing a dictionary by key. Raises KeyError if the label doesn't exist.
s = pd.Series( {'USA': 1776, 'CANADA': 1867, 'MEXICO': 1821} ) print(s['USA']) # 1776
series[0]
Get a value by its integer (positional) index. Even with label indexes, the default numeric position still works alongside the label.
s = pd.Series( {'USA': 1776, 'CANADA': 1867, 'MEXICO': 1821} ) print(s['USA']) # 1776 ← by label print(s[0]) # 1776 ← same result by position
series.keys()
Returns an Index object containing all the Series indexes. Behaves like a Python list — you can subscript it with [i] to get a specific label.
s = pd.Series( {'USA': 1776, 'CANADA': 1867, 'MEXICO': 1821} ) print(s.keys()) # Index(['USA', 'CANADA', 'MEXICO'], dtype='object') print(s.keys()[0]) # USA
Arithmetic

Series Arithmetic & Addition

Use + to combine two Series — pandas aligns by matching index labels. Labels in only one Series produce NaN. Use .add(fill_value=) to avoid this.

Operator / Method / DescriptionExample
series_a + series_b
Adds two Series together by aligning on matching index labels. Labels that exist in only one Series produce NaN because pandas cannot add a known value to a missing one.
first = pd.Series({'Japan': 100, 'China': 450, 'USA': 250}) second = pd.Series({'Brazil': 70, 'China': 350, 'USA': 200}) result = first + second print(result) # Brazil NaN ← only in second # China 800.0 # Japan NaN ← only in first # USA 450.0 # dtype: float64
.add(other, fill_value=)
Same as + but accepts a fill_value parameter. Missing labels are treated as fill_value before adding, so non-overlapping indexes get fill_value + actual_value instead of NaN.
first = pd.Series({'Japan': 100, 'China': 450, 'USA': 250}) second = pd.Series({'Brazil': 70, 'China': 350, 'USA': 200}) result = first.add(second, fill_value=0) print(result) # Brazil 70.0 ← 0 + 70 # China 800.0 # Japan 100.0 ← 100 + 0 # USA 450.0 # dtype: float64
Data Types

dtype & astype

Every Series stores values of a single data type. Use .dtype to inspect it and .astype() to convert it.

Property / Method / DescriptionExample
.dtype
Property (no parentheses) that returns the data type of all values stored in the Series. Common types: int64, float64, object (strings), bool.
s = pd.Series({ 'Brazil': 70.0, 'China': 800.0, 'Japan': 100.0, 'USA': 450.0 }) print(s.dtype) # float64
.astype(type)
Convert all values in the Series to a new type. Pass a Python type (int, float, str) or a dtype string. Returns a new Series — the original is unchanged.

Introduction

What is a DataFrame?

Until now we only used the Series data structure, which stores 1 value per key. In real life we need structures that can hold multiple values for a given key — like a table with columns and rows. For that we use the DataFrame.

A Pandas DataFrame is a two-dimensional, size-mutable data structure with labelled axes (rows and columns). It handles integers, floats, strings, and complex structures like lists and dictionaries — and is used for data cleaning, transformation, statistical analysis, and machine learning.

Pandas uses Series to represent each column in the DataFrame. A DataFrame can be thought of as a dictionary of Series objects that all share the same row index.

Creating

Creating a DataFrame

Use pd.DataFrame() to create a DataFrame from a numpy matrix or list of lists. Add optional index and columns parameters for custom labels.

Function / Parameter / DescriptionExample
pd.DataFrame(matrix)
Create a DataFrame from a 2-D array or numpy matrix. Pandas assigns default numeric indexes (0, 1, 2…) to both rows and columns.

pd.DataFrame(data, index=)
Pass a list of labels as the index parameter to replace default numeric row indexes. The order of labels in the list maps label → row in order.
my_data = np.random.randint(0, 101, (4, 3)) my_index = ['CA', 'NY', 'AZ', 'TX'] my_df = pd.DataFrame(data=my_data, index=my_index) print(my_df) # 0 1 2 # CA 98 14 34 # NY 24 15 100 # AZ 60 58 16 # TX 9 93 86
pd.DataFrame(data, index=, columns=)
Add a columns parameter to label each column. Note: adding label indexes does not replace the default numeric index — both coexist.
my_data = np.random.randint(0, 101, (4, 3)) my_index = ['CA', 'NY', 'AZ', 'TX'] my_cols = ['Jan', 'Feb', 'Mar'] my_df = pd.DataFrame(data=my_data, index=my_index, columns=my_cols) print(my_df) # Jan Feb Mar # CA 2 27 4 # NY 31 1 13 # AZ 83 100 4 # TX 91 59 67

set_index, iloc, loc & concat

Use set_index() to promote a column to the row index. Use iloc[] to select rows by position and loc[] to select by label. Use pd.concat() to stack DataFrames together.

Method / DescriptionExample
df.set_index('col')
Promote a column to the row index. The column disappears from the regular columns and becomes the new row label. Use inplace=True to persist the change on the original DataFrame.

Conditional Filtering

Filtering DataFrame Rows

Apply a condition to a column to get a boolean Series, then pass it back into the DataFrame to keep only matching rows. Use &, |, and ~ for compound conditions.

Operator / Method / DescriptionExample
df['col'] > value
Apply a comparison to a column — returns a boolean Series with True where the condition is met and False where it is not. Can use >, <, ==, !=, >=, <=.
countries_df = pd.DataFrame({ 'Country': ['USA', 'Canada', 'Mexico'], 'Year': [1776, 1867, 1821], 'Population': [328, 38, 126], 'GDP': [20.5, 1.7, 1.22] }) countries_df['Population'] > 50 # 0 True # 1 False # 2 True # Name: Population, dtype: bool
df[condition]
Pass the boolean Series back into the DataFrame to keep only rows where the condition is True. Returns a new filtered DataFrame.
countries_df[countries_df['Population'] > 50] # Country Year Population GDP # 0 USA 1776 328 20.50 # 2 Mexico 1821 126 1.22
cond1 & cond2
cond1 | cond2
~cond
& = AND (both must be true).
| = OR (at least one must be true).
~ = NOT (inverts the mask).
Always wrap each condition in parentheses when combining.
# AND: population > 50 AND country in list countries_df[ (countries_df['Population'] > 50) & (countries_df['Country'].isin(['Canada', 'USA'])) ] # Country Year Population GDP # 0 USA 1776 328 20.5 # NOT: exclude rows where Year is 1776 countries_df[~countries_df['Year'].isin([1776])] # Country Year Population GDP # 1 Canada 1867 38 1.70 # 2 Mexico 1821 126 1.22
.isin([...])
Returns a boolean mask that is True wherever the column value is in the provided list. Equivalent to multiple == conditions joined by |.
tips_df = pd.read_csv('tips.csv') # keep only Sunday and Saturday rows tips_df[tips_df['day'].isin(['Sun', 'Sat'])] # returns all rows where day is Sun or Sat
.between(a, b)
Returns a boolean mask that is True wherever the value is between a and b. Pass inclusive='both', 'left', 'right', or 'neither' to control boundary inclusion.
# rows where total_bill is between 10 and 20 inclusive tips_df[tips_df['total_bill'].between(10, 20, inclusive='both')] # 130 rows × 11 columns # total_bill tip sex smoker day ... # 0 16.99 1.01 Female No Sun ... # 1 10.34 1.66 Male No Sun ... # ...

Custom Functionality

df.apply() — Custom Column Functions

When Pandas built-in functions are not enough, write a regular Python function and pass it to df['col'].apply(func). Pandas will call the function once for every value in that column and collect the results into a new Series.

Method / DescriptionExample
def func(val): ...
Define a regular Python function that accepts one value and returns one value. This becomes the per-row transformation logic.
# extracts the last 4 digits of a credit card number def last_four(num): return str(num)[-4:] print(last_four(3560325168603410)) # 3410
df['col'].apply(func)
Pass the function (no parentheses) to apply(). Pandas calls it on every value in the column and returns a Series of results. Assign to a new column to store the output.
tips_df = pd.read_csv('tips.csv') # create 'last_four' column from CC Number tips_df['last_four'] = tips_df['CC Number'].apply(last_four) tips_df[['Payer Name', 'CC Number', 'last_four']].head(3) # Payer Name CC Number last_four # 0 Christy Cunningham 3560325168603410 3410 # 1 Douglas Tucker 4478071379779230 9230 # 2 Travis Walters 6011812112971322 1322
Multi-Column Functions

np.vectorize() — Functions Across Multiple Columns

When a custom function needs to read from more than one column per row, wrap it with np.vectorize(). This makes a regular Python function "NumPy-aware" so you can pass entire DataFrame columns as arguments.

Method / DescriptionExample
def func(col1, col2): ...
Write a function that accepts one value from each required column. Here the function classifies a tipper as Generous or Not Generous based on two columns.
def quality(total_bill, tip): if tip / total_bill > 0.25: return 'Generous' else: return 'Not Generous'
np.vectorize(func)(col1, col2)
First wrap the function with np.vectorize(), then call the result passing the DataFrame columns as positional arguments. Each pair of row values is processed together.
import numpy as np # vectorize, then pass both columns as arguments tips_df['quality'] = np.vectorize(quality)( tips_df['total_bill'], tips_df['tip'] ) tips_df[['total_bill', 'tip', 'quality']].head(3) # 0 16.99 1.01 Not Generous # 1 10.34 1.66 Not Generous # 2 21.01 3.50 Not Generous

Missing Data

Detecting Missing Data — isnull() & notnull()

Missing data is one of the most common problems in data science. Sources don't always provide every value expected, leaving gaps that Pandas represents as np.nan. Always check for NaN before analysis — use is (not ==) to test for it directly.

There are 3 strategies: keep the NaN as-is (simple but limits some algorithms), delete rows/columns (easy but risks data loss), or fill with a substitute value (best coverage, hardest to do well).

Practice dataset used in the examples below: ↓ Download movie_scores.csv
Method / DescriptionExample
myvar is np.nan
Use the is operator (not ==) to check if a value is NaN. The == operator returns False for NaN due to IEEE 754 floating-point rules.
import numpy as np myvar = np.nan print(myvar is np.nan) # True print(myvar == np.nan) # False
df['col'].isnull()
Returns a boolean Series — True where the value is NaN, False where it is present.
movie_score_df = pd.read_csv('movie_scores.csv') movie_score_df['first_name'].isnull() # 0 False # 1 True ← missing value # 2 False # 3 False # 4 False # Name: first_name, dtype: bool
df['col'].notnull()
The opposite of isnull() — returns True where a value is present, False where it is NaN. Use as a filter mask to keep only non-missing rows.
# keep only rows that have a pre_movie_score movie_score_df[ movie_score_df['pre_movie_score'].notnull() ] # first_name last_name age sex pre post # 0 Tom Hanks 63.0 m 8.0 10.0 # 3 Oprah Winfrey 66.0 f 6.0 8.0 # 4 Emma Stone 31.0 f 7.0 9.0
df[cond1 & cond2]
Combine isnull() and notnull() with & to filter on multiple null conditions at once.
# rows with a first_name but missing pre_movie_score movie_score_df[ movie_score_df['pre_movie_score'].isnull() & movie_score_df['first_name'].notnull() ] # first_name last_name age sex pre post # 2 Hugh Jackman 51.0 m NaN NaN
Drop Missing

df.dropna() — Removing Rows & Columns with NaN

Remove rows (or columns) that contain NaN values. Use thresh, axis, and subset to control exactly what gets dropped.

Parameter / DescriptionExample
df.dropna()
Remove every row that has at least one NaN value. Returns a DataFrame containing only complete rows.
movie_score_df.dropna() # first_name last_name age sex pre post # 0 Tom Hanks 63.0 m 8.0 10.0 # 3 Oprah Winfrey 66.0 f 6.0 8.0 # 4 Emma Stone 31.0 f 7.0 9.0
df.dropna(thresh=n)
Only drop a row if it has fewer than n non-null values. Useful for keeping rows that have most of their data and only drop the nearly-empty ones.
# keep rows with at least 1 non-null value # (drops only rows that are ALL NaN) movie_score_df.dropna(thresh=1) # first_name last_name age sex pre post # 0 Tom Hanks 63.0 m 8.0 10.0 # 2 Hugh Jackman 51.0 m NaN NaN # 3 Oprah Winfrey 66.0 f 6.0 8.0 # 4 Emma Stone 31.0 f 7.0 9.0
df.dropna(axis=1)
axis=0 (default) drops nullable rows. axis=1 drops nullable columns instead — removes any column that contains at least one NaN.
# remove any column that has even one NaN movie_score_df.dropna(axis=1)
df.dropna(subset=['col'])
Apply the drop logic only to specific columns. A row is dropped only if it has a NaN in one of those columns — NaN in other columns is ignored.
# drop rows missing 'first_name' only movie_score_df.dropna(subset=['first_name']) # first_name last_name age sex pre post # 0 Tom Hanks 63.0 m 8.0 10.0 # 2 Hugh Jackman 51.0 m NaN NaN # 3 Oprah Winfrey 66.0 f 6.0 8.0 # 4 Emma Stone 31.0 f 7.0 9.0 # combine thresh + subset: always empty here # because subset has only 1 column movie_score_df.dropna(thresh=2, subset=['first_name'])
Fill Missing

df.fillna() — Replacing NaN with Real Values

Instead of dropping missing data, replace it with a meaningful value — a fixed constant, the column mean, median, or any other computed value.

Method / DescriptionExample
df['col'].fillna(value)
Replace every NaN in the column with a fixed value. Reassign back to the column (or use inplace=True) to persist the change.
# fill missing pre_movie_score with 0 movie_score_df['pre_movie_score'] = ( movie_score_df['pre_movie_score'].fillna(0) ) # first_name ... pre_movie_score post_movie_score # 0 Tom ... 8.0 10.0 # 1 NaN ... 0.0 NaN # 2 Hugh ... 0.0 NaN
df['col'].fillna(df['col'].mean())
Fill NaN values with the column's mean (or any aggregate like median(), max()). A common strategy in machine learning to preserve row count without biasing the distribution heavily.
