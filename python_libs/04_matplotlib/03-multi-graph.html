Topic 03 — Subplots, Legends & Chart Types

Subplots, Legends & Chart Types

Create multi-chart layouts with plt.subplots(), add legends, customize line styles, and draw the most common chart types: line, bar, histogram, and scatter.

plt.subplots() ax.legend() ax.bar() ax.hist() ax.scatter()
plt.subplots()

Creating Multiple Charts with plt.subplots()

plt.subplots() is the recommended way to create multiple charts on one canvas. It returns two objects at once: the Figure (canvas) and an array of Axes objects (the actual chart areas).

Object / DescriptionCode & Output
plt.subplots(nrows, ncols)
Returns fig, axes.

fig — the Figure (canvas) everything is drawn on.
axes — an array of Axes objects. Each Axes is one chart area that can be individually configured with labels, title, xlim, ylim and data.
# 1 row, 2 columns → side-by-side charts fig, axes = plt.subplots(nrows=1, ncols=2)
Output — 2 empty side-by-side chart areas
ParameterDescription
nrowsNumber of rows of charts. Default is 1.
ncolsNumber of columns of charts. Default is 1.
figsizeTuple (width, height) in inches for the canvas size.
Indexing

Array vs Matrix — How to Access Each Chart

The way you index into the axes object depends on whether you passed only one dimension or two to plt.subplots().

Type / DescriptionCode & Output
Array of axes
When nrows = 1 or ncols = 1, you get a 1D array. Access each chart with a single index: axes[0], axes[1], etc.
# nrows=1 → 1D array of axes fig, axes = plt.subplots(nrows=1, ncols=2) x1 = np.arange(10) y1 = x1 * 2 x2 = np.arange(0, 5, 0.1) y2 = np.sin(x2) axes[0].plot(x1, y1) # first chart axes[1].plot(x2, y2) # second chart
Output — 1×2 array: linear left, sine right
Matrix of axes
When nrows > 1 and ncols > 1, you get a 2D matrix. Access each chart with row and column indices: axes[row][col].
# nrows=2, ncols=2 → 2D matrix of axes fig, axes = plt.subplots(nrows=2, ncols=2) axes[0][0].plot(x1, y1) # top-left axes[0][1].plot(x2, y2) # top-right # axes[1][0], axes[1][1] → bottom row
Output — 2×2 matrix: [row][col] indexing
Rule: If only one of nrows/ncols is >1, you get a 1D array (axes[i]). If both are >1, you get a 2D matrix (axes[i][j]).
Legends

ax.legend() — Labelling Multiple Lines

When plotting multiple graphs on the same axes, use ax.legend() to add a legend box that identifies each line. You must provide a label parameter to each ax.plot() call so the legend knows what to display.

Parameter / DescriptionCode & Output
ax.plot(..., label='text') ax.legend()
Step 1 — pass label='...' to each ax.plot() call to name that line.

Step 2 — call ax.legend() to render the legend box on the chart. Matplotlib auto-places it in the best empty spot.
x = np.arange(0, 11) fig = plt.figure() ax = fig.add_axes([0, 0, 1, 1]) ax.plot(x, x, label='X vs X') ax.plot(x, x**2, label='X vs X^2') ax.legend()
Output — legend auto-placed top-left
ax.legend(loc=(x, y))
The loc parameter positions the legend.

0–1 → inside the chart (e.g. loc=(0.5, 0.5) = center)
>1 or <0 → outside the chart boundary (e.g. loc=(1.1, 0.5) = right of chart)
# loc=(1.1, 0.5) → outside right edge ax.legend(loc=(1.1, 0.5))
Output — legend floated outside the chart
Styling

Plot Styling Parameters

Every ax.plot() call accepts styling parameters that control the line's color, width, style, and marker points. Pass them as keyword arguments alongside your data.

ParameterDescriptionExample values
colorLine color — accepts any CSS/hex color or named color.'red', '#1FEBDD', (0.1,0.5,0.9)
lw / linewidthLine width multiplier. Default = 1. Use 2 for double, 0.5 for half.lw=2
ls / linestyleLine style. Dashes, dots, dash-dot, or custom patterns.'--', ':', '-.', '-'
markerSymbol drawn at each real data point. The line between points is interpolated.'o', '+', '>', '<', '-'
markersizeSize of the marker symbol in points.markersize=8
Styled plot exampleOutput chart
fig = plt.figure() ax = fig.add_axes([0, 0, 1, 1]) ax.set_title('Customized Chart') ax.plot(x, x+1, marker='o', lw=2, ls='--', color='#1FEBDD')
Dashed cyan line with circle markers at each data point
Chart Functions

Matplotlib Chart Functions

All four chart functions are called on an Axes object (ax) — the chart area returned by plt.subplots() or fig.add_axes().

Function / DescriptionCode & Output
ax.plot(x, y)
Draws a line chart. First argument = X axis data, second = Y axis data. Points are connected by a continuous line.
x = np.arange(10) y_linear = x * 2 ax.plot(x, y_linear) ax.set_title('Line Plot')
Output — connected line rising left to right
ax.scatter(x, y, color='r')
Draws a scatter plot. First arg = independent variable (X), second = dependent (Y). Points are not connected. Use color to set dot color.
y_scatter = np.random.randn(10) ax.scatter(x, y_scatter, color='r') ax.set_title('Scatter Plot')
Output — individual red dots, no lines
ax.bar(categories, values, color='g')
Draws a bar chart. First arg = category labels (strings or numbers), second = the value (bar height) for each category.
categories = ['A', 'B', 'C', 'D', 'E'] values = np.random.rand(5) ax.bar(categories, values, color='g') ax.set_title('Bar Plot')
Output — green bars per category
ax.hist(data, bins=n, color='b', alpha=0.7)
Draws a histogram. Takes one data array. bins controls the number of columns — more bins = more detail but harder to read. alpha sets transparency (0–1).
y_hist = np.random.randn(1000) ax.hist(y_hist, bins=30, color='b', alpha=0.7) ax.set_title('Histogram')
Output — bell-curve distribution (1000 random values)
ax.pie(values, labels=..., autopct='%1.1f%%')
Draws a pie chart. Pass a list of values (sizes of each slice) and a matching list of labels. autopct prints the percentage inside each slice.
slices = [40, 35, 15, 10] labels = ['Bicycle', 'Bus', 'Car', 'Walking'] ax.pie(slices, labels=labels, autopct='%1.1f%%') ax.set_title('Types of Transportation')
Output — slices proportional to each value
bins parameter: More bins = the histogram is more detailed and accurate, but harder to read (more noise). Start with 20–30 bins and adjust based on your data size.
Full Example

2×2 Subplot — All Four Chart Types

Combining everything: plt.subplots(2, 2) creates a 2×2 grid. Populate each chart with a different chart type, set a figure-level title with fig.suptitle(), then call plt.tight_layout() to auto-adjust spacing.

CodeOutput
# Seed for reproducibility np.random.seed(0) # Data preparation x = np.arange(10) y_linear = x * 2 y_scatter = np.random.randn(10) categories = ['A','B','C','D','E'] bar_values = np.random.rand(5) y_hist = np.random.randn(1000) # 2×2 subplot fig, ax = plt.subplots(2, 2, figsize=(10, 10)) ax[0][0].plot(x, y_linear) ax[0][0].set_title('Line Plot') ax[0][1].scatter(x, y_scatter, color='r') ax[0][1].set_title('Scatter Plot') ax[1][0].bar(categories, bar_values, color='g') ax[1][0].set_title('Bar Plot') ax[1][1].hist(y_hist, bins=30, color='b', alpha=0.7) ax[1][1].set_title('Histogram') fig.suptitle('4 Types of Matplotlib Plots', fontsize=16) plt.tight_layout() plt.show()
2×2 output — Line / Scatter / Bar / Histogram
fig.suptitle('Title', fontsize=16) — adds a single title above all charts in the subplot (figure-level). plt.tight_layout() automatically adjusts spacing between charts so they don't overlap.
