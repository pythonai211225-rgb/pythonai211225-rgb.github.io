Scatter Plot
Basic Scatter

sns.scatterplot()

sns.scatterplot() creates a scatter plot showing the relationship between two numeric variables. Pass the column names as strings via x= and y=, and the DataFrame via data=.

Python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv('dm_office_sales.csv')

sns.scatterplot(x='salary', y='sales', data=df)
plt.show()
Output — salary vs sales scatter
sns vs plt: sns.scatterplot() draws the chart. plt.show() displays it. Seaborn automatically reads the DataFrame column names and uses them as axis labels.
Figure Size

Controlling Chart Size with figsize

Seaborn uses Matplotlib's figure system. Call plt.figure(figsize=(width, height)) before the Seaborn function to set the canvas size in inches.

Python
plt.figure(figsize=(10, 6))   # 10 inches wide, 6 inches tall

sns.scatterplot(
    x='salary',
    y='sales',
    data=df
)
plt.show()
Rule: plt.figure(figsize=...) must come before the Seaborn call. Calling it after has no effect on the current chart.

hue Parameter

Color by Category — the hue Parameter

The hue parameter colors each dot based on a categorical column. Seaborn automatically assigns a distinct color per unique value and adds a legend.

Python
plt.figure(figsize=(10, 6))

sns.scatterplot(
    x='salary',
    y='sales',
    hue='training level',   # color by training level (0/1/2/3)
    data=df
)
plt.show()
Output — hue = 'training level'
Result: Each dot is now colored by training level (0, 1, 2, or 3). A legend is automatically added by Seaborn. Higher training levels cluster toward higher salaries and sales.

You can also use hue with a numeric column — Seaborn will use a continuous color gradient instead of discrete colors:

Python
sns.scatterplot(x='salary', y='sales',
                 hue='work experience',   # numeric → gradient
                 data=df)
palette Parameter

Choosing Colors — the palette Parameter

The palette parameter controls which color scheme is used for the hue categories. Seaborn includes dozens of built-in palettes.

Python
sns.scatterplot(
    x='salary',
    y='sales',
    hue='training level',
    palette='coolwarm',   # blue → red gradient
    data=df
)

More Parameters

size / s / alpha / style Parameters

Seaborn's scatterplot() supports several parameters that modify dot appearance to encode additional dimensions of information:

Python — all parameters together
sns.scatterplot(
    x='salary',
    y='sales',
    hue='training level',
    size='work experience',  # dot size by years
    style='division',         # dot shape by division
    alpha=0.6,               # 60% opacity for overlap
    data=df
)
ParameterWhat it doesValues
hue= Colors each dot by a column value. String (column name) from the DataFrame. 'training level'
palette= Color scheme used for the hue categories. 'deep', 'Set2', 'viridis'
size= Scales dot diameter by a numeric column. Higher value → bigger dot. 'work experience'
s= Sets a fixed dot size in points² (Matplotlib-style). Use instead of size= when you don't want size to encode data. s=80 (default ~36)
alpha= Dot transparency. 0 = fully transparent, 1 = fully opaque. Helps show overlapping dots in dense scatter. 0.0 – 1.0
style= Assigns different marker shapes (circle, triangle, square…) by a categorical column. 'division'
Encoding tip: Use hue for the most important category. Add size or style for secondary dimensions. Too many encodings at once make the chart hard to read.
