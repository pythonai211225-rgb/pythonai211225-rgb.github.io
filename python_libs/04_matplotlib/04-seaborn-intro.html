Intro to Seaborn

Seaborn is a statistical data visualization library built on top of Matplotlib. It works natively with Pandas DataFrames and makes complex charts — scatter plots, histograms, box plots, and more — with minimal code.

seaborn Statistical Plots Built on Matplotlib Works with Pandas import seaborn as sns
What is Seaborn?

Seaborn — Statistical Data Visualization

Seaborn is a Python data visualization library built on top of Matplotlib. It provides a high-level interface for creating attractive statistical graphics. Seaborn is designed to work seamlessly with Pandas DataFrames — you pass the DataFrame and column names directly into plotting functions.

Key advantage: Where Matplotlib requires you to extract arrays and manage figure details manually, Seaborn lets you write sns.scatterplot(x='salary', y='sales', data=df) and get a fully labeled chart in one line.
📊

Statistical Charts

Built-in support for scatter plots with regression lines, KDE plots, box plots, violin plots, and heatmaps — all with statistical meaning baked in.

🐼

DataFrame-Native

Pass a Pandas DataFrame directly via the data= parameter. Use column names as strings for x, y, hue, size, and style — no need to extract Series manually.

🎨

Beautiful Defaults

Seaborn ships with thoughtful color palettes and clean themes. Charts look polished without manual styling — great for exploratory data analysis.

📐

Built on Matplotlib

Every Seaborn chart is a Matplotlib figure underneath. You can mix plt. calls — plt.title(), plt.xlabel(), plt.figure(figsize=...) — alongside Seaborn functions.

Installation

Installing Seaborn

Seaborn is not part of the Python standard library. Install it once using pip from your terminal or command prompt:

Terminal / CMD 
pip install seaborn
Anaconda users: Seaborn is included with the Anaconda distribution. You can skip the pip install step — just import it directly.

To verify the installation and check the version:

Python 
import seaborn
print(seaborn.__version__)
Import

Importing Seaborn

The standard convention is to import Seaborn as sns. You will almost always also need Matplotlib pyplot and Pandas:

Python 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np
Why all four? Seaborn (sns) creates the chart. Matplotlib (plt) controls figure size, titles, and plt.show(). Pandas (pd) loads the data. NumPy (np) is needed when you pass custom estimators to sns.barplot(estimator=np.mean).
