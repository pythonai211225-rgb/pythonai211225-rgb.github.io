Charts
Histogram

sns.displot() — Distribution / Histogram

sns.displot() draws a histogram showing the distribution of a single numeric variable. The bins parameter sets how many bars to use — more bins means narrower bars.

Python
sns.displot(data=df, x='salary', bins=20)
plt.show()
Output — salary distribution (bins=20)
Reading a histogram: Each bar's height shows how many employees (count) have a salary in that range. The peak around 80–90K means most employees earn in that bracket.

To control the chart size, use plt.figure(figsize=...) before sns.displot(), or pass height= and aspect= directly into displot():

Python
sns.displot(data=df, x='salary',
             bins=20, height=5, aspect=1.8)
KDE Plot

KDE Curve — kde=True & sns.kdeplot()

A KDE (Kernel Density Estimate) curve is a smooth line drawn over a histogram that estimates the underlying probability distribution. Add it to displot() with kde=True, or draw it standalone with sns.kdeplot().

Python — histogram + KDE overlay
sns.displot(data=df, x='salary', kde=True)
plt.show()
Output — histogram with KDE curve (kde=True)

To draw only the KDE curve without histogram bars:

Python — standalone KDE
sns.kdeplot(data=df, x='salary')
plt.show()
KDE vs Histogram: A histogram groups values into fixed-width bins — the shape depends on bin size. A KDE curve is continuous and doesn't depend on bin width, making it a smoother estimate of the underlying distribution.
Count Plot

sns.countplot() — Count per Category

sns.countplot() draws a bar chart where each bar's height is the count of rows with that category value. It is the categorical equivalent of a histogram.

Python
plt.figure(figsize=(10, 5), dpi=80)

sns.countplot(data=df, x='level of education')
plt.xlabel('Education Level')
plt.show()
Output — count by level of education

Add the hue parameter to split each bar by a second category:

Python — countplot with hue
sns.countplot(
    data=df,
    x='level of education',
    hue='training level'   # 4 sub-bars per category
)
hue='training level' — 4 bars per education category
ylim Warning — Deceptive Charts: Count plots automatically start the y-axis at 0. But if you manually set plt.ylim(350, 420) to "zoom in," small differences between bars look enormous. Always start y-axis at 0 when comparing counts.
Bar Plot

sns.barplot() — Aggregate Statistic per Category

sns.barplot() shows an aggregate statistic (default: mean) of a numeric variable for each category, plus an error bar showing uncertainty. Unlike countplot, this shows a computed value, not raw counts.

Python
import numpy as np

sns.barplot(
    data=df,
    x='level of education',
    y='salary',
    estimator=np.mean,   # compute mean salary per group
    errorbar='sd'         # error bars show standard deviation
)
plt.show()
Output — mean salary by education level (with error bars)
ParameterPurposeCommon values
estimator=The function used to aggregate y values per group. Default is np.mean.np.mean, np.median, np.sum
errorbar=Statistic to display as error bar width.'sd' (std dev), 'ci' (conf interval), None
hue=Split each category into sub-bars colored by the hue column.'training level'
order=List specifying the display order of categories.['high school', ...]
Box Plot

sns.boxplot() — Distribution + Outliers

A box plot (box-and-whisker plot) shows the distribution of a numeric variable using five statistics. It is ideal for comparing distributions across groups and spotting outliers.

Box Plot Anatomy — IQR, Quartiles & Whiskers
TermMeaningSalary example
Q1 (25th pct)25% of values fall below this point55,000
Q2 / Median (50th pct)The middle value — 50% below, 50% above75,000
Q3 (75th pct)75% of values fall below this point88,000
IQRInterquartile Range = Q3 − Q1 (the "box" width)33,000
WhiskersExtend to 1.5 × IQR beyond Q1 and Q35.5K to 137.5K
OutliersPoints beyond the whiskers — drawn as individual dotsSalaries > 137.5K
Python — salary box plot
plt.figure(figsize=(10, 4))

sns.boxplot(data=df, y='salary')
plt.show()
Output — sns.boxplot(data=df, y='salary')

To draw separate boxes per category, put the category on x= and the numeric values on y=:

Python — box plot by education level
sns.boxplot(
    data=df,
    x='level of education',
    y='salary'   # one box per education group
)
Box plot vs Histogram: A histogram shows the full shape of a distribution. A box plot compresses that shape into 5 numbers and makes it easy to compare many groups side-by-side.
