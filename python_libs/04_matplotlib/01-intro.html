Intro to Matplotlib

Matplotlib is Python's most popular 2D plotting library — create line charts, bar graphs, histograms, scatter plots, pie charts, and more with just a few lines of code.

matplotlib 2D Plotting Data Visualization pip install import matplotlib.pyplot as plt
What is Matplotlib?

Matplotlib — Python 2D Plotting Library

Matplotlib is an open-source plotting and visualization library for the Python programming language. It supports a wide range of graphs and plots including line plots, bar graphs, histograms, scatter plots, and more. Matplotlib is particularly good for creating static, interactive, and animated visualizations in Python.

Core idea: Matplotlib allows easy manipulation of visual attributes such as axis sizes, fonts, and color schemes. It is the foundation that many other visualization libraries (Seaborn, Pandas plotting) are built on top of.
Common Usages

What Matplotlib Is Used For

📊

Data Visualization

Create diverse multi-platform distributions of bar plots, pie charts, histograms, power spectra, line plots, error charts, and scatter plots. Matplotlib provides a matplot-based interface built on NumPy.

🖱️

Interactive Plotting

Produce procedural figure-making across various platforms. Matplotlib aims to recreate MATLAB's plotting capabilities with a syntax naturally suited to Python.

🎞️

Animated Visualizations

Create animations that update charts frame-by-frame, useful for showing data evolving over time or simulating movement.

🖼️

Static Reports

Save publication-quality figures to PNG, PDF, SVG, or JPEG using savefig() — ready to embed in presentations, papers, or dashboards.

Installation

Installing Matplotlib

Matplotlib is not part of the Python standard library. Install it once using pip from your computer's terminal or command prompt:

Terminal / CMD 
pip install matplotlib
Anaconda users: If you installed Python via Anaconda or Miniconda, matplotlib is already included. You can skip the pip install step.
Import

Importing Matplotlib

The standard convention is to import the pyplot sub-module and alias it as plt. This loads all matplotlib plotting functions into a short variable name.

Python 
import matplotlib.pyplot as plt
What this does: All matplotlib functions are now accessible via plt. — for example plt.plot(), plt.title(), plt.show(). By pressing plt. + TAB in Jupyter Notebook, you can browse every available function.

You will almost always also need NumPy to generate your data arrays:

Python 
import matplotlib.pyplot as plt
import numpy as np
