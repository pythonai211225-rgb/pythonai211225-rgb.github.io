Topic 02 — Basic Plots & Figure Object

Basic Plots & Figure Object

Learn the core matplotlib workflow — drawing a line chart, adding titles and labels, setting axis limits, saving plots, and using the Figure object for complex multi-chart layouts.

plt.plot() plt.figure() fig.add_axes() savefig() figsize
plt.plot()

Drawing a Line Chart

plt.plot(x, y) is the most fundamental matplotlib function. Pass two arrays — the first goes on the X axis, the second on the Y axis — and matplotlib draws a connected 2D line through all the points.

Function / DescriptionCode & Output
plt.plot(x, y)
Draws a 2D line chart. The first array argument maps to the X axis, the second maps to the Y axis. Matplotlib connects each (x, y) coordinate pair with a line.
import numpy as np import matplotlib.pyplot as plt x = np.arange(0, 10) # [0,1,2,...,9] y = 2 * x # [0,2,4,...,18] plt.plot(x, y)
Output chart
Plot Helpers

plt.show() · plt.title() · plt.xlabel() · plt.ylabel()

After calling plt.plot(), use these helper functions to label and display the chart. All calls must be in the same Jupyter cell so matplotlib knows they belong to the same figure.

Function / DescriptionCode & Output
plt.show()
Renders and displays the chart. Not needed in Jupyter Notebook (renders automatically), but required when running Python scripts in a terminal or IDE.
plt.plot(x, y) plt.show() # needed outside Jupyter
plt.title('text') plt.xlabel('text') plt.ylabel('text')
Add a title above the chart, and labels on the X and Y axes. Call them in the same cell as plt.plot().
plt.plot(x, y) plt.title('Example') plt.xlabel('X Data') plt.ylabel('Y Data')
Output chart
Rule: All plt.* configuration calls must be in the same Jupyter cell as plt.plot(). If you split them across cells, each cell starts a new figure.
Axis Limits

plt.xlim() & plt.ylim()

By default matplotlib calculates the axis range automatically to fit all data. Use these functions to manually specify a narrower or wider visible range.

Function / DescriptionCode & Output
plt.xlim(min, max) plt.ylim(min, max)
Set the visible range of the X and Y axes. Values outside this range are clipped. If not called, matplotlib auto-fits the range to the data.
plt.plot(x, y) plt.title('Example') plt.xlabel('X Data') plt.ylabel('Y Data') plt.xlim(0, 6) # show only x 0 → 6 plt.ylim(0, 15) # show only y 0 → 15
Output chart — notice X stops at 6, Y stops at 15
Save to File

plt.savefig()

plt.savefig() saves the current chart as an image file. It must be called in the same cell as the rest of the plot configuration, before plt.show().

Function / DescriptionCode & Output
plt.savefig('filename')
Saves the chart to the current working directory. The file extension determines the format — .png, .jpg, .svg, .pdf are all supported.
plt.plot(x, y) plt.title('Example') plt.xlabel('X Data') plt.ylabel('Y Data') plt.xlim(0, 6) plt.ylim(0, 15) plt.savefig('plot_example.jpg')
Result — image file saved to disk
Supported formats: Change the extension to switch format — .png (lossless), .jpg (compressed), .svg (vector), .pdf (vector, for papers).
Figure Object

plt.figure() — The Canvas

For complex layouts with multiple charts, use the Figure object. Think of it as an empty canvas that you can freely divide and place different charts into.

Function / DescriptionCode & Output
plt.figure()
Creates an empty canvas (Figure object) with the default size of 640 × 480 pixels. Save it to a variable (usually fig) so you can call its methods to add charts and set the layout.
fig = plt.figure() # fig is now an empty canvas ready for charts
The Figure — an empty canvas
When to use Figure: Use plt.figure() when you need multiple charts on the same canvas, need to control the exact size or layout, or want to save a complex multi-chart image.
add_axes()

fig.add_axes() — Placing a Chart on the Canvas

fig.add_axes([left, bottom, width, height]) adds a chart area at a specific position on the canvas. All four values are fractions from 0 to 1 relative to the total canvas size.

Parameter / DescriptionCode & Output
fig.add_axes([l, b, w, h])
left — how far from the left edge (0 = far left)
bottom — how far from the bottom (0 = bottom)
width — fraction of canvas width the chart takes
height — fraction of canvas height the chart takes

Example [0, 0, 0.5, 1]: starts at bottom-left, takes half the width and full height.
x = np.arange(0, 10) y = 2 * x fig = plt.figure() axes = fig.add_axes([0, 0, 0.5, 1]) # starts at (0,0), half width, full height axes.plot(x, y)
Output — chart occupies left half only (width=0.5)
Multiple Axes

Chart Inside a Chart — Zoom-In Layout

Call fig.add_axes() multiple times to layer charts on the same canvas. A common pattern is a large chart showing the full picture with a small inset showing a zoomed-in region.

Pattern / DescriptionCode & Output
Two axes on one canvas
axes_1 = [0, 0, 1, 1] → full canvas (the big chart)

axes_2 = [0.2, 0.5, 0.25, 0.25] → inset starting 20% from left, 50% from bottom, taking 25% width and 25% height
x = np.arange(0, 10) y = 2 * x # linear a = x b = a ** 4 # exponential fig = plt.figure() axes_1 = fig.add_axes([0, 0, 1, 1]) axes_1.plot(a, b) # big: exponential axes_2 = fig.add_axes([0.2, 0.5, 0.25, 0.25]) axes_2.plot(x, y) # inset: linear
Output — big exponential chart with small linear inset
Axes Labels on Figure

set_ Methods on Figure Axes

When using the Figure object, title, axis labels, and limits are set on the axes object using set_-prefixed methods instead of the plt.* functions.

plt. version → axes. versionCode & Output
axes.set_title('...') axes.set_xlabel('...') axes.set_ylabel('...') axes.set_xlim(a, b) axes.set_ylim(a, b)
Same purpose as the plt.* functions, but applied to a specific axes object inside a Figure. Necessary when you have multiple axes and want to configure each independently.
fig = plt.figure() axes_1 = fig.add_axes([0, 0, 1, 1]) axes_1.set_xlim(0, 8) axes_1.set_ylim(0, 8000) axes_1.set_xlabel('A') axes_1.set_ylabel('B') axes_1.set_title('Power Of 4') axes_1.plot(a, b) axes_2 = fig.add_axes([0.2, 0.5, 0.25, 0.25]) axes_2.set_xlim(1, 2) axes_2.set_ylim(0, 50) axes_2.set_title('Zoomed In') axes_2.plot(x, y)
Output — "Power Of 4" chart with labelled axes + zoomed inset
Canvas Size & Save

figsize & fig.savefig()

Control the physical size of the canvas with figsize and save the complete figure (including all axes) with fig.savefig(). Use bbox_inches='tight' to prevent labels from being cut off.

Parameter / DescriptionCode & Output
plt.figure(figsize=(w, h))
Sets the canvas size in inches. The saved image file will match this size. A wide canvas like (10, 3) produces a landscape image; (6, 6) produces a square one.
# wide canvas: 10 inches wide, 3 tall fig = plt.figure(figsize=(10, 3))
Wide canvas vs. default canvas
fig.savefig('file.jpg', bbox_inches='tight')
Saves the full figure to a file. Without bbox_inches='tight' the saved image may clip axis labels that extend past the default bounding box. Always use 'tight' when labels are present.
fig = plt.figure(figsize=(10, 3)) axes = fig.add_axes([0, 0, 1, 1]) axes.plot(x, y) # save — bbox_inches keeps labels from clipping fig.savefig('example_fig.jpg', bbox_inches='tight')
Without vs. with bbox_inches='tight'
