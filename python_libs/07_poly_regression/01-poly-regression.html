Polynomial Regression 01 / 07 · The Motivation
When a line fails
Some data curves — and no straight line can chase it
data curves ⟶ line = bad fit R² = 0.285 → we need a curve

An athlete's running time vs their weekly training hours. Train too little and you're slow; train too much and over-training makes you slow again. The pattern dips down and comes back up — a U-shape. Fit a straight LinearRegression and it can't win: to stay near the low middle it must miss both raised ends.

python — a line on curved data
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

training_hours = np.array([2, 3, 5, 7, 9, 12, 16, 20, 25, 30]).reshape(-1, 1)
running_times  = np.array([95, 85, 70, 65, 60, 55, 50, 53, 58, 70])

model = LinearRegression()
model.fit(training_hours, running_times)
y_pred = model.predict(training_hours)

print(f"MSE: {mean_squared_error(running_times, y_pred):.7f}")   # 134.4338762
print(f"R²:  {r2_score(running_times, y_pred):.7f}")            # 0.2852683
The straight line fights the curve — and loses
⚠️ R² = 0.285 is a failing grade — the line explains only 29% of the variance. Nothing is broken in sklearn; we simply asked a straight tool to draw a bent shape.
💡 The fix: give the model higher powers of x — x², x³, … — so the fitted shape can bend. That is polynomial regression, and the rest of this deck builds it.
Polynomial Regression 02 / 07 · The Vocabulary
Degrees
The highest power decides how many times the curve can bend
y = aₙxⁿ + … + a₁x + a₀ degree degree — nThe highest power of x that appears. Degree 2 → one bend, degree 3 → two bends, and so on. → the shape

A polynomial raises x to whole-number powers and adds the pieces up. The degree — the highest power present — controls the shape: a degree-n curve can bend up to n − 1 times.

$$y = a_n x^n + \dots + a_2 x^2 + a_1 x + a_0$$
NameHighest powerShapeBends
Linearx¹A straight line0
Quadraticx²A parabola (U or ∩)1
Cubicx³An S-curve2
Quarticx⁴A W / M shape3
The same four degrees, drawn — watch the bends multiply
🧠 Etymology: quadratic is from the Latin quadratus = "square" (x is squared), and cubic from cubus = "cube" (x is cubed). A quartic is the polynomial whose highest power is really 4.
Polynomial Regression 03 / 07 · The Shape
Plot a quadratic
Draw the one-bend curve before you fit one
y = a·x² + b·x + c a a — curvatureMultiplies x². Its sign flips the parabola: a > 0 opens up (a valley), a < 0 opens down (a hill). Bigger |a| → tighter curve. b b — tiltMultiplies x. It slides the vertex left/right and tilts the curve. c c — interceptThe constant. It is exactly where the curve crosses the y-axis (the value of y when x = 0).

The quadratic is the simplest curve — one bend. Choose the three coefficients, sweep x with np.linspace, and let NumPy compute every y at once:

python — draw y = x² − 3x + 2
import numpy as np
import matplotlib.pyplot as plt

# Coefficients
a, b, c = 1.0, -3.0, 2.0              # y = x² - 3x + 2
x = np.linspace(-10, 10, 400)
y = a * x**2 + b * x + c              # vectorised: 400 y-values at once

plt.figure()
plt.plot(x, y)
plt.axhline(0, linewidth=1)
plt.axvline(0, linewidth=1)
plt.xlabel('x'); plt.ylabel('y')
plt.title('y = x² - 3x + 2')
plt.grid(True, which='both', linestyle='--', alpha=0.3)
plt.show()

Polynomial Regression 04 / 07 · The sklearn Way
PolynomialFeatures
Add x², x³ columns — then it's just LinearRegression
from sklearn.preprocessing import PolynomialFeatures degree degree=2How many powers to generate. degree=2 turns one column x into [1, x, x²]. fit_transform fit_transform(X)Builds the expanded feature table — the extra x², x³ columns — from your original X. → back to LinearRegression

The key insight: polynomial regression is still linear regression — just on new columns. If we hand the model x² as an extra feature, then ŷ = β₀ + β₁x + β₂x² is linear in its weights. PolynomialFeatures builds those extra columns for us:

Live Demo ① — ONE feature: pick a degree and watch one column x expand into its powers
2

With more than one feature it also adds the interaction terms. Two features x₁, x₂ at degree 2 become [1, x₁, x₂, x₁², x₁x₂, x₂²] — the model gets each feature's square and the product x₁x₂, which lets it learn how the features work together. Slide the count from 1 to 3 and watch the columns multiply:

python — PolynomialFeatures + LinearRegression
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

x = np.array([2, 3, 5, 7, 9, 12, 16, 20, 25, 30]).reshape(-1, 1)
y = np.array([95, 85, 70, 65, 60, 55, 50, 53, 58, 70])

# 1. build the x² (and x⁰, x¹) columns
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(x)         # each row → [1, x, x²]

# 2. ordinary LinearRegression on the expanded columns
model = LinearRegression()
model.fit(X_poly, y)

y_pred = model.predict(X_poly)
print('R² =', r2_score(y, y_pred))   # 0.9510 — identical to polyfit

# predict a NEW x — transform it the same way first
print(model.predict(poly.transform([[18]])))   # [48.88]
ApproachBest forNote
PolynomialFeaturesThe ML pipelinePlugs into sklearn — cross-validation, multiple features, scaling
np.polyfitQuick, one featureReturns coefficients directly — great for plotting
🧠 Big idea: "polynomial regression" is not a new algorithm — it's linear regression on engineered features. Add the right columns and the same fit / predict / coef_ you already know draws curves. That is why PolynomialFeatures + LinearRegression can match np.polyfit on a one-variable curve.
⚠️ Transform new data too. Before predicting a fresh x you must run it through the same poly.transform(...) — the model expects the [1, x, x²] shape, not a bare number.
Polynomial Regression 05 / 07 · NumPy's Built-in Fit
np.polyfit
NumPy finds the best-fit curve for you — no sklearn needed
coeffs = np.polyfit(x, y, deg) brand-new function → the curve's coefficients
🥇
np.polyfit works for ONE feature only
It fits a curve in a single input variable x → y:  one column in, one column out
If your data has several features (area, rooms, age, …), polyfit cannot do it
For many features use PolynomialFeatures + LinearRegression
instead Remember this: polyfit = one feature

Here is the new tool. Until now, finding the best line meant calling LinearRegression. But NumPy ships its own one-function way to fit a curve: np.polyfit. You hand it your points and the degree you want, and it hands back the coefficients of the best-fitting polynomial. That is the entire idea — one line, no model object, no fit / predict.

"Best-fit" means the same thing it did for the line: NumPy chooses the coefficients that make the curve pass as close as possible to all the points (it minimises the squared errors — least squares). The only new knob is deg, which tells it how bendy the curve is allowed to be.

$$\texttt{np.polyfit}(x,\; y,\; \underbrace{\texttt{deg}}_{\text{how bendy}}) \;\longrightarrow\; [\,a_n,\; \dots,\; a_1,\; a_0\,]$$

Read the three inputs one at a time — nothing here is hidden:

ArgumentWhat you passMeaning
xa 1-D array of inputsThe feature — e.g. training hours. Just a flat list, no reshape needed
ya 1-D array of outputsThe target — e.g. running times. Same length as x
dega whole numberThe degree: 1 = line, 2 = parabola, 3 = cubic. This is the new choice you make

What comes back is a plain NumPy array of numbers — the coefficients, listed highest power first. Ask for degree 2 and you get three numbers, which are exactly the a, b, c in y = a·x² + b·x + c:

$$\texttt{np.polyfit}(x, y, 2) = [\,\underbrace{0.159}_{a},\; \underbrace{-5.712}_{b},\; \underbrace{100.05}_{c}\,] \;\Rightarrow \\[6pt] y = 0.159x^2 - 5.712x + 100.05$$

How to actually use those numbers. You could plug them into the formula by hand, but NumPy gives you a helper: np.poly1d(coeffs) turns the coefficient array into a ready-made curve you can call like a function. Feed it any x and it returns the predicted y:

python — np.polyfit from zero, step by step
import numpy as np
from sklearn.metrics import r2_score

# 1. the data — plain 1-D arrays, same length
x = np.array([2, 3, 5, 7, 9, 12, 16, 20, 25, 30])       # training hours
y = np.array([95, 85, 70, 65, 60, 55, 50, 53, 58, 70])   # running times

# 2. FIT: ask NumPy for the best degree-2 curve
coeffs = np.polyfit(x, y, 2)      # → array([  0.1594,  -5.7118, 100.0485])
print(coeffs)                        # [a, b, c], highest power first

# 3. BUILD the curve you can call like a function
p = np.poly1d(coeffs)          # p(x) = 0.1594 x² - 5.7118 x + 100.05
print(p)                             # NumPy even prints it as a nice equation

# 4. PREDICT — just call p( ) with any x, old or new
print(p(18))                       # 48.88   → a runner training 18 h
y_pred = p(x)                       # predictions for every original x

# 5. SCORE it, exactly like before
print('R² =', r2_score(y, y_pred))   # 0.9510  — the curve fits well!
  1. polyfit fitsnp.polyfit(x, y, deg) returns the coefficients of the best curve of that degree.
  2. poly1d buildsp = np.poly1d(coeffs) turns those numbers into a curve p you can call.
  3. p(x) predictsp(18) gives one prediction; p(x) gives one for every point. No powers typed by hand.
The curve np.polyfit found — the parabola that beats the line

Change one number — the deg — and you get a different curve. Here is the same data fitted at three degrees:

CallDegreeR²Verdict
np.polyfit(x, y, 1)10.285Underfit — a line can't bend
np.polyfit(x, y, 2)20.951Great — one bend matches the U
np.polyfit(x, y, 3)30.979A hair better, but is it worth it?
⚠️ Watch the order: polyfit lists coefficients highest power first. For degree 2 that is [a, b, c] in y = a·x² + b·x + c — the constant c is last, not first.
💡 The whole recipe in three words: polyfit → poly1d → call it. Fit the curve, wrap the coefficients, then use p(x) to predict. That's polynomial regression with nothing but NumPy.
Polynomial Regression 06 / 07 · The Trade-off
Choosing degree
Too low underfits, too high overfits — find the Goldilocks degree
degree too low → underfit degree too high → overfit → just right

A higher degree can always squeeze training R² closer to 1 — but past a point it stops learning the pattern and starts memorising the noise. That's overfitting: brilliant on the training points, wild everywhere between them.

The same 10 points at three degrees — slide to compare

DegreeTraining R²Diagnosis
1 (line)0.285Underfit — too simple, misses the curve

🔎 How to choose in practice: don't trust training R² alone — it only ever goes up. Use a train/test split (Lesson 12 / Deck 06) and pick the degree with the best score on the test set. Prefer the simplest degree that does well — usually 2 or 3.
⚠️ The overfitting echo: raising the degree is exactly like adding features. Training R² climbs toward 1, but the model gets worse on new data — the very trap Adjusted R² and the test set were built to catch.
