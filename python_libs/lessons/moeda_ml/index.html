02 How To Show Your Work — Worked Demo

Formula

Average (mean)$$\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}$$ Sum every value, then divide by how many values there are.

Demo Question

Calculate the average of the numbers \(2,\; 4,\; 6,\; 8\).

✓ Correct way — the calculation is shown

Sum the numbers, then divide by how many there are:

$$\text{sum} = 2 + 4 + 6 + 8 = 20 \qquad n = 4 \qquad \bar{x} = \frac{20}{4} = \mathbf{5}$$

Or the same arithmetic, written as code you build yourself:

numbers = [2, 4, 6, 8]
total = sum(numbers)      # 20
n = len(numbers)          # 4
average = total / n       # 5

✗ Wrong way — don't just call a function that does it all for you

The number comes out right, but this shows no work — the exam wants to see how you got to 5, not just the finished value from a library call:

import statistics
average = statistics.mean([2, 4, 6, 8])   # 5 — but no calculation shown

03 Scaling: Min-Max & Standard

Formulas

Min-max normalisation — MinMaxScaler$$x_{norm} = \frac{x - \min(x)}{\max(x) - \min(x)}$$ Squeezes the column into \([0, 1]\). The min becomes 0 and the max becomes 1.
Standardisation — StandardScaler$$z = \frac{x - \bar{x}}{Std}$$ Re-centres the column on mean 0 with a standard deviation of 1.

04 Linear Regression

Formulas

The line$$\hat{y} = \beta_0 + \beta_1 x$$
Residual$$e_i = y_i - \hat{y}_i$$
MSE / RMSE$$\text{MSE} = \frac{1}{n}\sum (y_i - \hat{y}_i)^2 \qquad \text{RMSE} = \sqrt{\text{MSE}}$$
SSE and SST$$SSE = \sum (y_i - \hat{y}_i)^2 \qquad SST = \sum (y_i - \bar{y})^2$$
R squared$$R^2 = 1 - \frac{SSE}{SST}$$ \(R^2 = 1\) perfect · \(R^2 = 0\) no better than predicting \(\bar{y}\).

05 Polynomial Regression

Formulas

Degree 3 (cubic)$$\hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3$$
Scored identically to a straight line$$SSE = \sum (y_i - \hat{y}_i)^2 \qquad R^2 = 1 - \frac{SSE}{SST}$$
Adjusted R² — R² with a fee per predictor$$R^2_{adj} = 1 - \left[\frac{(1 - R^2)(n - 1)}{n - p - 1}\right]$$ \(n\) = rows, \(p\) = predictors (here \(x\), \(x^2\), \(x^3\), so \(p = 3\)).

06 Logistic Regression

Formulas

Sigmoid$$P(Y=1 \mid X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$$
Decision rule$$\hat{y} = \begin{cases} 1 & P \ge \text{threshold} \\ 0 & P < \text{threshold} \end{cases}$$
The 50% point (decision boundary)$$x_{50\%} = -\frac{\beta_0}{\beta_1}$$ Because \(P = 0.5\) exactly when \(\beta_0 + \beta_1 x = 0\).
The \(x\) for any probability \(p\)$$x_{(p)} = \frac{\ln\!\left(\frac{p}{1-p}\right) - \beta_0}{\beta_1}$$ \(\frac{p}{1-p}\) is the odds; \(\ln\!\left(\frac{p}{1-p}\right)\) is the log-odds.

07 Classification Metrics

Formulas

Accuracy$$\frac{TP + TN}{TP + TN + FP + FN}$$
Precision — of those I flagged, how many were right$$\frac{TP}{TP + FP}$$
Recall — of those that were real, how many did I catch$$\frac{TP}{TP + FN}$$
Specificity$$\frac{TN}{TN + FP}$$
F1 — one number for both$$F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$ The harmonic mean: it collapses toward the worse of the two.

08 K-Nearest Neighbours

Formulas

Euclidean distance$$d(p,q) = \sqrt{\sum_{i=1}^{n}(p_i - q_i)^2}$$
Two features, written out$$d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$
Min-max normalisation$$x_{norm} = \frac{x - \min(x)}{\max(x) - \min(x)}$$ Scale before measuring any distance, so no column can shout louder than another.

09 Support Vector Machines

Formulas

The hyperplane$$w^{T}x + b = 0$$ written out feature by feature: \(w_1x_1 + w_2x_2 + \dots + w_nx_n + b = 0\)
Signed distance — which side, and how far$$\text{SignedDistance}(x) = \frac{w \cdot x + b}{\lVert w \rVert}$$ where \(\lVert w \rVert = \sqrt{w_1^2 + w_2^2 + \dots + w_n^2}\).
Absolute distance$$\text{Distance}(x) = \frac{|\,w \cdot x + b\,|}{\lVert w \rVert}$$
Margin width$$\text{margin} = \frac{2}{\lVert w \rVert}$$ Bigger \(\lVert w \rVert\) → narrower street. SVM maximises this width.

10 Decision Trees

Formulas

Gini impurity of a node$$G(Q) = 1 - \sum_c p_c^{\,2}$$
Weighted impurity of a level$$G_{\text{split}} = \frac{n_L}{n}G(\text{left}) + \frac{n_R}{n}G(\text{right})$$
Gain$$\text{Gain} = G(\text{parent}) - G_{\text{split}}$$ The tree tries every feature at every threshold and keeps the largest gain.
Regression: impurity is MSE$$\text{MSE}(Q) = \frac{1}{n}\sum_{i \in Q}(y_i - \bar{y}_Q)^2$$
Regression: weighted MSE and its gain$$\text{MSE}_{\text{split}} = \frac{n_L}{n}\text{MSE}(L) + \frac{n_R}{n}\text{MSE}(R)$$ $$\text{Gain} = \text{MSE}(\text{parent}) - \text{MSE}_{\text{split}}$$

11 PCA

Formulas

Variance of one column$$s^2 = \frac{\sum (x - \bar{x})^2}{n}$$ Do it for every column and add them up to get the total variance.
Projecting one row onto a component$$\text{projection} = x_1w_1 + x_2w_2 + \dots + x_pw_p$$ Do all \(n\) rows and you have the component's new column — then take its variance.
Explained variance ratio$$\text{ratio} = \frac{\text{variance of that component}}{\text{total variance}}$$
A legal component$$w_1^2 + w_2^2 + \dots + w_p^2 = 1 \qquad u \cdot v = 0$$ Weights squared add to 1, and every pair of components is orthogonal.
