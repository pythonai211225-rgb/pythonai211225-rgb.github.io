MSE by hand

Mean squared error compares real labels to predicted labels. For each point, subtract prediction from the real value, square the error, then average all squared errors.

MSE = 1 n ∑(yi - ŷi)2

y is the real value, ŷ is the predicted value, and n is the number of points.

Observed labels Y = [2, 4, 8, 20]
Predictions Y_pred = [2, 5, 10, 25]
MSE MSE = (2 - 2)2 + (4 - 5)2 + (8 - 10)2 + (20 - 25)2 4 = 0 + 1 + 4 + 25 4 = 7.5 
Y = np.array([2, 4, 8, 20])
Y_pred = np.array([2, 5, 10, 25])

mse = ((Y_pred - Y) ** 2).sum() / len(Y)
print(mse)

Compare two candidate lines

The class plotted observed points and tested two possible regression lines. The line with the lower MSE fits the data better.

First, create x-values for the graph. These values are only used to draw smooth lines across the plot.

x = np.arange(0, 9)

Now define the real observations. These are the actual points the regression line should fit.

x_obs = np.array([1, 2, 3, 4])
y_obs = np.array([2, 2, 7, 8])

Draw the observed points as a scatter plot. These red points are the data, not predictions.

plt.scatter(x_obs, y_obs, color='red')

Test the first candidate line: y = 2x - 0.5. We draw it on the graph, then use the same equation to predict y-values for the observed x-values.

plt.plot(x, 2*x - 0.5, label="y = 2x - 0.5")

y_pred_1 = 2*x_obs - 0.5

Calculate the MSE for the first candidate line. This tells us how far the predicted values are from the real observed values.

mse_1 = ((y_pred_1 - y_obs) ** 2).sum() / len(x_obs)

Then test the second candidate line: y = 2.3x - 1. It is the same process: draw the line, predict values, and calculate MSE.

plt.plot(x, 2.3*x - 1, color='pink', label="y = 2.3x - 1")

y_pred_2 = 2.3*x_obs - 1
mse_2 = ((y_pred_2 - y_obs) ** 2).sum() / len(x_obs)

Finally, compare the two MSE values. The smaller MSE belongs to the better line for this data.

print(mse_1)
print(mse_2)

In this example, the second line has the smaller error, so it fits the observed points better.

Lower MSE means a better fit

Scikit-learn fit

After calculating candidate lines manually, the class used LinearRegression to let scikit-learn learn the best slope and intercept.

First, import the model class and the error function from scikit-learn.

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

Next, prepare the observed data. In scikit-learn, the feature data must be a two-dimensional table, so one feature still needs reshape(-1, 1).

x_obs = np.array([1, 2, 3, 4]).reshape(-1, 1)
y_obs = np.array([2, 2, 7, 8])

Create the regression model and train it with fit(). This is the step where scikit-learn finds the best slope and intercept.

model = LinearRegression()
model.fit(x_obs, y_obs)

After training, read the learned equation. coef_ is the slope, and intercept_ is the value where the line crosses the y-axis.

a = round(model.coef_[0], 2)
b = round(model.intercept_)

Use the learned line to predict y-values, then compare those predictions to the real labels with MSE.

y_pred = a*x_obs + b
mse = mean_squared_error(y_obs, y_pred)

Finally, draw the learned line and the original points on the same graph.

x = np.arange(0, 9)

plt.plot(x, a*x + b, label=f"y = {a}x + {b}")
plt.scatter(x_obs, y_obs, color='red', zorder=5)
plt.grid(color='gray', linestyle='--', linewidth=0.5)
plt.legend()

Scikit-learn learned line: y = 2.3x - 1

Regression with two features

Linear regression can use more than one feature. Instead of one x column, the model receives a table with x1 and x2.

First, import the regression model and MSE helper. This is the same model as before, but now it will receive two feature columns.

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

Prepare the two features and the real labels. Here, each observation has both x1 and x2, and the model uses both values to predict y.

x1_obs = np.array([1, 2, 3, 4, 5])
x2_obs = np.array([2, 1, 4, 3, 5])
y_obs = np.array([5, 6, 11, 11, 15])

Scikit-learn needs one feature table. We combine the two separate arrays into a table where every row is one observation.

X_table_obs = np.column_stack((x1_obs, x2_obs))

Now train the model. Because the table has two columns, the model learns two weights: one for x1 and one for x2.

model = LinearRegression()
model.fit(X_table_obs, y_obs)

Read the learned equation. For two features, the equation is y = w1*x1 + w2*x2 + b.

w1, w2 = model.coef_
b = model.intercept_

print(f"Model Equation: y = {w1:.2f}*x1 + {w2:.2f}*x2 + {b:.2f}")

Finally, predict values with the trained model and calculate the MSE against the real labels.

y_pred = model.predict(X_table_obs)
mse = mean_squared_error(y_obs, y_pred)

print(f"mse= {mse:.2f}")
