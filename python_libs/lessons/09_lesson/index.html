Line Equations

A linear function creates a straight line. The class used the formula y = 0.8x - 2, generated x-values with NumPy, calculated y-values, and plotted the result with Matplotlib.

import numpy as np import pandas as pd from IPython.display import display import matplotlib.pyplot as plt import seaborn as sns def linear_function(x): y = 0.8 * x - 2 return y x_values = np.linspace(-15, 35, 20) y_values = linear_function(x_values) plt.axhline(0, color="black", linewidth=0.8, linestyle="--") plt.axvline(0, color="black", linewidth=0.8, linestyle="--") plt.plot(x_values, y_values, color="green") plt.title("y = 0.8x - 2") plt.xlim(-10, 20) plt.ylim(-20, 20) plt.grid(color="gray", linestyle="--", linewidth=0.5) plt.show()

Graph Idea: y = 0.8x - 2

A line equation has slope and intercept. In y = 0.8x - 2, the slope is 0.8 and the y-intercept is -2.

Solve the Intersection with SymPy

Instead of calculating the point by hand, SymPy can solve where two expressions are equal. The x solution is then substituted into either line to calculate y.

from sympy import symbols, Eq, solve x = symbols("x") eq1 = -x + 5 eq2 = 2 * x - 1 solution = solve(Eq(eq1, eq2), x) x_junc = float(solution[0]) y_junc = -1 * x_junc + 5 plt.scatter(x_junc, y_junc, color="blue", zorder=5) plt.annotate( f"({x_junc}, {y_junc})", (x_junc, y_junc), xytext=(x_junc - 1, y_junc + 6), fontsize=10, color="blue" )
solution = [2] x_junc = 2.0 y_junc = 3.0
Use Eq(left_side, right_side) when you want SymPy to solve the equality between two formulas.

Systems of Equations

SymPy can also solve more than one unknown. The class bonus used three variables and three equations.

from sympy import symbols, Eq, solve x = symbols("x") y = symbols("y") z = symbols("z") eq1 = Eq(x + y + z, 6) eq2 = Eq(2 * x - y + z, 3) eq3 = Eq(x + 2 * y - z, 2) solution = solve((eq1, eq2, eq3), (x, y, z)) print(f"The solution is: {solution}")
The solution is: {x: 1, y: 2, z: 3}
Parallel lines such as y = 2x + 5 and y = 2x + 7 have the same slope, so they never meet.

Features and Labels

Linear regression starts with examples. X stores the feature values we know, and Y stores the label values we want the model to learn.

X = np.array([1, 2, 3, 4]) # Features Y = np.array([1, 2, 3, 4]) # Labels """ X Y 1 1 2 2 3 3 4 4 7 ? 12 ? """ plt.scatter(X, Y, zorder=5, s=200)

Graph Idea: Four Feature/Label Points

The model sees pairs like 1 -> 1, 2 -> 2, and so on. Later it should predict labels for new feature values such as 7 or 12.

Mean Squared Error

To know if a line is good, compare the real y-values to the y-values predicted by the line. Square each error, then calculate the mean.

Short NumPy version
mse = ((Y - (a * X + b)) ** 2).mean()

Graph Idea: Error is the Distance from Point to Line

Squaring makes every error positive and punishes large mistakes more strongly.

Search for the Best Line

The class tested many possible lines. Each line is described by a and b in the formula y = ax + b. The best line is the one with the lowest MSE.

ab = [] mse_arr = [] for a in np.arange(-5, +5, 1): for b in np.arange(-5, +5, 1): ab.append((a, b)) mse = ((Y - (a * X + b)) ** 2).mean() mse_arr.append(mse) mse_np = np.array(mse_arr) print("lowest mse", mse_np.min()) print("index lowest = ", mse_np.argmin()) print("a =", ab[mse_np.argmin()][0], "b =", ab[mse_np.argmin()][1]) a, b = ab[mse_np.argmin()] plt.plot( np.arange(X[0] - 1, X[len(X) - 1] + 1), a * np.arange(0, 4 + 1) + b, color="red" ) plt.title("Linear Regression BF") plt.grid(color="gray", linestyle="--", linewidth=0.5) plt.show()
