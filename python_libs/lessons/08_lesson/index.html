Setup & Arrays

Matplotlib works very well with NumPy arrays. The usual import is matplotlib.pyplot as plt.

import numpy as np import pandas as pd from IPython.display import display import matplotlib.pyplot as plt

The class started by comparing a regular Python loop with NumPy vectorized math.

# Create numbers from 0 to 9 x = np.arange(0, 9 + 1) # Create an empty list for the loop result y2 = [] # Go over every number inside x for num in x: # Calculate 2*num + 1 and add it to the list y2.append(num * 2 + 1) # Print the list created by the loop print(y2) # Use NumPy to calculate 2*x + 1 for every x value y = x * 2 + 1 # Print the x array print(x) # Print the y array print(y)

Most Matplotlib examples use one array for the x-axis and one array for the y-axis. The two arrays should usually have the same length.

First Line Plot

plt.plot(x, y) draws a line chart. Then use title, labels, legend, limits, save, and show to finish the chart.

# Draw the first line using x and y plt.plot(x, y) # Create a second y array slightly above the first line y1 = y + 0.5 # Draw the second line on the same chart plt.plot(x, y1) plt.title("Hours vs Production") # Add the chart title plt.xlabel("Hours") # Add the x-axis label plt.ylabel("Production") # Add the y-axis label plt.legend(["Production", "Product + 0.5"]) # Add a legend for the two lines plt.xlim(0, 6) # Show only x values from 0 to 6 plt.ylim(0, 12.5) # Show only y values from 0 to 12.5 plt.savefig("line_chart1.jpg") # Save the chart as an image file plt.show() # Display the chart

Graph Output: Hours vs Production

Use plt.show() at the end of the cell when you want Jupyter to display the finished chart cleanly.

Figure and Axes

plt.figure() creates the canvas. fig.add_axes([left, bottom, width, height]) manually places a chart inside that canvas.

# Create a new 6.4 x 4.8 inch figure fig = plt.figure(figsize=(6.4, 4.8)) # Add the main axes using the full figure area axes1 = fig.add_axes([0, 0, 1, 1]) x = np.arange(0, 10) # Create x values from 0 to 9 y = 2 * x # Create y values by doubling x # Limit the main chart x-axis from 0 to 6 axes1.set_xlim(0, 6) # Limit the main chart y-axis from 0 to 12.5 axes1.set_ylim(0, 12.5) # Add the x-axis label to the main chart axes1.set_xlabel("Hours") # Add the y-axis label to the main chart axes1.set_ylabel("Production") axes1.set_title("Graph 1") # Add the main chart title axes1.plot(x, y) # Draw the main line chart # Add a smaller inset chart inside the figure axes2 = fig.add_axes([0.2, 0.5, 0.25, 0.3]) a = np.arange(0, 10) # Create a values from 0 to 9 # Create b values by raising a to the fourth power b = a ** 4 axes2.set_title("Zoomed In [Graph 2]") # Add the inset chart title axes2.plot(a, b) # Draw the inset line chart # Add another axes to the right of the main figure axes3 = fig.add_axes([1.2, 0, 1, 1]) axes3.set_title("Graph 3") # Add the third chart title axes3.plot(a, b) # Draw the third line chart # Display the figure with all axes plt.show()

Graph Output: Manual Figure Axes

Manual axes can overlap or go outside the figure. That is useful for custom layouts, but for regular grids plt.subplots() is easier.

Subplots

plt.subplots() creates a table of charts. For one row and two columns, the axes are accessed with ax[0] and ax[1].

# Create x values from 0 to 4.9 x = np.arange(0, 5, 0.1) # Calculate sine values for every x y_sin = np.sin(x) # Calculate cosine values for every x y_cos = np.cos(x) # Create one row with two charts fig, ax = plt.subplots(nrows=1, ncols=2, figsize=(12, 4)) # Draw sine on the first chart ax[0].plot(x, y_sin, label="sin(x)", color="blue") # Add the first chart title ax[0].set_title("Sine Function") # Add the first chart x-axis label ax[0].set_xlabel("X Values") # Add the first chart y-axis label ax[0].set_ylabel("sin(x)") # Show the first chart legend ax[0].legend() # Turn on the first chart grid ax[0].grid(True) # Draw cosine on the second chart ax[1].plot(x, y_cos, label="cos(x)", color="red") # Add the second chart title ax[1].set_title("Cosine Function") # Add the second chart x-axis label ax[1].set_xlabel("X Values") # Add the second chart y-axis label ax[1].set_ylabel("cos(x)") # Show the second chart legend ax[1].legend() # Turn on the second chart grid ax[1].grid(True) # Fix spacing between the two charts plt.tight_layout() # Save the figure as an image plt.savefig("line_chart2.jpg") # Display the figure plt.show()

Graph Output: 1 x 2 Subplots

Use plt.tight_layout() when labels or titles are too close to each other.

2x2 Subplot Grid

For two rows and two columns, the axes behave like a table: ax[0, 0], ax[0, 1], ax[1, 0], and ax[1, 1].

# Create x values from 0 to 4.9 x = np.arange(0, 5, 0.1) y_sin = np.sin(x) # Calculate sine values y_cos = np.cos(x) # Calculate cosine values y_tan = np.tan(x) # Calculate tangent values # Calculate exponential values y_exp = np.exp(x) # Create a 2 row by 2 column chart grid fig, ax = plt.subplots(2, 2, figsize=(10, 8)) # Draw sine in row 0, column 0 ax[0, 0].plot(x, y_sin, label="sin(x)", color="blue") # Add the sine chart title ax[0, 0].set_title("Sine Function") # Show the sine chart legend ax[0, 0].legend() # Turn on the sine chart grid ax[0, 0].grid(True) # Draw cosine in row 0, column 1 ax[0, 1].plot(x, y_cos, label="cos(x)", color="red") # Add the cosine chart title ax[0, 1].set_title("Cosine Function") # Show the cosine chart legend ax[0, 1].legend() # Turn on the cosine chart grid ax[0, 1].grid(True) # Draw tangent in row 1, column 0 ax[1, 0].plot(x, y_tan, label="tan(x)", color="green") # Add the tangent chart title ax[1, 0].set_title("Tangent Function") # Show the tangent chart legend ax[1, 0].legend() # Turn on the tangent chart grid ax[1, 0].grid(True) # Draw exponent in row 1, column 1 ax[1, 1].plot(x, y_exp, label="exp(x)", color="purple") # Add the exponent chart title ax[1, 1].set_title("Exponential Function") # Show the exponent chart legend ax[1, 1].legend() # Turn on the exponent chart grid ax[1, 1].grid(True) # Fix spacing between all four charts plt.tight_layout() # Display the full 2x2 figure plt.show()

Graph Output: 2 x 2 Subplot Grid

When tan(x) becomes very large, the plot can stretch the y-axis. In real work, limit the y-axis or choose a smaller x range.

Style Lines

Matplotlib lines can be styled with color, line width, line style, markers, marker size, grid, and legend.

# Create a new empty figure fig = plt.figure() # Add one axes that fills the whole figure ax = fig.add_axes([0, 0, 1, 1]) ax.set_title("custom chart") # Add a title to the axes x = np.arange(0, 11) # Create x values from 0 to 10 ax.plot( # Start drawing a styled line x, # Use x for the horizontal axis x + 1, # Use x + 1 for the vertical axis marker="p", # Use pentagon markers on the line lw=2, # Set the line width to 2 ls="--", # Use a dashed line style color="#e39802" # Set the line color with a hex color ) # Finish the plot command plt.show() # Display the styled chart

Graph Output: Custom Styled Line

Two styled waves
# Create 100 x values from 0 to 10 x = np.linspace(0, 10, 100) y = np.sin(x) # Calculate sine values y2 = np.cos(x) # Calculate cosine values # Create one chart with a custom size fig, ax = plt.subplots(figsize=(8, 6)) ax.plot( # Draw the styled sine wave x, # Use x for the horizontal axis # Use sine values for the vertical axis y, label="Sine Wave", # Set the legend label color="#1FEBDD", # Set the line color lw=2, # Set the line width ls="--", # Use a dashed line style marker="o", # Add circle markers markersize=6 # Set marker size ) ax.plot( # Draw the styled cosine wave x, # Use x for the horizontal axis # Use cosine values for the vertical axis y2, label="Cosine Wave", # Set the legend label color="red", # Set the line color lw=3, # Set the line width linestyle="-", # Use a solid line style marker="x", # Add x markers markersize=8 # Set marker size ) ax.set_title("Customized Chart", fontsize=14) # Add a title with font size 14 # Add an x-axis label with font size 12 ax.set_xlabel("X-axis", fontsize=12) # Add a y-axis label with font size 12 ax.set_ylabel("Y-axis", fontsize=12) ax.legend() # Show the legend ax.grid(True) # Show grid lines plt.tight_layout() # Fix spacing plt.show() # Display the chart

Graph Output: Customized Chart

Bar Charts

Bar charts compare categories. The class practiced regular bars, stacked bars, and grouped bars.

Regular bar chart
# Create the category names movies = ["Sci-Fi", "Comedy", "Action", "Drama"] # Create the value for each category votes = [45, 25, 60, 15] # Create one color for each bar bar_colors = ["skyblue", "gold", "lightgreen", "tomato"] plt.bar( # Draw the bar chart # Use movie genres on the x-axis movies, # Use vote counts as bar heights votes, color=bar_colors, # Apply the custom colors edgecolor="black" # Add black bar borders ) plt.ylabel("Number of Votes") # Add the y-axis label plt.title("Favorite Movie Genres") # Add the chart title plt.tight_layout() # Fix spacing around labels plt.show() # Display the chart

Graph Output: Favorite Movie Genres

Stacked bars
# Create the game names games = ["Game A", "Game B", "Game C"] # Create the bottom part of each bar digital_sales = [40, 55, 30] # Create the top part of each bar physical_sales = [25, 20, 45] plt.bar( # Draw the digital sales bars games, # Use game names on the x-axis # Use digital sales as bar heights digital_sales, color="skyblue", # Set the bar color label="Digital" # Set the legend label ) plt.bar( # Draw the physical sales bars games, # Use the same game names # Use physical sales as bar heights physical_sales, bottom=digital_sales, # Stack them above digital sales color="orange", # Set the bar color label="Physical" # Set the legend label ) plt.ylabel("Units Sold (Thousands)") # Add the y-axis label plt.title("Game Sales Breakdown") # Add the chart title plt.legend() # Show the legend plt.tight_layout() # Fix spacing plt.show() # Display the chart

Graph Output: Game Sales Breakdown

Grouped bars
# Create category names categories = ["Apples", "Bananas", "Cherries"] left_values = [10, 15, 7] # Create the first value set right_values = [12, 8, 14] # Create the second value set # Create numeric x positions: 0, 1, 2 x = np.arange(len(categories)) width = 0.35 # Set each bar width plt.bar( # Draw the left bars x - width / 2, # Shift bars slightly left left_values, # Use the first value set width=width, # Set the bar width color="skyblue", # Set the bar color label="Left Side" # Set the legend label ) plt.bar( # Draw the right bars x + width / 2, # Shift bars slightly right right_values, # Use the second value set width=width, # Set the bar width color="salmon", # Set the bar color label="Right Side" # Set the legend label ) # Replace numeric x positions with category names plt.xticks(x, categories) plt.ylabel("Values") # Add the y-axis label plt.title("Vertically Split Bars") # Add the chart title plt.legend() # Show the legend plt.tight_layout() # Fix spacing plt.show() # Display the chart

Pie Charts & Histograms

Pie charts show parts of a whole. Histograms show how numeric values are distributed into ranges.

Pie chart
# Create the size of each pie slice slices = [40, 30, 20, 10] # Create the label for each slice activities = ["Gaming", "Sleeping", "School", "Eating"] # Create the color for each slice pie_colors = ["skyblue", "gold", "lightgreen", "tomato"] plt.pie( # Start creating the pie chart # Use slices as the numeric values slices, # Put activity names around the pie labels=activities, colors=pie_colors, # Apply custom slice colors # Display each percentage with one decimal autopct="%1.1f%%", # Start the first slice at the top startangle=90, wedgeprops={ # Configure the slice borders "edgecolor": "black", # Use black borders "linewidth": 1.5 # Set border width } ) plt.tight_layout() # Fix spacing around the pie plt.show() # Display the pie chart

Graph Output: Activities Pie Chart

Histogram
# Store exam scores scores = [ 55, 62, 67, 71, 74, 78, 81, 85, 88, 90, 92, 95, 96, 98, 100 ] # Print how many scores are in the list print(len(scores)) plt.hist( # Start creating the histogram scores, # Use scores as the numeric data # Set the score ranges for each bar bins=[60, 70, 80, 90, 100], color="skyblue", # Set the bar color edgecolor="black" # Draw black borders around bars ) plt.title("Exam Scores Distribution") # Add the chart title plt.xlabel("Scores") # Add the x-axis label plt.ylabel("Number of Students") # Add the y-axis label plt.tight_layout() # Fix spacing plt.show() # Display the histogram

Graph Output: Exam Scores Distribution

The score 55 is outside the shown bins. If you want to include it, start the bins at 50: bins=[50, 60, 70, 80, 90, 100].

Scatter & Radar Charts

Scatter plots show individual points. Radar charts use polar coordinates to compare several categories around a circle.

Scatter plot
# Create x values from 0 to 9 x = np.arange(10) y_scatter = np.random.randn(10) # Create 10 random y values plt.scatter( # Draw a scatter plot x, # Use x for horizontal positions # Use random values for vertical positions y_scatter, color="red" # Set point color ) plt.title("Random Scatter") # Add the chart title plt.xlabel("x") # Add the x-axis label plt.ylabel("random value") # Add the y-axis label plt.show() # Display the scatter plot

Graph Output: Random Scatter

Radar chart
# Create radar chart labels categories = [ "Speed", "Power", "Stamina", "Skill", "Defense" ] values = [4, 5, 2, 4, 3] # Create the value for each label # Split the circle into equal angles angles = np.linspace( 0, # Start angle 2 * np.pi, # End angle: one full circle len(categories), # Create one angle per category # Do not repeat the final circle point yet endpoint=False # Convert the NumPy array into a list ).tolist() # Repeat the first value to close the shape values = values + [values[0]] # Repeat the first angle to close the shape angles = angles + [angles[0]] fig, ax = plt.subplots( # Create a figure and axes figsize=(6, 6), # Set the figure size subplot_kw=dict(projection="polar") # Make the axes circular/polar ) ax.plot( # Draw the radar outline angles, # Use angles around the circle # Use stat values as distance from center values, color="red", # Set line color linewidth=2, # Set line width label="Player Stats" # Set legend label ) ax.fill( # Fill the radar shape angles, # Use the same circular angles values, # Use the same stat values color="red", # Set the fill color alpha=0.25 # Make the fill transparent ) # Put category ticks around the circle ax.set_xticks(angles[:-1]) # Show category names on those ticks ax.set_xticklabels(categories) plt.title("Character Stats Radar Chart", y=1.1) # Add a title and move it up plt.tight_layout() # Fix spacing plt.show() # Display the radar chart

Graph Output: Character Stats Radar Chart

A radar chart must connect back to the first point, so the first value and first angle are added again at the end.
