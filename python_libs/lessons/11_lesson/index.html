Two scores, two questions. MSE answers "how big is the average error?" (in squared units). R squared answers "what fraction of the variance did the model explain?" (0 to 1).

X = np.array([

X has 12 samples and 3 feature columns. y has one matching target value for each row.

So the numbers we hid in the data are:

PartTrue valueMeaning
B0 (intercept)5the bias
B1 (weight of x1)2.5x1 pushes y up

Train the model and read the equation

The code is exactly the same as with one feature. Because X already has 3 columns, the model simply learns 3 weights instead of 1.

model = LinearRegression()
model.fit(X, y)

print("beta0 =", model.intercept_)
print("beta1, beta2, beta3 =", model.coef_)
beta0 = 6.007340293971851 beta1, beta2, beta3 = [ 2.49454376 -1.60503768 2.84756112]

Read that output carefully. intercept_ is a single number (B0), but coef_ is now an array with one weight per feature.

$$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3$$

One bias, and one weight for every feature column.

$$\hat{y} = 6.01 + 2.49x_1 - 1.61x_2 + 2.85x_3$$

Finally, predict on the training data and score with MSE.

print("--- Model Results ---")
y_pred = model.predict(X)
mse = mean_squared_error(y, y_pred)
print('mse=', mse)
--- Model Results --- mse= 0.8924765982600965

The trained model can now price apartments it has never seen. We treat the three features as Rooms, Floor and Distance.

predict() expects a 2D table, so we pass a list of rows - each inner list is one apartment.

#                     Rooms  Floor  Distance
#                       X1     X2      X3
print(model.predict([[  3,     2,     30],     # 3*B1 + 2*B2 + 30*B3 + B0 = price1
                     [  5,     5,     60] ]))  # 5*B1 + 5*B2 + 60*B3 + B0 = price2
[ 95.71 181.31]
$$\hat{y}_1 = \beta_0 + \beta_1(3) + \beta_2(2) + \beta_3(30)$$ $$\hat{y}_1 \approx 6.01 + 2.49(3) - 1.61(2) + 2.85(30) \approx \boxed{95.71}$$ $$\hat{y}_2 = \beta_0 + \beta_1(5) + \beta_2(5) + \beta_3(60)$$ $$\hat{y}_2 \approx 6.01 + 2.49(5) - 1.61(5) + 2.85(60) \approx \boxed{181.31}$$
Two rows in, two predictions out. The model does not "look up" these apartments anywhere - it just plugs the numbers into the equation it learned.

Bonus - do the prediction by hand

predict() is not magic. It is only "multiply each feature by its weight, add them up, then add the bias". Here are three ways to compute the same number.

Way 1 - write out every term. Notice coef_[0], coef_[1], coef_[2] are B1, B2, B3.

y_pred_3_2_30 = model.intercept_ + model.coef_[0] * 3 + model.coef_[1] * 2 + model.coef_[2] * 30
y_pred_3_2_30
95.70772981

Way 2 - use @, the dot product. @ multiplies each feature by its matching weight and sums the results in one step - exactly the same arithmetic, much shorter.

y_pred_3_2_30 = [3, 2, 30] @ model.coef_ + model.intercept_
y_pred_3_2_30
95.70772981

The dot product, step by step: [3, 2, 30] @ model.coef_ + model.intercept_

Follow the arrows: every feature meets its own weight and they multiply. The three products are then summed, and only at the very end is the bias B0 added - once, not once per feature. That is the entire computation hiding inside predict().

Way 3 - many rows at once. Give @ a matrix of rows and it returns one prediction per row - this is what predict() does internally.

y_pred_2_rows = [[3, 2, 30], [5, 5, 60]] @ model.coef_ + model.intercept_
y_pred_2_rows
array([ 95.70772981, 181.30853788])

Matrix form: every ROW of the matrix does its own dot product with coef_

Same answer as model.predict(). This is the whole secret of a linear model: a dot product plus a bias. Each row of the matrix is one apartment, and each row gets its own dot product with the same coef_ - so n rows in gives n predictions out.

R squared - the coefficient of determination

MSE tells us the size of the average error, but its units are squared and it has no upper limit - so "mse = 3.68" alone does not tell us whether the model is good. R squared fixes this: it always lands between 0 and 1.

$$R^2 = 1 - \frac{SSE}{SST} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

R squared measures how well the model explains the variance in the target variable \(y\).

Every symbol in that formula:

SymbolNameMeaning
\(R^2\)Coefficient of DeterminationThe final score - the proportion of variance in the target explained by the model
\(SSE\)Sum of Squared ErrorsThe total squared error made by your model. Also called \(SS_{res}\) (Residual Sum of Squares)
\(SST\)Total Sum of SquaresThe total variance in the data - the squared error you would get if you simply guessed the average every time
\(\sum\)Sigma"Add all of these up" - once for every data point
\(y_i\)actualThe real (observed) value of the target for point \(i\)
\(\hat{y}_i\)y-hat, predictedThe value your model predicted for point \(i\)
\(\bar{y}\)y-barThe mean (average) of all the actual target values

The idea behind the fraction: SST is the error of the dumbest possible model (always answer the average), and SSE is the error of your model. R squared asks: how much of that dumb error did you remove?

R² = 1 SSE = 0 - perfect fit. Best... too good to be true
R² = 0 SSE = SST - worst. No better than guessing the average
R² = 0.97 The model explains 97% of the variance
Next slide: we will calculate SST, SSE and R squared by hand with three houses.

SSE and SST by hand - three houses

Work the formula manually once, on a tiny dataset, and it stops being scary.

House (\(i\))Actual Value \(y_i\)Predicted Value \(\hat{y}_i\)
House 122.5
House 233.0
House 376.5

Goal: find \(\bar{y}\) (y-bar), calculate \(SST\) and \(SSE\), then find the final \(R^2\) score.

Step 1 - the mean of the actual values \(\bar{y}\).

$$\bar{y} = \frac{2 + 3 + 7}{3} = \frac{12}{3} = 4$$

Step 2 - SST: how far each actual value sits from that mean, squared and summed. This is the error of "always guess 4".

$$SST = \sum (y_i - \bar{y})^2 = (2-4)^2 + (3-4)^2 + (7-4)^2 = 4 + 1 + 9 = \boxed{14}$$

Step 3 - SSE: how far each actual value sits from our model's prediction, squared and summed.

$$SSE = \sum (y_i - \hat{y}_i)^2 = (2-2.5)^2 + (3-3.0)^2 + (7-6.5)^2 = 0.25 + 0 + 0.25 = \boxed{0.5}$$

Step 4 - put them together.

$$R^2 = 1 - \frac{SSE}{SST} = 1 - \frac{0.5}{14} = 1 - 0.0357 = \boxed{0.964}$$

The model removed about 96.4% of the error you would have made by guessing the average.

Sanity check: SSE (0.5) is much smaller than SST (14), so the fraction is tiny and R squared is close to 1. A good model always has SSE much smaller than SST.

R² in code - and the same thing by hand

Back to the 3-feature apartment model. Scikit-learn computes R squared with one call, and we prove it matches our own formula.

The full flow: use the fixed data, fit the model, predict, then score it twice - with MSE and with R squared.

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

X = np.array([
    [ 1, 2, 3], [ 2, 1, 4], [3, 4, 2], [ 4, 2, 5],
    [ 5, 3, 1], [ 6, 5, 4], [7, 1, 6], [ 8, 4, 3],
    [ 9, 2, 7], [ 3, 7, 5], [6, 8, 2], [10, 6, 4]
])
y = np.array([14.7, 19.7, 13.0, 25.6, 16.9, 24.2,
              40.5, 26.9, 45.9, 16.3, 15.0, 31.8])

model = LinearRegression()
model.fit(X, y)
print(model.intercept_)
print(model.coef_)

print("--- Model Results ---")
y_pred = model.predict(X)
mse = mean_squared_error(y, y_pred)
print('mse=', mse)
$$R^2 = 1 - \frac{SSE}{SST} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$ 
r2 = r2_score(y, y_pred)
print('r2=', r2)
r2= 0.99136221831541
sse = np.sum( (y - y_pred)**2 )      # error of OUR model
sst = np.sum( (y - np.mean(y))**2 )  # error of guessing the average
r2_manual = 1 - (sse/sst)
print('r2_manual=', r2_manual)
6.007340293971851 [ 2.49454376 -1.60503768 2.84756112] --- Model Results --- mse= 0.8924765982600965 r2= 0.99136221831541 r2_manual= 0.99136221831541
r2 and r2_manual are identical - that is the proof that r2_score() is nothing more than 1 - SSE/SST. Our model explains about 99.14% of the variance in the prices.

Note the two scores answer different questions about the same model:

ScoreValueHow to read it
MSE0.8925Average squared error. Lower is better, no fixed range.
R squared0.991499.14% of the variance explained. Higher is better.
