Sorting Rows

sort_values orders rows by one or more columns. With multiple columns, pandas sorts by the first column, then breaks ties using the next column.

Counting Values

value_counts() answers "how many rows are in each category?" It can work on one column or on several columns together.

One column
df = pd.read_csv('tips.csv') print(df['smoker'].value_counts())
No 151 Yes 93 Name: smoker, dtype: int64
Combinations of columns
display(df[['sex', 'smoker']].value_counts()) display(df[['sex', 'smoker']].value_counts()['Female']['No']) print(df[['sex', 'smoker']].value_counts()[('Male', 'Yes')])
sex smoker Male No 97 Yes 60 Female No 54 Yes 33 dtype: int64 54 60
For two columns, the result uses a MultiIndex. You can access a specific combination with a tuple, for example ('Male', 'Yes').

Unique Values

Use unique-value tools to discover what values exist in a column and how many different values there are.

df = pd.read_csv('tips.csv') display(df['day'].unique()) # like SQL DISTINCT display(df['size'].unique()) print(100 in df['size'].values) # fastest membership check print(3 in df['size'].unique()) # works, but usually worse print(df['size'].isin([100]).any()) # also possible print(len(df['size'].unique())) print(df['size'].nunique()) # count distinct values
array(['Sun', 'Sat', 'Thur', 'Fri'], dtype=object) array([2, 3, 4, 1, 6, 5], dtype=int64) False True False 6 6
Use .unique() when you need the actual values, and .nunique() when you only need the count.

Duplicates

Duplicates are one of the first things to check while cleaning data.

simple_df = pd.DataFrame([1, 2, 2, 2], ['a', 'b', 'c', 'd']) display(simple_df) display(simple_df.duplicated()) display(simple_df[~simple_df.duplicated()]) display(simple_df.drop_duplicates(keep='last')) display(simple_df.drop_duplicates(keep='first')) display(simple_df.drop_duplicates(keep=False))
simple_df: 0 a 1 b 2 c 2 d 2 simple_df.duplicated(): a False b False c True d True dtype: bool drop_duplicates(keep='last'): 0 a 1 d 2 drop_duplicates(keep='first'): 0 a 1 b 2 drop_duplicates(keep=False): 0 a 1
Keep one row per group, based on sorting
df = pd.read_csv('tips.csv') # One row from each size, with the highest tip in that size df.sort_values( by=['size', 'tip'], ascending=[True, False] ).drop_duplicates('size')
total_bill tip sex smoker day time size Payer Name 222 8.58 1.92 Male Yes Fri Lunch 1 Jason Lawrence 88 24.71 5.85 Male No Thur Lunch 2 Roger Taylor 170 50.81 10.00 Male Yes Sat Dinner 3 Gregory Clark 212 48.33 9.00 Male No Sat Dinner 4 Alex Williamson 155 29.85 5.14 Female No Sun Dinner 5 Madison Wilson 141 34.30 6.70 Male No Thur Lunch 6 Steven Carlson
The trick is to sort first, then drop duplicates. drop_duplicates('size') keeps the first row it sees for each table size.

Missing Data

Missing values require a decision: remove rows, keep rows, or fill values with something meaningful such as 0, a mean, a min/max, or a domain-specific value.

NaN checks
import math x = np.nan print(x == np.nan) # False: NaN never equals anything, even itself print(x is np.nan) print(np.isnan(x)) print(math.isnan(x))
