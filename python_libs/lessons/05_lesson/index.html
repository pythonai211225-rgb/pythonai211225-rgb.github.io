Selecting Columns

Single column → returns a Series
tips_df['tip'] # 0 1.01 # 1 1.66 # 2 3.50 # ... # 243 5.92 # Name: tip, Length: 244, dtype: float64
Multiple columns → returns a DataFrame
tips_df[['tip', 'day']] # tip day # 0 1.01 Sun # 1 1.66 Sun # 2 3.50 Sun # ...
💡 One bracket df['col'] → Series. Double brackets df[['col']] → DataFrame. The return type matters — many functions only accept one or the other.

Adding & Modifying Columns

Add a new computed column
# New column = sum of two existing columns tips_df['Sum With Tip'] = tips_df['tip'] + tips_df['total_bill'] # tips_df now has 8 columns
Modify an existing column in-place
# Double every tip value tips_df['tip'] = tips_df['tip'] * 2
⚠️ Assigning to an existing column name overwrites it permanently. Make a copy (df.copy()) first if you need to keep the original values.

Dropping Columns & Rows

Drop a column — axis=1
# axis=1 → operate along the column axis tips_df.drop('tip', axis=1, inplace=True)
Drop a row — axis=0 (default)
# Removes the row whose index label is 1 tips_df.drop(1, axis=0, inplace=True)

with inplace=True

df.drop('col', axis=1, inplace=True) # modifies df directly # returns None

without inplace

new_df = df.drop('col', axis=1) # df unchanged # new_df has column removed
💡 Prefer the without-inplace style when experimenting — it leaves the original DataFrame intact so you can re-run cells in any order.

set_index & reset_index

Replace the default integer index with a column
# 'Payer Name' becomes the row label df = df.set_index('Payer Name') # total_bill tip smoker day time size # Payer Name # Michael Avila 32.83 1.17 No Sat Dinner 2 # Douglas Tucker 27.20 4.00 No Sun Dinner 2 # ...
Restore the integer index
df = df.reset_index() # 'Payer Name' goes back to a regular column # a fresh 0-based integer index is created
💡 Use set_index() when you want to use .loc[] with meaningful labels (names, dates, IDs) instead of row numbers.

loc vs iloc

Both select rows (and optionally columns) — the difference is how you address them.

.loc[ ] — label-based

df.loc['Michael Avila'] # row whose index label # equals 'Michael Avila' df.loc['Alice':'Bob'] # slice: Alice to Bob # (both ends inclusive)

.iloc[ ] — position-based

df.iloc[0] # first row (position 0) df.iloc[0:5] # rows 0-4 # (end is exclusive)
Reverse slice with iloc
df.iloc[4::-1] # from position 4 backwards to 0
loc with a label range (after set_index)
df.loc['Douglas Tucker':'Tonya Carter'] # all rows between these two labels (inclusive on both ends)
⚠️ .loc[] slices are inclusive on both ends. .iloc[] slices are exclusive on the end — same as Python list slicing.

pd.concat

Stacks DataFrames together — either vertically (more rows) or horizontally (more columns).

axis=0 — stack rows (union)
# Combine first 3 rows and last 2 rows into one DataFrame combined = pd.concat( [df.head(3), df.tail(2)], axis=0, ignore_index=True # resets the index to 0,1,2,3,4 ) # total_bill tip ... # 0 16.99 1.01 # 1 10.34 1.66 # 2 21.01 3.50 # 3 10.07 1.83 # 4 12.60 1.00
axis=1 — stack columns (join side by side)
# Join two DataFrames with matching row indexes df_left = tips_df[['total_bill', 'tip']] df_right = tips_df[['day', 'time']] merged = pd.concat([df_left, df_right], axis=1) # total_bill tip day time # 0 16.99 1.01 Sun Dinner # 1 10.34 1.66 Sun Dinner
💡 Use ignore_index=True with axis=0 whenever the original indexes contain duplicates — otherwise the concatenated DataFrame carries duplicated index values, which can cause subtle bugs with .loc[].

Boolean Filtering

Pass a boolean Series inside df[...] to keep only the rows where the condition is True.

Single condition
df[df['smoker'] == 'Yes'] # smokers only df[100 * df['tip'] / df['total_bill'] > 10] # tip % > 10
.between() — range check
df[df['total_bill'].between(10, 20)] # bill between 10 and 20 (inclusive) df[~df['total_bill'].between(10, 20)] # NOT between 10 and 20 (~ = NOT)
Combining conditions
# AND: both conditions must be True df[(df['smoker'] == 'Yes') & (df['total_bill'] > 20)] # OR: at least one condition must be True df[(df['day'] == 'Sat') | (df['day'] == 'Sun')]
⚠️ Always wrap each condition in parentheses when combining with & or |. Without parentheses Python's operator precedence causes a ValueError.

apply & np.vectorize

.apply(func) — custom function on a single column
def last_four(num): return str(num)[-4:] # last 4 characters of the string tips_df['4 last digit'] = df['CC Number'].apply(last_four) # 0 1117 # 1 9303 # 2 1126 # dtype: object
np.vectorize(func) — custom function on multiple columns
def is_generous(total_bill, tip): return 'Generous' if (tip / total_bill) * 100 > 10 else 'Not Generous' tips_df['category'] = np.vectorize(is_generous)( df['total_bill'], tips_df['tip'] )

.apply() — use when

# function takes 1 argument # (one value from one column) df['col'].apply(my_func)

np.vectorize() — use when

# function takes 2+ arguments # (values from multiple columns) np.vectorize(my_func)( df['col1'], df['col2'] )
💡 np.vectorize is essentially a loop under the hood — it's not faster than a plain loop, but it's cleaner to read. For performance-critical code, prefer vectorized pandas operations instead.

String Operations — .str accessor

Pandas exposes string methods on a Series via the .str accessor, letting you apply Python string operations to an entire column at once.

Split a full name and extract the first name
# 'Payer Name' contains values like 'Michael Avila' tips_df['first_name'] = tips_df['Payer Name'].str.split(' ').str[0] # 0 Michael # 1 Douglas # 2 Travis # dtype: object
Other common .str methods
df['sex'].str.lower() # 'Female' → 'female' df['day'].str.upper() # 'Sun' → 'SUN' df['day'].str.startswith('S') # True/False per row df['day'].str.contains('S') # True if 'S' appears anywhere df['time'].str.replace('Dinner', 'Evening')
💡 .str.split() returns a Series of lists. Chaining .str[0] after it picks the first element from each list — no loop needed.
