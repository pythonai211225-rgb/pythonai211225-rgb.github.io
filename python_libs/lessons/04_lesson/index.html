Imports

Every data-science script starts by importing NumPy and Pandas:

import numpy as np import pandas as pd
💡 The aliases np and pd are universal conventions — you'll see them in every tutorial, documentation page, and Stack Overflow answer.

pd.Series vs np.array

Both hold the same numbers — the difference is that a Series always carries an index alongside its values.

pd.Series

pd.Series([10, 100, 15, 35]) # 0 10 # 1 100 # 2 15 # 3 35 # dtype: int64

np.array

np.array([10, 100, 15, 35]) # array([ 10, 100, 15, 35])
print(type(pd.Series([10]))) # <class 'pandas.core.series.Series'> print(type(np.array([10]))) # <class 'numpy.ndarray'>
💡 The left column (0, 1, 2, 3) is the index. By default it starts at 0 — but you can replace it with custom labels (see next topic).

Creating a Series — 3 ways

1. From a list — integer index (auto-assigned)
s1 = pd.Series([1, 2, 3]) print(s1) # 0 1 # 1 2 # 2 3 # dtype: int64 s1[0] # → 1 (key is the integer 0)
2. From a dict — keys become the index
countries = {'USA': 1776, 'CANADA': 1867, 'MEXICO': 1821} s = pd.Series(countries) print(s) # USA 1776 # CANADA 1867 # MEXICO 1821 # dtype: int64
3. From a list + explicit index
years = [1776, 1867, 1821] label_index = ['USA', 'CANADA', 'MEXICO'] countries = pd.Series(data=years, index=label_index)
💡 Methods 2 and 3 produce the same result — pick whichever is more readable for your data source.

Accessing Values

# Using: countries = pd.Series({'USA': 1776, 'CANADA': 1867, 'MEXICO': 1821}) print(countries.keys()) # Index(['USA', 'CANADA', 'MEXICO'], dtype='object') print(list(countries.keys())) # ['USA', 'CANADA', 'MEXICO'] countries.iloc[0] # → 1776 (position 0) countries.loc['CANADA'] # → 1867 (by label)
⚠️ With a label index, avoid s[0].
When the index contains strings, countries[0] raises KeyError — there is no key 0 in the index.

Use .iloc[n] for position-based access and .loc['LABEL'] for label-based access.

Series Arithmetic

Pandas aligns Series by index label before operating. Keys that appear in only one Series produce NaN.

+ operator — unmatched keys become NaN
first = pd.Series({'Japan': 100, 'China': 450, 'USA': 250}) second = pd.Series({'Brazil': 70, 'China': 350, 'USA': 200}) result = first + second print(result) # Brazil NaN # China 800.0 # Japan NaN # USA 450.0 # dtype: float64
.add(fill_value=0) — treats missing keys as 0
result = first.add(second, fill_value=0) print(result) # Brazil 70.0 # China 800.0 # Japan 100.0 # USA 450.0 # dtype: float64
💡 fill_value=0 tells Pandas: "treat any missing entry as 0 before adding." Use this when combining data from different sources that don't share all the same keys.

dtype & astype

Every Series stores one dtype for all its values. A single float forces the whole Series to float64.

s_float = pd.Series({'Japan': 100.99, 'China': 450, 'USA': 250}) print(s_float.dtype) # float64 s_int = pd.Series([1, 2, 3]) print(s_int.dtype) # int64
Converting with .astype()
print(s_float.astype(int)) # Japan 100 ← truncated, NOT rounded # China 450 # USA 250 # dtype: int64
⚠️ .astype(int) truncates the decimal — it does not round. 100.99 → 100, not 101.

Real-world: Branch Inventory

Three store branches each stock different products. Create each as a pd.Series, combine with .add(fill_value=0), then let the user input a product name and print its total stock.

Step 1 — define the 3 stores as Series
tel_aviv = pd.Series({'milk': 10, 'bread': 5, 'eggs': 12, 'butter': 3}) haifa = pd.Series({'milk': 8, 'eggs': 6, 'water': 20}) modiin = pd.Series({'bread': 15, 'butter': 7, 'water': 10, 'juice': 5})
Step 2 — combine with .add(fill_value=0)
total_stock = ( tel_aviv .add(haifa, fill_value=0) .add(modiin, fill_value=0) ) print(total_stock) # bread 20.0 # butter 10.0 # eggs 18.0 # juice 5.0 # milk 18.0 # water 30.0 # dtype: float64
Step 3 — input a product name and print its stock
product = input("Enter product name: ") if product in total_stock.index: print(f"{product}: {int(total_stock[product])} units across all stores") else: print(f"{product} is not stocked in any store") # Enter product name: milk # milk: 18 units across all stores # Enter product name: cheese # cheese is not stocked in any store
💡 total_stock[product] returns a float (e.g. 18.0) because .add(fill_value=0) promotes the dtype to float64. Wrapping it with int() prints a cleaner number.

Reading a CSV — pd.read_csv

The most common way to load real data. pd.read_csv() returns a DataFrame — a 2D table with named columns and a row index.

tips_df = pd.read_csv('tips.csv') tips_df
📄 tips.csv contains 244 restaurant bills (from the seaborn sample datasets). Columns: total_bill, tip, sex, smoker, day, time, size.

Selecting Columns

Single column → returns a Series
tips_df['tip'] # 0 1.01 # 1 1.66 # 2 3.50 # ... # 243 5.92 # Name: tip, Length: 244, dtype: float64
Multiple columns → returns a DataFrame
tips_df[['tip', 'day']] # tip day # 0 1.01 Sun # 1 1.66 Sun # 2 3.50 Sun # ...
💡 One bracket df['col'] → Series. Double brackets df[['col']] → DataFrame (even for one column). The type matters when you pass the result to other functions.

Adding & Dropping

Add a new column
# Assign a computed value directly — no method needed tips_df['new_column'] = tips_df['tip'] + tips_df['total_bill'] # tips_df now has 8 columns instead of 7
Drop a row (by index label)
# Removes the row whose index label is 1 tips_df.drop(1, inplace=True)
Drop a column
# axis=1 tells pandas to look along the column axis tips_df.drop('tip', axis=1, inplace=True)
⚠️ inplace=True modifies the original DataFrame and returns None. Without it, .drop() returns a new DataFrame and leaves the original unchanged.
