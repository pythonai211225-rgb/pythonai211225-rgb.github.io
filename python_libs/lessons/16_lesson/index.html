VS Code + Live Server

Everything today happens inside one editor. Two installs and one extension:

Step 1Install VS Codecode.visualstudio.com — free, all platforms
Step 2Install Pythonpython.org, then the Python extension
Step 3Live Serverextension by Ritwick Dey
Step 4Open a folderFile → Open Folder, not a single file

To install an extension: click the Extensions icon in the left bar (or Ctrl+Shift+X), type the name, press Install.

ExtensionWhat it gives you
Live ServerRight-click index.html → Open with Live Server. Serves the folder on http://127.0.0.1:5500 and reloads the browser every time you save.
PythonRun and debug .py files, pick the interpreter, get IntelliSense.
GitHub CopilotInline AI completions as you type. See the next slide.
Why Live Server and not double-clicking the file? Opening index.html directly gives you a file:// address. Browsers block fetch from file:// for security, so the moment your page calls an API it fails. Live Server gives you a real http:// address and the auto-reload is a nice bonus.
Later in the lesson we drop Live Server for the regression site — Flask itself serves the page on port 5000, so the page and the API share one origin and there is no CORS to fight.

Enrolling in Copilot & Claude

Two assistants, both living inside VS Code:

ToolHow to get itHow you use it
GitHub Copilot A GitHub account → enable Copilot on github.com → install the GitHub Copilot and GitHub Copilot Chat extensions → sign in when VS Code asks. Free for verified students through GitHub Education. Ghost text appears as you type — press Tab to accept, Esc to dismiss. Ctrl+I opens inline chat on the selected code.
Claude An account at claude.ai. Use it in the browser, or install the Claude extension / Claude Code to work directly on the files in your folder. Describe a whole feature in a sentence or two and let it write or edit the files, then read what changed.
They are good at different things. Copilot shines at finishing the line or the function you already started. Claude is better when you want a whole file, a whole feature, or a redesign described in words. Today we used both.
Never paste secrets into a prompt. API keys, passwords, private data — assume anything you type goes to a server. Keep secrets in environment variables and out of the repo.

Warm-up: the XO game

Before touching the model we built something with no stakes — tic tac toe. One prompt, three files, and a game that runs in the browser:

Build me a tic tac toe game in HTML, CSS and JavaScript. Make it look premium — neon, dark theme, animated. The two players should be starships instead of X and O, and I want to be able to play against the computer.

What came back was NEXUS · Starship Tic Tac Toe:

05.08.2026/ index_claude.html # ~42 KB - board, SVG ship sprites, panels script_claude.js # ~46 KB - game state, win check, AI opponent styles_claude.css # ~48 KB - the neon design, animations, themes

The three files split the job the way any web page does:

FileJob
index.htmlStructure — what is on the page: the 9 cells, the score panel, the buttons.
styles.cssAppearance — colours, glow, layout, the animations when a ship lands.
script.jsBehaviour — what happens on click: place a ship, check for a win, let the computer move.

To play it: open the folder in VS Code, right-click index_claude.html, Open with Live Server.

Why start with a game? It has no backend, no data and no way to get it wrong — so the only thing you are practising is the loop: describe, read, run, correct. That is exactly the skill you need for the rest of the lesson.

The site we built

Same loop as the game, but this time on top of a real model. We took the polynomial regression from July 15, asked for two functions around it, wrapped those in a Flask REST API, and vibe-coded a front end that calls it.

This is the finished thing, running on localhost:5000 — every number on the page came out of the API:

On the pageComes from
R² 0.9945 · RMSE 1.02GET /model-summary
The curve + the 10 dotsGET /model-summary

The written-out equationGET /model-parameters
The slider stops at 2 and 30 on purpose — that is exactly the training range. A degree-5 curve is not trustworthy outside the data it was fitted on, so the interface refuses to ask the model a question it cannot answer honestly.
