00 Core Vocabulary — the words every question is written in asked everywhere

Be able to define each of these in one line, with an example

TermWhat it means
FeatureAn input column — one fact about each row (age, minutes watched). Also called \(X\).
Label / targetThe column you are trying to predict — the answer (\(y\)). "Labelled data" means every row already carries it.
Observation / row / sampleOne example in the dataset: one person, one email, one plant.
Supervised learningThe training data has labels, and the model learns to reproduce them. Regression and classification.
Unsupervised learningNo labels at all. The model only looks for structure — clusters, or fewer columns. Nothing is "right" or "wrong".
ClassificationSupervised, and the label is a class (spam / not spam).
RegressionSupervised, and the label is a number (price, growth in cm).
Train / test splitFit the model on one part of the data, score it on a part it has never seen (typically 70–80% / 20–30%). The test set is the only honest estimate of future performance.
Data leakageLetting the test set influence training — the classic case being a scaler fitted on all the data. Scalers fit on train only, then transform both.
fit / predict / transformfit learns from data, predict answers with the learned model, transform re-expresses data (a scaler, an encoder). fit_transform = both, and only ever on the training set.
OverfittingGreat on train, poor on test — the model memorised noise. Cure: simpler model, more data, limits like max_depth.
UnderfittingPoor on both — the model is too simple for the pattern (a straight line through a curve).
Parameter vs hyperparameterA parameter is learned by fitting (\(\beta_0, \beta_1\), the tree's thresholds). A hyperparameter is set by you before fitting (\(k\) in KNN, \(K\) in K-Means, max_depth, \(C\), \(\varepsilon\)).
ScalingPutting columns with different units onto a comparable range, so no column dominates a distance or a variance. See the two formulas below.
Residual\(e_i = y_i - \hat{y}_i\) — how far one observation sits from the prediction, measured vertically. Positive means the model under-predicted.
R² (R-squared)The share of the variation in \(y\) that the model explains: \(R^2 = 1 - \frac{SSE}{SST}\). 1 is perfect, 0 means no better than always predicting the mean \(\bar{y}\), and a negative value means worse than that. It can never fall when you add a predictor — which is why it cannot be used to choose between models of different sizes.
Adjusted R²\(R^2\) with a fee charged for every predictor: \(R^2_{adj} = 1 - \left[\frac{(1-R^2)(n-1)}{n-p-1}\right]\), where \(n\) = rows and \(p\) = predictors. Always \(\le R^2\), and it falls when a new feature does not earn its keep — so this is the one to compare models with different numbers of features.
SolverThe search procedure that finds the best weights for a model — the engine under LogisticRegression. It changes the speed and the path, not the question being answered. See the table below.
WeightThe number a column gets multiplied by. A big weight means that column has a big say in the prediction — and a weight of 0 means the column is ignored entirely.
L1 penaltyA training rule that stops weights growing on coincidences, and is allowed to push a weight to exactly 0 — which removes that column from the prediction altogether, since \(0 imes ext{anything} = 0\). Choose it when you want the model to drop unhelpful columns. Offered by liblinear and saga.
L2 penaltyThe same idea, but it makes all the weights smaller and never makes one exactly 0: every column stays in, and none is allowed to dominate. The usual default, supported by every solver. With no penalty at all, a model can learn enormous weights from a coincidence in the training rows and then predict badly on new ones.
Encoding (one-hot)Turning a text column into numbers — one 0/1 column per category (OneHotEncoder, get_dummies). Models do arithmetic; they cannot read words.
PipelineOne object holding the whole recipe (scaler → encoder → model). It applies fit_transform going in and transform coming out, so the scaler can never leak.
Cross-validation (K-fold)Split the training data into \(K\) folds; train on \(K-1\), test on the one left out, rotate, average the scores. A more stable estimate than a single split.
Grid searchTrying every combination of hyperparameters in a grid, scored by cross-validation, and keeping the best.
ThresholdThe probability line where a class is decided (0.5 by default in logistic regression). Moving it trades recall against precision.
Outlier / noiseA point far from everything else. K-Means is dragged by them; DBSCAN can leave them out as noise (label −1).
CentroidThe mean point of a cluster — the average of its members, coordinate by coordinate.
ClusterA group the model found by itself, with no name attached. Naming it is your job, not the model's.
WCSS (inertia)How tight the clusters are: every point's squared distance to its own centroid, added up. Smaller means tighter.
Elbow (elbow method)How \(K\) is chosen for K-Means. Plot WCSS against \(K\) and take the \(K\) at the bend. WCSS always falls as \(K\) grows — at \(K = n\) it reaches 0 — so the lowest value is never the answer; the bend is where extra clusters stop buying you much.

Trap "Labelled" is what separates supervised from unsupervised — not the kind of answer. K-Means predicts a number (a cluster id) and is still unsupervised, because nobody ever told it what the right groups were.

⚖ Scaling & Solvers — the two settings behind every model lessons 15-16

You must be able to

  • Say what scaling is for: putting columns with different units onto a comparable range, so no column can dominate a distance or a variance by accident.
  • Apply both formulas by hand and tell them apart.
  • Say which models need it (anything measuring distance or spread — KNN, SVM, K-Means, hierarchical, DBSCAN, PCA) and which never do (trees).
  • Say why the scaler is fitted on the training set only, and what leakage is.
  • Say what a solver is and name the ones from class, with one reason each.

Scaling — the two you must be able to tell apart

Min-max normalisation — MinMaxScaler$$x_{norm} = \frac{x - \min(x)}{\max(x) - \min(x)}$$ Squeezes the column into \([0, 1]\). The min becomes 0 and the max becomes 1. Sensitive to a single extreme outlier, because that outlier is the max.
Standardisation — StandardScaler$$z = \frac{x - \bar{x}}{Std}$$ Re-centres the column on mean 0 with a standard deviation of 1. Values are no longer bounded, but an outlier no longer sets the scale. The usual default.

Both are fitted on the training set only, then applied to the test set with transform. Scale before anything that measures a distance or a spread — KNN, SVM, K-Means, hierarchical, DBSCAN, PCA. Trees never need it.

Solvers — the engine that finds the weights

SolverChoose it when
lbfgsThe default, and the right answer unless something forces otherwise. Reliable on ordinary small and medium data, handles 3+ classes.
liblinearSmall, two-class data, or when you want L1 to push unused weights to exactly zero. Does not do multi-class directly.
sagaLarge datasets, and the only one supporting the L1/L2 mixture. Needs its columns scaled.
sagVery large datasets, updating from part of the data at a time. Also needs scaled columns.
newton-cgYou want an unusually precise fit and can afford the extra work per step.
newton-choleskyMany rows but few columns. Memory use explodes if the columns are many.

All six are looking for the same best weights — they differ in how they search, how fast they get there, and which penalty (L1 / L2) they can apply. Changing the solver is not changing the model.

Trap Min-max is not "the safe default". One mistyped value becomes the maximum and squashes every real number into the bottom of the range — StandardScaler only shifts a little when that happens.

Example question

⚖ Scaling & solvers min-max · standardise · pick the solver

(a) Min-max normalise the column \([\,10,\; 20,\; 60\,]\).

(b) Standardise the column \([\,2,\; 4,\; 4,\; 4,\; 5,\; 5,\; 7,\; 9\,]\), which has mean 5 and standard deviation 2.

(c) One reading in (b) is re-entered as 90 instead of 9. What does that do to a min-max scaling of the column, and why is StandardScaler the safer choice?

(d) Pick a solver:  (i) a first logistic model on 3,000 rows;  (ii) 400,000 rows where you want unused columns driven to exactly zero.

(e) Why is the scaler fitted on the training set only?

(a) \(\min = 10\), \(\max = 60\), so the range is 50:

$$\frac{10-10}{50} = \mathbf{0} \qquad \frac{20-10}{50} = \mathbf{0.2} \qquad \frac{60-10}{50} = \mathbf{1}$$ The smallest value always lands on 0 and the largest on 1 — that is what min-max is.

(b) \(z = \dfrac{x - 5}{2}\):

\(x\)24445579
\(z\)−1.5−0.5−0.5−0.500+1+2

The mean value 5 becomes 0, and a \(z\) of +2 means "two standard deviations above average".

(c) Min-max would now divide by a range of \(90 - 2 = 88\) instead of 7. Every genuine reading is squashed into the bottom of the scale — 9 falls from 1.00 to \(\tfrac{7}{88} = 0.08\), and the column stops discriminating between the real values. StandardScaler uses the mean and the standard deviation instead of the two extremes, so a single wild value shifts the scale a little rather than defining it.

(d) (i) lbfgs — the default, and correct for ordinary small data. (ii) saga with an L1 penalty — it is the large-data solver that supports L1, which is what pushes unused weights to exactly zero. Remember to scale the columns: saga and sag need it.

(e) Because the test set must stay unseen. A scaler fitted on everything has already looked at the test rows' minimum, maximum, mean and spread, and has smuggled that knowledge into training — data leakage. The score you then report is optimistic and not reproducible on tomorrow's data. Fit on train, transform both — or let a Pipeline enforce it for you.

01 Linear Regression — fitting a line and scoring it lessons 9-11

You must be able to

  • Read a fitted line \(\hat{y} = \beta_0 + \beta_1 x\) and predict \(\hat{y}\) for a given \(x\).
  • Say what the slope and the intercept mean in the units of the question.
  • Measure the distance from one observation to the line — that is the residual, measured vertically, \(y - \hat{y}\), positive above the line and negative below it.
  • Fill a residual table by hand: \(\hat{y}\), then \(e\), then \(e^2\), then the sums.
  • Compute MSE, RMSE and MAE from that table and say which one punishes a big miss harder.
  • Compute SSE, SST and \(R^2\), and explain \(R^2\) as "the share of the spread the line explains".
  • Explain why residuals are squared instead of simply added up (they always sum to 0).

Formulas

The line$$\hat{y} = \beta_0 + \beta_1 x$$
Residual — observation to line$$e_i = y_i - \hat{y}_i$$
MSE / RMSE$$\text{MSE} = \frac{1}{n}\sum (y_i - \hat{y}_i)^2 \qquad \text{RMSE} = \sqrt{\text{MSE}}$$ RMSE is back in the original units — MSE is in units squared.
MAE$$\text{MAE} = \frac{1}{n}\sum |\,y_i - \hat{y}_i\,|$$
SSE and SST$$SSE = \sum (y_i - \hat{y}_i)^2 \qquad SST = \sum (y_i - \bar{y})^2$$ SSE compares to the line; SST compares to the flat mean.
R squared$$R^2 = 1 - \frac{SSE}{SST}$$ \(R^2 = 1\) perfect · \(R^2 = 0\) no better than predicting \(\bar{y}\) · negative is possible and means worse than the mean.

Trap The residual is the vertical gap, not the shortest (perpendicular) gap to the line. Subtract in the order \(y - \hat{y}\), keep the sign, and only then square.

02 Polynomial Regression — a curve, fitted the same way lesson 12

You must be able to

  • Build the extra columns: from \(x\) alone to \(x, x^2, x^3 \dots\)
  • Predict \(\hat{y}\) from a quadratic or cubic model by substitution.
  • Score the curve with exactly the same SSE / MSE / \(R^2\) machinery as a straight line.
  • Explain why a higher degree always lowers the training error but not the test error.
  • Compute Adjusted R², and say why it can fall at the very moment \(R^2\) rises.
  • Recognise underfitting (degree too low) and overfitting (degree too high) from a plot or an error table.

Formulas

Degree 2 (quadratic)$$\hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2$$
Degree \(d\)$$\hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2 + \dots + \beta_d x^d$$
Scored identically$$SSE = \sum (y_i - \hat{y}_i)^2 \qquad R^2 = 1 - \frac{SSE}{SST}$$ It is still linear regression — linear in the coefficients \(\beta\), curved in \(x\).
Adjusted R² — \(R^2\) with a fee per predictor$$R^2_{adj} = 1 - \left[\frac{(1 - R^2)(n - 1)}{n - p - 1}\right]$$ \(n\) = rows, \(p\) = predictors (for \(\hat{y} = \beta_0 + \beta_1x + \beta_2x^2\), \(p = 2\): \(x\) and \(x^2\)). Adding a predictor shrinks \(n - p - 1\), which inflates the penalty — so a new term only pays off if it lifts \(R^2\) enough to cover its own cost. Adjusted R² is always \(\le R^2\), and a wide gap between them says some terms are dead weight.

Trap Squaring happens to the feature \(x^2\), never to the coefficient. And \(\bar{y}\) — so \(SST\) — does not change when you change the degree; only \(SSE\) moves. \(R^2\) can never fall when you add a term, which is exactly why it cannot be trusted to choose the degree — that is Adjusted R²'s job.

Example question

02 Polynomial regression predict · residuals · R² · Adjusted R²

A greenhouse fits the curve \(\hat{y} = 5 + 4x - x^2\), where \(x\) is weeks of fertiliser and \(y\) is the harvest in kilos. Four plots were measured:

\(x\) (weeks)1234
\(y\) (kilos)81085

(a) Predict the harvest at each \(x\).   (b) Give the residuals and the SSE.   (c) Compute \(R^2\).   (d) Compute Adjusted R² and say why it comes out below \(R^2\).   (e) Why would a straight line do badly on this data?   (f) A colleague suggests degree 3. What happens to \(R^2\), what happens to Adjusted R², and why is that not good news?

(a) Substitute each \(x\) into \(5 + 4x - x^2\):

$$x=1:\; 5+4-1 = 8 \qquad x=2:\; 5+8-4 = 9 \qquad x=3:\; 5+12-9 = 8 \qquad x=4:\; 5+16-16 = 5$$

\(x\)\(y\)\(\hat{y}\)\(e = y-\hat{y}\)\(e^2\)
18800
2109+11
38800
45500
SSE1

(b) Residuals 0, +1, 0, 0  →  \(SSE = \mathbf{1}\), and \(\text{MSE} = \tfrac{1}{4} = 0.25\).

(c) \(\bar{y} = \dfrac{8+10+8+5}{4} = \dfrac{31}{4} = 7.75\)

$$SST = 0.25^2 + 2.25^2 + 0.25^2 + (-2.75)^2 = 0.0625 + 5.0625 + 0.0625 + 7.5625 = 12.75$$ $$R^2 = 1 - \frac{1}{12.75} = 1 - 0.078 = \mathbf{0.922}$$

(d) Here \(n = 4\) rows and \(p = 2\) predictors — \(x\) and \(x^2\). The intercept is not a predictor:

$$R^2_{adj} = 1 - \left[\frac{(1 - 0.922)(4 - 1)}{4 - 2 - 1}\right] = 1 - \left[\frac{0.078 \times 3}{1}\right] = 1 - 0.235 = \mathbf{0.765}$$

It lands well below \(R^2\) because the model is charged for both of its terms and there are only four rows to pay with. \(R^2\) asks "how much of the spread did I explain?"; Adjusted R² asks "… and was it worth the predictors it cost?". The gap here, 0.922 against 0.765, is wide because \(n\) is tiny — with 400 plots the same \(R^2\) would give an Adjusted R² of about 0.921, almost no penalty at all.

(e) The harvest rises and then falls — more fertiliser helps up to a point and then hurts. A straight line can only go one way, so it would underfit: it would miss the peak entirely and leave large residuals at both ends.

(f) With 4 points, a degree-3 curve passes through every one of them, so \(SSE\) drops to 0 and \(R^2\) rises to 1 — apparently perfect. Now look at the adjustment: \(p = 3\), so the denominator becomes \(n - p - 1 = 4 - 3 - 1 = \mathbf{0}\) and Adjusted R² cannot even be computed. The model has four parameters for four data points and no degrees of freedom left to judge it with.

That is the whole warning in one line of arithmetic: the curve has memorised these four plots rather than learned the pattern, it would wobble wildly at \(x = 2.5\), and the honest test is the test set, never the training \(R^2\).

Only \(SSE\) changed when the model changed. \(\bar{y}\), and therefore \(SST\), belongs to the data, not to the curve. And note the direction of travel: from degree 2 to degree 3, \(R^2\) went up while Adjusted R² collapsed. That disagreement is the signal to stop adding terms.

03 Logistic Regression — a probability, then a decision lessons 13-14

You must be able to

  • Put a number through the sigmoid and get a probability between 0 and 1.
  • Turn that probability into a class with a threshold (0.5 unless the question says otherwise).
  • Find the input at which the model is exactly 50% undecided: \(x = -\beta_0 / \beta_1\).
  • Work backwards from any probability to the \(x\) that produces it — 80%, 90%, 20% — not only the 50% point.
  • Say what moving the threshold to 0.3 or 0.7 does to recall and to precision.
  • Explain why a straight line cannot be used for a Yes/No target (it leaves the 0–1 range).

Formulas

Sigmoid$$P(Y=1 \mid X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$$
The 50% point (decision boundary)$$x_{50\%} = -\frac{\beta_0}{\beta_1}$$ Because \(P = 0.5\) exactly when \(\beta_0 + \beta_1 x = 0\).
The \(x\) for any probability \(p\)$$x_{(p)} = \frac{\ln\!\left(\frac{p}{1-p}\right) - \beta_0}{\beta_1}$$ \(\frac{p}{1-p}\) is the odds and \(\ln\!\left(\frac{p}{1-p}\right)\) is the log-odds, which is what the straight line \(\beta_0 + \beta_1x\) actually predicts. Put \(p = 0.5\) in and the odds are 1, \(\ln 1 = 0\), and the whole thing collapses back to \(-\beta_0/\beta_1\) — the 50% rule above is just this formula's easiest case.
Decision rule$$\hat{y} = \begin{cases} 1 & P \ge \text{threshold} \\ 0 & P < \text{threshold} \end{cases}$$
Useful values$$\sigma(0) = 0.5 \qquad \sigma(+2) \approx 0.88 \qquad \sigma(-2) \approx 0.12$$

Trap The minus sign inside the exponent. \(e^{-z}\) with \(z = \beta_0 + \beta_1 x\) — a large positive \(z\) makes \(e^{-z}\) tiny and the probability close to 1.

04 Classification Metrics — reading a confusion matrix lessons 13-14

You must be able to

  • Build a confusion matrix from a list of true labels and predictions.
  • Name TP, TN, FP (false alarm) and FN (miss) in the words of the question.
  • Compute accuracy, precision, recall, specificity and F1 from the four counts.
  • Argue which metric matters for a given scenario — a disease test cares about recall, a spam filter cares about precision.
  • Explain why accuracy lies when one class is rare (99 healthy, 1 sick).

Formulas

Accuracy$$\frac{TP + TN}{TP + TN + FP + FN}$$
Precision — of those I flagged, how many were right$$\frac{TP}{TP + FP}$$
Recall — of those that were real, how many did I catch$$\frac{TP}{TP + FN}$$
Specificity$$\frac{TN}{TN + FP}$$
F1 — one number for both$$F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$ The harmonic mean: it collapses toward the worse of the two.

Trap Precision and recall share the same numerator \(TP\) and differ only in the denominator: precision divides by the whole predicted-positive column, recall by the whole actually-positive row.

05 K-Nearest Neighbours — distance, then a vote lesson 15

You must be able to

  • Compute the Euclidean distance between two rows, by hand, in 2 or 3 features.
  • Rank the distances, take the \(k\) smallest, and read off the majority class.
  • Show that the answer can flip between \(k = 1\), \(k = 3\) and \(k = 5\).
  • Min-max normalise a column and redo the distances with the scaled values.
  • Explain why an unscaled column with big numbers (salary vs. age) hijacks every distance.
  • Say why an even \(k\) is a bad idea with two classes, and what a very large \(k\) does.

Formulas

Euclidean distance$$d(p,q) = \sqrt{\sum_{i=1}^{n}(p_i - q_i)^2}$$
Two features, written out$$d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$
Min-max normalisation$$x_{norm} = \frac{x - \min(x)}{\max(x) - \min(x)}$$ Every column ends up between 0 and 1, so no column can shout louder than another.

Trap Ranking distances does not need the square root — but if the question asks for the distance, write the root. Normalise using the min and max of the column, not of the row.

06 Support Vector Machines — the widest street lesson 17

You must be able to

  • Read a hyperplane \(w_1x_1 + w_2x_2 + b = 0\) and plot it.
  • Substitute a point into \(w \cdot x + b\) and use the sign to say which side it is on.
  • Compute the perpendicular distance from a point to that line, i.e. divide by \(\lVert w \rVert\).
  • Identify the support vectors — the points sitting exactly on the margin — and say why moving any other point changes nothing.
  • Explain the margin, and what a small vs. large \(C\) does (tolerate mistakes vs. force a hard separation).
  • Say in one line what a kernel buys you when the classes are not separable by a straight line.

Formulas

The hyperplane$$w^{T}x + b = 0$$ which, written out feature by feature, is $$w_1x_1 + w_2x_2 + \dots + w_nx_n + b = 0$$
Signed distance — which side, and how far$$\text{SignedDistance}(x) = \frac{w \cdot x + b}{\lVert w \rVert}$$ where \(\lVert w \rVert = \sqrt{w_1^2 + w_2^2 + \dots + w_n^2}\) — the length of the weight vector.
Absolute distance$$\text{Distance}(x) = \frac{|\,w \cdot x + b\,|}{\lVert w \rVert}$$
Margin width$$\text{margin} = \frac{2}{\lVert w \rVert}$$ Bigger \(\lVert w \rVert\) → narrower street. SVM maximises this width.

Trap Forgetting to divide by \(\lVert w \rVert\). \(w \cdot x + b\) alone is a score, not a distance — only after dividing by the length of \(w\) is it measured in the units of the axes.

The one thing students mix up: two different distances to a line

Regression — vertical. The line is a prediction, so the only gap that means anything is the one measured in the units of \(y\): straight down or straight up from the point to the line.

$$e_i = y_i - \hat{y}_i$$

Used in: residuals, SSE, MSE, RMSE, \(R^2\), and the MSE impurity of a regression tree.

SVM — perpendicular. Here the line is a border, so what matters is the shortest gap to it in any direction — which is why the score gets divided by the length of \(w\).

$$\text{Distance}(x) = \frac{|\,w \cdot x + b\,|}{\lVert w \rVert}$$

Used in: which side of the boundary a point is on, the margin, and finding the support vectors.

Same picture, two different questions. If the exam asks "how wrong was the prediction" it is the vertical gap; if it asks "how far is the point from the boundary" it is the perpendicular one.

07 Decision Trees — Gini, gain, and the regression split lessons 18-19

You must be able to

  • Compute the Gini impurity of a single node from its class counts.
  • Split a table on a given condition and count what landed in each child.
  • Compute the weighted Gini of the level — each child weighted by how many rows it holds.
  • Compute the gain and compare two candidate questions, then state which one the tree asks and why.
  • Recognise a pure node (\(G = 0\)) and say that it becomes a leaf predicting its one class.
  • Know the ceiling \(1 - 1/k\): 0.5 for two classes, 0.667 for three, 0.75 for four.
  • Do the same for a numeric target: MSE of a node, weighted MSE of the level, MSE gain.
  • State what each leaf predicts — majority class for classification, the mean for regression.

Formulas

Gini impurity of a node$$G(Q) = 1 - \sum_c p_c^{\,2}$$
Weighted impurity of a level$$G_{\text{split}} = \frac{n_L}{n}G(\text{left}) + \frac{n_R}{n}G(\text{right})$$
Gain$$\text{Gain} = G(\text{parent}) - G_{\text{split}}$$ The tree tries every feature at every threshold and keeps the largest gain.
Regression: impurity is MSE$$\text{MSE}(Q) = \frac{1}{n}\sum_{i \in Q}(y_i - \bar{y}_Q)^2$$
Regression: weighted MSE and its gain$$\text{MSE}_{\text{split}} = \frac{n_L}{n}\text{MSE}(L) + \frac{n_R}{n}\text{MSE}(R)$$ $$\text{Gain} = \text{MSE}(\text{parent}) - \text{MSE}_{\text{split}}$$

Trap A plain average of the two children is wrong — a child holding 8 rows must count for more than one holding 4. And gain is always measured against the parent, never between the two children.

08 K-Means — the loop, in the right order lesson 21

You must be able to

  • Say what \(K\) is, and that you choose it before the algorithm starts.
  • Put the stages of the loop in the right order, and say what each one does.
  • Say what happens in one full pass: every point is assigned first, and only then does every centroid move.
  • Say what a centroid is — the mean of the points currently in its cluster.
  • Say when the loop stops: when an assignment round changes nobody's cluster.
  • Explain why different starting centroids can end in a different answer.
  • Say what WCSS measures, why it always falls as \(K\) grows, and why that means you pick \(K\) at the elbow rather than at the lowest value.
  • Say why the features must be scaled first, and why K-Means struggles with outliers and with clusters that are not roughly round.

The flow — know this order

  1. Choose \(K\) — how many clusters you want. Nothing in the data tells you this.
  2. Place \(K\) centroids to start, at random (or with k-means++).
  3. Assign — every point joins the nearest centroid. Now every point has a cluster.
  4. Update — every centroid moves to the mean of the points that just joined it.
  5. Repeat 3 and 4 — assign, update, assign, update.
  6. Stop when an assignment round changes nothing. The model has converged.

Choosing \(K\): run the whole thing for \(K = 1, 2, 3\dots\), plot WCSS against \(K\), and take the \(K\) at the bend — the point after which more clusters stop buying much.

Not in the exam You will not be asked to compute distances, move a centroid, or work out WCSS by hand. What the exam asks for is the order of the stages and the reason behind each one.

Trap Assign all the points before moving any centroid — never one point at a time. And K-Means has no labels to be right about: it finds groups, it does not name them.

09 PCA — fewer columns, most of the information lesson 22

You must be able to

  • Say what PCA is for: replacing many columns with a few new ones while keeping as much of the variation as possible.
  • Say what a component is — a direction, a weighted mix of all the original columns, not one of them.
  • Say why PC1 comes first (it carries the most variance), and that each later component carries less.
  • Say that the components are orthogonal — perpendicular, so they do not repeat each other's information.
  • Turn a list of component variances into explained variance ratios — each variance over the total — build the cumulative column, and say how many components are needed to keep, say, 95%.
  • Say why the data must be scaled first — PCA chases variance, and variance carries units.
  • Say what you give up: the new columns are mixtures, so they no longer mean anything you can name.
  • Say what PCA is not: it is not feature selection. It does not throw columns away, it blends them.

The ideas, in words

Variance = information A column where everybody scores the same tells you nothing. PCA looks for the direction along which the rows are the most spread out, and calls it PC1.
Explained variance ratio Each component's share of the total variance. The shares add up to 1, and the cumulative column is how you decide where to stop: keep components until the running total clears your target.
Orthogonal Every component is at right angles to every other one, so PC2 carries only what PC1 could not.
The trade 4 columns → 2 components at 96% means a smaller, faster, less noisy dataset, paid for with columns nobody can interpret any more.

Not in the exam Nothing is computed from the raw data: you will not project a row onto a component, you will not work out a variance from the numbers in a column, and eigenvectors are not required. The variances are handed to you — turning them into ratios and a cumulative column, and saying what the components are, is the work.

Trap "PCA picks the best columns" is wrong. It builds new ones out of all of them.

10 Hierarchical Clustering — the merge order and the four linkages lesson 23

You must be able to

  • Describe the agglomerative loop: every point starts as its own cluster, the two nearest clusters merge, and that repeats until one cluster holds everything.
  • Say why it needs no \(K\) up front — you decide the number of clusters afterwards, by cutting the tree.
  • Read a dendrogram: what the height of a join means (how far apart the two merged clusters were), and how cutting at a height gives you a number of clusters.
  • Say how many clusters a given cut produces — count the vertical lines the cut crosses.
  • Name and explain the four linkages — the whole point of this topic: once clusters hold several points, "the distance between them" has to be defined, and each definition gives a different tree.
  • Say which linkage is satisfied by a single close pair (single) and which insists that every pair is close (complete, and Ward in effect) — and what that does to the shape of the clusters.
  • Say why the features must be scaled first.

How far apart are two clusters?

Single linkage — the closest pair The distance between the two nearest members, one from each cluster. Two clusters count as close when any two of their points are close, so a single point sitting between two groups can act as a stepping stone and merge them into one long cluster.
Complete linkage — the furthest pair The distance between the two furthest members. Clusters merge only when every pair is reasonably close, so it produces tight, compact, roughly equal-sized clusters and never strings points into a chain.
Average linkage — the mean of every pair Average the distance over all pairs, one point from each side. A compromise between single and complete, less affected by any one extreme pair.
Centroid linkage — middle to middle The distance between the two cluster means. Simple to picture, but it ignores how spread out each cluster is.
Ward linkage — the cheapest merge Not a distance between points at all: at every step it merges the pair that increases the total within-cluster spread the least. Gives compact, similar-sized clusters and is the usual default.

Not in the exam No calculation — you will not build a linkage matrix or a dendrogram by hand. What is asked is which linkage means what, what a dendrogram shows, and what a cut at a given height gives you.

Trap The linkage is not a detail. Single and complete linkage on the very same points can produce completely different clusters — the tree is a consequence of the definition you chose, so always say which one you used.

11 DBSCAN — density, and the points that belong to nothing lesson 23

You must be able to

  • Name the two parameters and say exactly what each one does: \(\varepsilon\) (eps) — the radius of the neighbourhood, and MinPts (min_samples) — how many points must be inside that radius.
  • Given the distances, count how many points lie within \(\varepsilon\) of each one, itself included — that count is the whole test.
  • Classify any point as core, border or noise from that count.
  • Work out the clusters: chain the core points that reach each other, attach the border points, leave the rest as noise.
  • Describe the process in order — how a cluster starts at a core point and grows outward.
  • Say what DBSCAN does that K-Means cannot: no \(K\) to choose, clusters of any shape, and outliers left out instead of forced in.
  • Say what goes wrong when \(\varepsilon\) is too small (almost everything becomes noise) and when it is too large (everything merges into one cluster).
  • Say why the features must be scaled — \(\varepsilon\) is a distance, so it is meaningless across mixed units.

The test, then the three kinds of point

Distance between two points$$d(p,q) = \sqrt{(x_p - x_q)^2 + (y_p - y_q)^2}$$ A point is a neighbour when \(d \le \varepsilon\). Exactly \(\varepsilon\) counts as inside.
Core point Has at least MinPts points (itself included) within distance \(\varepsilon\). It sits in a dense region, and only core points can grow a cluster.
Border point Does not have enough neighbours itself, but lies inside the \(\varepsilon\)-radius of a core point. It joins that cluster — as a passenger, not a driver.
Noise point Neither. Too few neighbours, and not close to any core point. DBSCAN leaves it unassigned, labelled -1 — the only model on the course allowed to say "this one belongs to nothing".

The process

  1. Pick a point that has not been visited yet.
  2. Count how many points lie within \(\varepsilon\) of it.
  3. If that count reaches MinPts, it is a core point: open a new cluster around it.
  4. Expand — add its neighbours; every neighbour that is itself core brings its neighbours in too, and the cluster keeps growing outward.
  5. Neighbours that are not core join as border points and stop the growth there.
  6. If the count was too small, mark the point noise for now — it can still be picked up later as a border point of some other cluster.
  7. Move on to the next unvisited point and repeat until every point has been visited.

Trap Noise is a result, not a failure. If a point is far from every dense region, leaving it out is the correct answer — K-Means would have forced it into the nearest cluster and dragged the centroid towards it.
