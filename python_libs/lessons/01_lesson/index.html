Exercise

Build a Markdown Cell About Yourself

Open a new Jupyter Notebook, add a Markdown cell, and recreate the structure below. Replace the placeholder text with your own information.

📋 Markdown Template

Type this syntax inside a Markdown cell in Jupyter:

# Your Name ## About Me *A short sentence about yourself.* ## Hobbies 1. Hobby 1 2. Hobby 2 3. Hobby 3
💡 Remember: Press Shift + Enter to run the Markdown cell and see the rendered result.

📝 Tasks
  1. Open Jupyter Notebook and create a new notebook.
  2. Change the first cell type to Markdown (press M in Command Mode).
  3. Write # Your Name as a level-1 heading.
  4. Add ## About Me and write one sentence about yourself in italic using *text*.
  5. Add ## Hobbies and list at least 3 real hobbies as a numbered list.
  6. Run the cell with Shift + Enter — check that it looks like the preview above.
  7. Save your notebook (Ctrl + S), upload it to GitHub, and send the link to the email below.
