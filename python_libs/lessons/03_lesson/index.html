Finding Row & Column from argmax() / argmin()

argmax() returns a flat (1D) index — as if the 2D array were unrolled into a single row. To convert back to row and col use integer division and modulo:

Formula
$$\text{row} = \frac{\text{flat\_index}}{\text{num\_cols}} \quad \text{(integer division)} \qquad \text{col} = \text{flat\_index} \bmod \text{num\_cols}$$
📋 5 × 5 example — argmax
import numpy as np np.random.seed(42) arr = np.random.randint(0, 100, size=(5, 5)) print(arr) # [[51 92 14 71 60] # [20 82 86 74 74] # [87 99 23 2 21] ← max = 99 is here # [52 1 87 29 37] # [10 14 72 98 76]] print('arg_max', arr.argmax()) # 11 (flat index) # 11 // 5 = row 2 # 11 % 5 = col 1 print(f"row: {arr.argmax() // arr.shape[1]}, col: {arr.argmax() % arr.shape[1]}") # row: 2 col: 1
📋 6 × 3 example — argmin
arr = np.random.randint(0, 100, size=(6, 3)) print(arr) print('arg_min', arr.argmin()) # flat index of minimum print(f"row: {arr.argmin() // arr.shape[1]}, col: {arr.argmin() % arr.shape[1]}")
💡 arr.shape[1] is the number of columns. The pattern flat // cols and flat % cols is universal — works for any 2D shape.

Exponential — np.exp()

Applies ex element-wise to every value in the array, where e ≈ 2.71828 is Euler's number.

Formula
$$e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots$$
📋 Basic usage
a = np.array([0, 1, 2, 3]) print(np.exp(a)) # [ 1. 2.71828183 7.3890561 20.08553692] # e⁰ = 1, e¹ = e, e² ≈ 7.389, e³ ≈ 20.09 print(np.exp(1)) # 2.718281828459045 ← Euler's number print(np.exp(0)) # 1.0
📋 Common use — softmax temperature
scores = np.array([1.0, 2.0, 3.0]) e_x = np.exp(scores) softmax = e_x / e_x.sum() print(softmax) # [0.09003057 0.24472847 0.66524096] # All values sum to 1.0 — used in neural network output layers
💡 np.exp(x) is the inverse of np.log(x): np.exp(np.log(x)) == x

Logarithms — np.log, np.log10, np.log2

A logarithm answers the question: "what exponent do I need?"
$\log_b(x) = y$ means $b^y = x$. NumPy has three variants covering the most common bases.

Core idea
$$\log_b(x) = y \;\;\Longleftrightarrow\;\; b^{\,y} = x$$
📋 Simple examples — reading logs intuitively
# log₃(9) = 2 because 3² = 9 import math print(math.log(9, 3)) # 2.0 # log₁₀(1000) = 3 because 10³ = 1000 print(math.log(1000, 10)) # 3.0
📋 np.log10() — base 10
print(np.log10(1)) # 0.0 ← 10⁰ = 1 print(np.log10(10)) # 1.0 ← 10¹ = 10 print(np.log10(1000)) # 3.0 ← 10³ = 1000 print(np.log10(100000)) # 5.0 ← 10⁵ = 100000
📋 np.log() — natural log (base e)
# base is e ≈ 2.71828 print(np.log(1)) # 0.0 ← e⁰ = 1 print(np.log(np.e)) # 1.0 ← e¹ = e print(np.log(np.e**3)) # 3.0 ← e³ # Element-wise on array a = np.array([1, np.e, np.e**2, np.e**3]) print(np.log(a)) # [0. 1. 2. 3.]
📋 np.log2() — base 2
print(np.log2(1)) # 0.0 ← 2⁰ = 1 print(np.log2(2)) # 1.0 ← 2¹ = 2 print(np.log2(8)) # 3.0 ← 2³ = 8 print(np.log2(1024)) # 10.0 ← 2¹⁰ = 1024 # Element-wise on array bits = np.array([1, 2, 4, 8, 16, 32]) print(np.log2(bits)) # [0. 1. 2. 3. 4. 5.]
⚠️ np.log(0) returns -inf and np.log(negative) returns nan — always check your data for zeros or negatives before taking a log.

Matrix Multiply — .dot() / @

Each cell in the output is the sum of products of one row from A with one column from B. Shape rule: A is m × p, B is p × n → result is m × n.

📋 3 × 2 · 2 × 3 = 3 × 3
A  (3 × 2)
[[1, 2], [3, 4], [5, 6]]
@
B  (2 × 3)
[[ 7, 8, 9], [10, 11, 12]]
=
C  (3 × 3)
[[ 27, 30, 33], [ 61, 68, 75], [ 95, 106, 117]]
A = np.array([[1, 2], [3, 4], [5, 6]]) # shape (3, 2) B = np.array([[7, 8, 9], [10, 11, 12]]) # shape (2, 3) C = A.dot(B) # or: C = A @ B print(C) # [[ 27 30 33] # [ 61 68 75] # [ 95 106 117]] print(C.shape) # (3, 3)
How each cell is calculated (row · col)
C[0,0]
1×7 + 2×10
= 7 + 20 = 27
C[0,1]
1×8 + 2×11
= 8 + 22 = 30
C[0,2]
1×9 + 2×12
= 9 + 24 = 33
C[1,0]
3×7 + 4×10
= 21 + 40 = 61
C[1,1]
3×8 + 4×11
= 24 + 44 = 68
C[1,2]
3×9 + 4×12
= 27 + 48 = 75
C[2,0]
5×7 + 6×10
= 35 + 60 = 95
C[2,1]
5×8 + 6×11
= 40 + 66 = 106
C[2,2]
5×9 + 6×12
= 45 + 72 = 117
⚠️ Columns of A must equal rows of B. A(3×2) · B(2×3) ✅  |  A(3×2) · B(3×3) ❌ — shapes don't align.

Cumulative Sum — .cumsum()

Returns an array of the same shape where each element is the running total of all previous elements up to and including that position.

Formula
$$\text{out}[k] = \sum_{i=0}^{k} a_i \qquad k = 0, 1, \ldots, n-1$$
📋 1-D cumulative sum
a = np.array([1, 2, 3, 4, 5]) print(a.cumsum()) # [ 1 3 6 10 15] # out[0]=1, out[1]=1+2=3, out[2]=1+2+3=6, ...
📋 2-D with axis
b = np.array([[1, 2, 3], [4, 5, 6]]) print(b.cumsum(axis=1)) # running total along each row # [[ 1 3 6] # [ 4 9 15]] print(b.cumsum(axis=0)) # running total down each column # [[1 2 3] # [5 7 9]]
📋 Real-world use — cumulative sales
daily_sales = np.array([120, 95, 140, 110, 160]) print(daily_sales.cumsum()) # [120 215 355 465 625] # By end of day 5, total sales = 625
💡 cumsum()[-1] equals sum() — the last element is always the grand total.

Median — np.median()

The middle value of a sorted dataset. Resistant to outliers — a single extreme value barely moves it, unlike the mean.

Formula — sort first, then pick the middle
$$\text{median} = \begin{cases} a_{\left\lfloor n/2 \right\rfloor} & \text{if } n \text{ is odd} \\[6pt] \dfrac{a_{n/2-1} + a_{n/2}}{2} & \text{if } n \text{ is even} \end{cases}$$
where $a_0 \leq a_1 \leq \cdots \leq a_{n-1}$ is the sorted array
📋 Odd length (n = 5)
a = np.array([3, 1, 4, 1, 5]) # sorted: [1, 1, 3, 4, 5] → middle index = 5//2 = 2 print(np.median(a)) # 3.0
📋 Even length (n = 6)
b = np.array([3, 1, 4, 1, 5, 9]) # sorted: [1, 1, 3, 4, 5, 9] → avg of [2] and [3] = (3+4)/2 print(np.median(b)) # 3.5
📋 Outlier resistance
salaries = np.array([50000, 52000, 54000, 56000, 2000000]) print(np.median(salaries)) # 54000 — barely moved print(salaries.mean()) # 442400 — pulled way up by the outlier!
💡 Rule of thumb: if mean ≫ median, the data is right-skewed (a large outlier pulling the mean up). Use median for salary, house prices, response times.

Standard Deviation — np.std()

Measures how far values spread from the mean. Small std → tightly clustered. Large std → widely scattered. Same units as the original data.

Formula (population, ddof=0)
$$\sigma = \sqrt{\frac{\displaystyle\sum_{i=1}^{n}(x_i - \mu)^2}{n}} \qquad \mu = \frac{1}{n}\sum_{i=1}^{n} x_i$$
📋 Step-by-step walkthrough
a = np.array([2, 4, 4, 4, 5, 5, 7, 9]) # Step 1 — mean mu = a.mean() # 40/8 = 5.0 # Step 2 — deviations from mean: [-3,-1,-1,-1,0,0,2,4] # Step 3 — squared deviations: [ 9, 1, 1, 1,0,0,4,16] # Step 4 — mean of squares: 32/8 = 4 ← this is variance # Step 5 — square root: √4 = 2.0 print(np.std(a)) # 2.0 ← population std print(np.std(a, ddof=1)) # 2.138 ← sample std (use for surveys/samples)
📋 Axis-wise on 2D
m = np.array([[2, 4, 6], [1, 5, 9]]) print(np.std(m, axis=0)) # std of each column: [0.5 0.5 1.5] print(np.std(m, axis=1)) # std of each row: [1.633 3.266]
💡 Use ddof=0 (default) for the whole population. Use ddof=1 for a sample (e.g. survey data) — it applies Bessel's correction for an unbiased estimate.

Variance — np.var()

Variance is std² — the mean of squared deviations from the mean. Units are squared (e.g. metres²), so it's less interpretable than std, but it's additive across independent sources of error.

Formula (population, ddof=0)
$$\sigma^2 = \frac{\displaystyle\sum_{i=1}^{n}(x_i - \mu)^2}{n}$$
Key relationship
$$\sigma^2 = \sigma^2 \quad\Leftrightarrow\quad \text{var} = \text{std}^2 \qquad \text{std} = \sqrt{\text{var}}$$
📋 Basic usage
a = np.array([2, 4, 4, 4, 5, 5, 7, 9]) print(np.var(a)) # 4.0 ← population variance print(np.std(a) ** 2) # 4.0 ← same thing (std²) print(np.var(a, ddof=1)) # 4.571 ← sample variance
📋 Variance decomposition — why it matters
# Independent noise sources — variances ADD, std does NOT sensor_var = 0.04 # σ² from sensor noise process_var = 0.09 # σ² from process variation total_var = sensor_var + process_var # = 0.13 total_std = np.sqrt(total_var) # ≈ 0.36
💡 var = std² — always. They measure the same thing on different scales. Prefer std for communicating results (same units); prefer var for calculations (additive).
