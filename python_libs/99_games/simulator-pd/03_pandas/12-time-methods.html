python
# common freq strings
# 'D'  — daily     'W' — weekly (Sun)
# 'ME' — month end 'QE' — quarter end
# 'YE' — year end  'h'  — hourly

# mean per week
sales.set_index('date').resample('W')['amount'].mean()
Old vs new freq strings: pandas ≥ 2.2 uses 'ME' (month end) instead of 'M', and 'YE' instead of 'A'. Both work in most versions, but the new aliases are preferred.

Parse the joined column and add three new columns: year, month, and day_of_week (0 = Monday).

Q2

Add a column due_date that is 90 days after each start_date. Then add overdue: True if due_date is before 2024-07-01.

df = pd.DataFrame({
    'task':       ['A', 'B', 'C'],
    'start_date': pd.to_datetime(['2024-01-01', '2024-04-01', '2024-06-01'])
})
Show answer 
df['due_date'] = df['start_date'] + pd.Timedelta(days=90)
df['overdue']  = df['due_date'] < pd.Timestamp('2024-07-01')
print(df)
#   task start_date   due_date  overdue
# 0    A 2024-01-01 2024-04-01     True
# 1    B 2024-04-01 2024-06-30     True
# 2    C 2024-06-01 2024-08-30    False

Resample the sales data below to get the total revenue per month.
