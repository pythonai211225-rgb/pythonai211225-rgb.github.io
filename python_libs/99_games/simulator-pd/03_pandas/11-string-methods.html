String Methods

The .str accessor applies vectorised string operations to an entire Series — no Python loops needed. Works on any object-dtype column.

str.lower / upper str.contains str.replace str.split / extract

extract vs findall: str.extract() returns the first match per row as a DataFrame. str.findall() returns a list of all matches per row — useful when a row may contain multiple matches.
Exercises

Practice — String Methods

Q1

Normalize the name column: strip whitespace and convert to title case.

df = pd.DataFrame({'name': ['  alice smith  ', 'BOB JONES', 'carol lee']})
Show answer 
df['name'] = df['name'].str.strip().str.title()
print(df)
#           name
# 0  Alice Smith
# 1    Bob Jones
# 2    Carol Lee
Q2

Filter the DataFrame to keep only rows where product starts with 'ap' (case-insensitive).

df = pd.DataFrame({'product': ['Apple', 'apricot', 'Banana', 'APRICOT']})
Show answer 
mask = df['product'].str.lower().str.startswith('ap')
print(df[mask])
#   product
# 0   Apple
# 1 apricot
# 3 APRICOT
Q3

Split full_name into two new columns first and last.

df = pd.DataFrame({'full_name': ['Alice Smith', 'Bob Jones', 'Carol Lee']})
Show answer 
df[['first', 'last']] = df['full_name'].str.split(' ', expand=True)
print(df)
#      full_name  first   last
# 0  Alice Smith  Alice  Smith
# 1    Bob Jones    Bob  Jones
# 2    Carol Lee  Carol    Lee
