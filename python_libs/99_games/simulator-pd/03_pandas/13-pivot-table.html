Pivot Table

pd.pivot_table() reshapes a DataFrame from long to wide, aggregating values along the way — like a spreadsheet pivot but in code.

pd.pivot_table index / columns aggfunc margins
Basic pivot_table

Reshaping with pd.pivot_table()

python
import pandas as pd

df = pd.DataFrame({
    'region':  ['North','North','South','South','East','East'],
    'product': ['A','B','A','B','A','B'],
    'sales':   [100,200,150,80,120,90],
    'units':   [10,8,12,5,9,7]
})

python
# rows = region, columns = product, cells = sum of sales
pd.pivot_table(
    df,
    values='sales',
    index='region',
    columns='product',
    aggfunc='sum'

pivot_table vs pivot: df.pivot() requires unique combinations of index/column and does no aggregation. pd.pivot_table() handles duplicates by aggregating — use it when rows may not be unique.
aggfunc & Values

Changing the Aggregation Function

python
# mean instead of sum
pd.pivot_table(df, values='sales', index='region',
               columns='product', aggfunc='mean')

python
# multiple values — each gets its own block of columns
pd.pivot_table(df, values=['sales','units'],
               index='region', columns='product', aggfunc='sum')
multi-value pivot

python
# different aggfunc per value column
pd.pivot_table(df, values=['sales','units'],
               index='region', columns='product',
               aggfunc={'sales': 'sum', 'units': 'mean'})
Margins & Fill

Row / Column Totals and Missing Values

python
# margins=True adds row and column totals
pd.pivot_table(
    df, values='sales', index='region',
    columns='product', aggfunc='sum',
    margins=True, margins_name='Total'
)

Exercises

Practice — Pivot Table

Q1

Create a pivot table showing the average score for each student (rows) and subject (columns).

df = pd.DataFrame({
    'student': ['Alice','Alice','Bob','Bob','Carol','Carol'],
    'subject': ['Math','English','Math','English','Math','English'],
    'score':   [90, 85, 70, 78, 88, 92]
})
Show answer 
pt = pd.pivot_table(df, values='score', index='student',
                   columns='subject', aggfunc='mean')
print(pt)
# subject  English  Math
# student
# Alice       85.0  90.0
# Bob         78.0  70.0
# Carol       92.0  88.0
Q2

Add row and column totals to the pivot table from Q1 using margins=True.

Show answer 
pt = pd.pivot_table(df, values='score', index='student',
                   columns='subject', aggfunc='mean',
                   margins=True, margins_name='All')
print(pt)
# subject  English  Math        All
# student
# Alice       85.0  90.0  87.500000
# Bob         78.0  70.0  74.000000
# Carol       92.0  88.0  90.000000
# All         85.0  82.67  83.833333
Q3

Create a pivot table of total sales by month (rows) and category (columns). Fill missing combinations with 0.

df = pd.DataFrame({
    'month':    ['Jan','Jan','Feb','Mar'],
    'category': ['A',  'B',  'A',  'B'  ],
    'sales':    [100, 200, 150, 80  ]
})
Show answer 
pt = pd.pivot_table(df, values='sales', index='month',
                   columns='category', aggfunc='sum', fill_value=0)
print(pt)
# category    A    B
# month
# Feb       150    0
# Jan       100  200
# Mar         0   80
