Shape 01 / 04 · Transpose
.T / np.transpose()
Flip the axes — rows become columns
array.T np.transpose(array) array arrayThe input array to transpose. Rows become columns and vice versa. For 1D arrays the result is unchanged; for N-D arrays all axes are reversed. returns view → transposed ndarray

Swaps rows and columns: a shape (2, 3) array becomes (3, 2). .T is the concise attribute form; both return a view (no data copied). On a 1D array, .T does nothing — use .reshape(-1,1) to make a column vector.

python
b = np.array([[1,2,3],[4,5,6]])
print(b.T)
# [[1 4]
#  [2 5]
#  [3 6]]
print(b.shape, b.T.shape)  # (2,3) (3,2)

Shape 02 / 04 · Flatten
.ravel()
Unroll any shape into a 1D array
array.ravel() order orderReading order for flattening. 'C' reads row-by-row (default), 'F' reads column-by-column (Fortran-order). Affects the element sequence in the output. returns view if possible → 1D ndarray

Flattens any multi-dimensional array into a single row, reading elements in row-major (C) order by default — left to right, top to bottom. Returns a view when the memory is contiguous; otherwise a copy. Compare with .flatten() which always copies.

python
b = np.array([[1,2],[3,4]])
print(b.ravel())   # [1 2 3 4]

c = np.arange(24).reshape(2,3,4)
print(c.ravel().shape)  # (24,)

Shape 03 / 04 · Reshape
.reshape()
New shape, same data — use -1 to auto-calculate
array.reshape(rows, cols) rows rowsNumber of rows in the new shape. The product of all shape dimensions must equal the total element count. Use -1 to have NumPy infer this dimension. cols colsNumber of columns in the new shape. The product of all shape dimensions must equal the total element count. Use -1 to have NumPy infer this dimension. -1 -1 (auto dim)Passing -1 for one dimension tells NumPy to calculate it automatically from the total element count. Only one dimension can be -1 at a time. returns view → ndarray (new shape)

Rearranges the data into a new shape without copying. The total number of elements must stay the same. Use -1 as a wildcard for one dimension to let NumPy compute it — e.g. reshape(3, -1) on 12 elements gives (3, 4).

python
g = np.arange(6)
print(g.reshape(2, 3))
# [[0 1 2]
#  [3 4 5]]

print(g.reshape(3, -1))  # -1 auto → (3,2)
# [[0 1]
#  [2 3]
#  [4 5]]

Shape 04 / 04 · Resize
.resize()
Reshape in-place — can grow or shrink
array.resize(new_shape) new_shape new_shapeA tuple specifying the desired new dimensions. If larger than the original, extra slots are filled with 0. If smaller, data is truncated. The array is resized in-place. in-place pads with 0s → None

Unlike .reshape(), .resize() modifies the array in-place and can change the total number of elements. If the new shape is larger, the array is padded with zeros. If smaller, it is truncated. Use np.resize(a, shape) to get a new array instead of modifying in-place.

python
h = np.arange(6)        # [0 1 2 3 4 5]
h.resize((2, 4))       # 6 elements → 8 slots (pad)
print(h)
# [[0 1 2 3]
#  [4 5 0 0]]  ← padded with zeros

Add/Remove 01 / 03
np.append()
Add elements to the end — returns a new array
np.append(arr, values) arr arrThe base array. It is flattened to 1D before appending unless axis is specified. The original array is never modified. values valuesThe values to add at the end. Also flattened to 1D unless axis is given. Can be a scalar, list, or array. returns NEW array → 1D ndarray

Returns a new flat array with the values appended at the end. The original is unchanged. Unlike Python list .append(), this is not O(1) — it allocates a brand new array every time, so avoid calling it in a loop for performance.

python
a = np.array([1, 2, 3])
print(np.append(a, [4, 5]))
# [1 2 3 4 5]
print(a)   # [1 2 3]  ← unchanged

# 2D → flattened automatically
print(np.append([[1,2],[3,4]], [5,6]))
# [1 2 3 4 5 6]

Add/Remove 02 / 03
np.insert()
Inject a value before a given index
np.insert(arr, obj, values) arr arrThe array to insert into. The original is not modified — a new array is always returned with the inserted values in place. values valuesThe value(s) to insert. Can be a scalar or array. For multiple positions, provide matching arrays for both obj and values. obj objThe index (or list of indices) before which to insert. Existing elements at and after that index are shifted right to make room. → new ndarray

Returns a new array with values inserted before the given index. The original is not modified. You can insert at multiple positions at once by passing lists for both obj and values.

python
a = np.array([1, 2, 3])
print(np.insert(a, 1, 5))
# [1 5 2 3]  ← 5 inserted before index 1

print(np.insert(a, [1,2], [5,6]))
# [1 5 2 6 3]  ← two insertions

Add/Remove 03 / 03
np.delete()
Remove elements at specified indices
np.delete(arr, obj) arr arrThe source array. The original is never modified — a new array with the specified elements removed is returned. obj objIndex or list of indices to remove. The remaining elements are packed together in the result. Supports negative indices too. → new ndarray

Returns a new array with the elements at the specified indices removed. The original is untouched. Pass a list to delete multiple elements at once. On 2D arrays, pass an axis to delete entire rows or columns.

python
a = np.array([1, 2, 3, 4, 5])
print(np.delete(a, 2))        # [1 2 4 5]
print(np.delete(a, [1, 3]))   # [1 3 5]
print(a)                          # [1 2 3 4 5] unchanged

Combine 01 / 04
np.concatenate()
Join arrays along an existing axis
np.concatenate((a, b), axis=0) (a, b, …) (a, b, …)A tuple or list of arrays to join. All arrays must have the same shape except along the concatenation axis. axis axisaxis=0 stacks rows (default, same as vstack). axis=1 joins along columns (same as hstack). Arrays must match in all other dimensions. → new ndarray

The general-purpose joining function. The arrays must have compatible shapes — all dimensions except the concatenation axis must match. For 1D arrays it simply chains them together.

python
a = np.array([1,2,3])
d = np.array([10,15,20])
print(np.concatenate((a, d), axis=0))
# [ 1  2  3 10 15 20]

x = np.array([[1,2],[3,4]])
y = np.array([[5,6]])
print(np.concatenate((x, y), axis=0))
# [[1 2],[3 4],[5 6]]

Combine 02 / 04
np.vstack()
Stack arrays vertically — row on top of row
np.vstack((a, b, …)) tup tupA sequence of arrays to stack vertically (row-wise). All arrays must have the same number of columns. 1D arrays are treated as a single row before stacking. row-wise (axis=0) → 2D ndarray

Stacks arrays on top of each other. A 1D array is treated as a single row. All arrays must have the same number of columns. Equivalent to np.concatenate((a, b), axis=0) and also to np.r_[a, b].

python
a = np.array([1, 2, 3])
b = np.array([[4, 5, 6],
              [7, 8, 9]])
print(np.vstack((a, b)))
# [[1 2 3]
#  [4 5 6]
#  [7 8 9]]

Combine 03 / 04
np.hstack()
Stack arrays side by side — column by column
np.hstack((a, b, …)) tup tupA sequence of arrays to stack horizontally (column-wise). For 2D inputs, all arrays must have the same number of rows. column-wise (axis=1) → ndarray

Places arrays next to each other horizontally. For 2D arrays this is equivalent to np.concatenate((a, b), axis=1). All arrays must have the same number of rows. Equivalent to np.c_[a, b] for 2D.

python
e = np.full((2,2), 7)
f = np.eye(2)
print(np.hstack((e, f)))
# [[7. 7. 1. 0.]
#  [7. 7. 0. 1.]]

Combine 04 / 04
np.column_stack()
1D arrays become columns in a 2D matrix
np.column_stack((a, b)) tup tupA tuple of 1D or 2D arrays to stack as columns. 1D arrays are automatically promoted to shape (n, 1) before stacking, making them proper columns. 1D → columns → 2D ndarray

Takes 1D arrays and stacks them as columns. Each input array becomes a column in the output. This is the natural way to build a feature matrix from individual feature vectors. Equivalent to np.hstack for 2D arrays.

python
a = np.array([1, 2, 3])
d = np.array([10, 15, 20])
print(np.column_stack((a, d)))
# [[ 1 10]
#  [ 2 15]
#  [ 3 20]]

Split 01 / 02
np.hsplit()
Cut a 1D array into equal horizontal pieces
np.hsplit(array, N) array arrayThe 2D array to split horizontally (column-wise). Its number of columns must be evenly divisible by N. N NNumber of equal sections to split into. If an integer, the array must be divisible by N. You can also pass a list of split points like [3, 5]. → list of ndarrays

Splits along the horizontal axis (axis=1 for 2D, axis=0 for 1D). Returns a list of sub-arrays. The array length must be evenly divisible by N (or use split points). The inverse operation of np.hstack().

python
a = np.array([1, 2, 3, 4, 5, 6])
parts = np.hsplit(a, 3)
# [array([1, 2]), array([3, 4]), array([5, 6])]

# split at specific positions
np.hsplit(a, [2, 4])
# [array([1,2]), array([3,4]), array([5,6])]
Live Demo — choose how many pieces
Split 02 / 02
np.vsplit()
Slice a 2D array into horizontal row groups
np.vsplit(array, N) array arrayThe 2D array to split vertically (row-wise). Its number of rows must be evenly divisible by N. N NNumber of equal row-groups to cut into, or a list of row indices at which to split. The number of rows must be divisible by N when passing an integer. → list of ndarrays

Splits a 2D array into row groups (along axis=0). Each part is a 2D sub-array. The inverse operation of np.vstack(). Use np.split(a, N, axis=0) for the same effect.

python
c = np.arange(12).reshape(4, 3)
parts = np.vsplit(c, 2)
print(parts[0])   # rows 0-1
# [[0 1 2]
#  [3 4 5]]
print(parts[1])   # rows 2-3
# [[ 6  7  8]
#  [ 9 10 11]]
