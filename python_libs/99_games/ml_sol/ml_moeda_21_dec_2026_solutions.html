Concept questions (multiple choice)

The correct option is marked in green. The explanation says why it is correct.

Concept Q1 Answer: C#

We have a dataset with columns: age, income, city, and loan_approved. A model is trained to predict whether a loan will be approved. What is the label here?

  • A. age
  • B. income
  • C. loan_approved ✓ correct answer
  • D. city

Why: The label is the column the model is trying to predict. Here that is loan_approved. The other three columns (age, income, city) are the inputs, called features.

Concept Q2 Answer: A#

A house price model uses square_meters, number_of_rooms, and location to estimate the price. Which of these is a feature?

  • A. square_meters ✓ correct answer
  • B. house_price
  • C. prediction
  • D. accuracy

Why: A feature is an input the model uses. square_meters is one of the inputs. house_price is the label (the thing predicted), prediction is the model's output, and accuracy is a score that measures the model.

Concept Q3 Answer: C#

In a supervised learning problem, the variable we try to predict is called the:

  • A. feature
  • B. row
  • C. target variable (label) ✓ correct answer
  • D. index

Why: In supervised learning every example comes with a known answer. That answer column is the target variable, also called the label. Features are the inputs, a row is one example, and the index is just a row number.

Concept Q4 Answer: B#

Which part of the dataset is used to teach the model?

  • A. test set
  • B. training set ✓ correct answer
  • C. mean value
  • D. column name

Why: The model learns its weights from the training set. The test set is kept aside and used only afterwards, to check how the model does on data it has never seen.

Concept Q5 Answer: C#

In supervised learning, each training example usually includes:

  • A. only random noise
  • B. only labels, without features
  • C. features and a corresponding label ✓ correct answer
  • D. only features and no target value

Why: To learn a mapping from inputs to outputs the model needs both: the features (inputs) and the label (the correct output) for the same example. Features without a label is unsupervised learning.

Concept Q6 Answer: B#

A single row in a dataset is often called an:

  • A. attribute list
  • B. observation ✓ correct answer
  • C. model weight
  • D. correlation

Why: One row is one observation (also called a sample, record or instance). A column is a feature or attribute, a weight is a number inside the model, and correlation describes the relation between two columns.

Concept Q7 Answer: B#

Which task predicts a continuous numeric value?

  • A. classification
  • B. regression ✓ correct answer
  • C. sorting
  • D. filtering

Why: Regression predicts a number on a continuous scale, for example a price or a temperature. Classification predicts a category. Sorting and filtering are data operations, not prediction tasks.

Concept Q8 Answer: A#

Which task predicts a category such as spam or not spam?

  • A. classification ✓ correct answer
  • B. regression
  • C. normalization
  • D. shuffling

Why: Predicting one of a fixed set of categories is classification. Regression predicts numbers. Normalization and shuffling are data preparation steps.

Concept Q9 Answer: B#

A model performs very well on training data but poorly on new data. This usually means the model is:

  • A. underfitting
  • B. overfitting ✓ correct answer
  • C. standardizing
  • D. encoding

Why: Overfitting means the model memorised the training data, including its noise, so it does not generalise to new data. An underfitting model is bad on both the training data and the new data.

Concept Q10 Answer: B#

What does underfitting usually mean?

  • A. The model is too complex and memorizes noise.
  • B. The model is too simple and cannot capture the pattern in the data. ✓ correct answer
  • C. The model has no training data.
  • D. The model is perfectly balanced.

Why: Underfitting means the model is too simple to capture the pattern, so the error is high even on the training data. Option A describes overfitting.

Concept Q11 Answer: C#

Why do we usually split data into training and test sets?

  • A. To train the model using the wrong prediction made in the test
  • B. To make the data smaller
  • C. To train the model and then evaluate it on unseen data ✓ correct answer
  • D. To convert strings into numbers

Why: The test set stands in for future, unseen data. Evaluating on it gives an honest estimate of how the model will behave in real use. If we scored the model on the same data it learned from, the score would be too optimistic. The test set is never used for training (so A is wrong).

Concept Q12 Answer: C#

What is the main purpose of scaling or normalization?

  • A. To change labels into categories
  • B. To remove missing values
  • C. To put features on a similar scale so the model can learn better ✓ correct answer
  • D. To create new rows in the dataset

Why: Features often have very different ranges (for example age 0 to 100 against income 0 to 100,000). Models that use distances or gradients are dominated by the large-range column. Scaling puts all features on a comparable scale.

Concept Q13 Answer: B#

Standardization usually transforms a feature so that it has:

  • A. minimum = 0 and maximum = 1
  • B. mean = 0 and standard deviation = 1 ✓ correct answer
  • C. only positive values
  • D. all values equal to each other

Why: Standardization computes \(z = \frac{x - \bar{x}}{Std}\), which gives a column with mean 0 and standard deviation 1. Option A describes min-max normalization.

Concept Q14 Answer: A#

Which type of data contains values such as red, blue, or small, medium, large?

  • A. Categorical data ✓ correct answer
  • B. Continuous numeric data
  • C. Label encoding
  • D. Missing data

Why: Values that are names of groups are categorical data. Colours are unordered categories and small / medium / large are ordered categories. Label encoding is a technique for turning categories into numbers, not a type of data.

Concept Q15 Answer: C#

What is one-hot encoding mainly used for?

  • A. To calculate the mean
  • B. To sort rows
  • C. To convert categorical values into numeric columns that a model can process ✓ correct answer
  • D. To remove outliers

Why: One-hot encoding replaces a categorical column with one 0/1 column per category, so a model that only understands numbers can use it without inventing an order between the categories.

Concept Q16 Answer: C#

What is the best description of a missing value in a dataset?

  • A. A very large number
  • B. A duplicate row
  • C. A value that is absent, empty, or unknown ✓ correct answer
  • D. A correct prediction

Why: A missing value is a cell with no known value (empty, NaN or null). It is not an outlier (A), not a duplicate (B) and has nothing to do with predictions (D).

Concept Q17 Answer: C#

What is a machine learning model?

  • A. A virtual machine which learns from its own data
  • B. An AI pattern recognition
  • C. A learned function that maps inputs to outputs ✓ correct answer
  • D. A spreadsheet used for storing raw values

Why: A model is the function that training produces: it takes the features as input and returns a prediction as output. It is not a machine, and not the data itself.

Concept Q18 Answer: B#

Accuracy tells us:

  • A. How fast the model trains
  • B. How often the model predicts correctly ✓ correct answer
  • C. How many features the model has
  • D. How much memory is used

Why: \(\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}\), the share of all predictions that were correct.

Concept Q19 Answer: C#

An outlier is a value that:

  • A. Always appears in the label column
  • B. Is the mean of all values
  • C. Is far away from the rest of the data and may distort the model ✓ correct answer
  • D. Is a type of training set

Why: An outlier is an unusually extreme value. It can pull the mean, stretch min-max scaling and drag a regression line towards itself.

Concept Q20 Answer: B#

What is data leakage?

  • A. Losing rows because a file failed to load correctly
  • B. Letting information from the test set influence training — for example, fitting a scaler on the whole dataset before splitting ✓ correct answer
  • C. Removing outliers before training
  • D. Reducing the number of features used by the model

Why: Leakage means the model gets, directly or indirectly, information from data it should not have seen. Fitting a scaler before the split lets the test rows influence the mean and standard deviation. The correct order is: split first, fit the scaler on the training set only, then apply it to the test set.

Concept Q21 Answer: B#

What does k-fold cross-validation do?

  • A. Doubles the size of the dataset
  • B. Splits the training data into k folds, trains on k−1 of them and tests on the one left out, rotating through all folds and averaging the scores ✓ correct answer
  • C. Splits the training data into k folds, trains on k% of them and tests on the 100%-k left out, rotating and averaging the scores
  • D. Selects the best k features to keep

Why: The data is cut into k equal folds. Each fold takes one turn as the test fold while the other k−1 folds train the model, and the k scores are averaged. Option C is wrong because k is a number of folds, not a percentage.

Concept Q22 Answer: B#

What is grid search used for?

  • A. Visualising data on a grid of scatter plots
  • B. Trying every combination of hyperparameters in a grid, scored by cross-validation, and keeping the combination with the best average score ✓ correct answer
  • C. Trying every combination of hyperparameters in a grid, scored by cross-validation, and keeping every score it computes
  • D. Normalising every feature onto a 0–1 grid

Why: Grid search tries every combination of the listed hyperparameter values, scores each one by cross-validation, and keeps the combination with the best average score. Option C is wrong because the purpose is to choose the best combination, not to keep every score.

Concept Q23 Answer: B#

In a linear model, what does a feature's weight represent?

  • A. The number of missing values in that column
  • B. The column's multiplier when computing the prediction ✓ correct answer
  • C. The name of the column
  • D. The number of rows in the dataset

Why: In \(\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots\) each weight \(\beta_i\) multiplies its feature. It says how much the prediction changes when that feature grows by one unit.

Concept Q24 Answer: B#

What is special about an L1 penalty (L1 regularisation)?

  • A. It only works with categorical features
  • B. It can push some weights to exactly zero, removing those features from the prediction entirely ✓ correct answer
  • C. Shrinks all the weights smaller, but never forces one to exactly zero
  • D. It replaces missing values with zero

Why: L1 (Lasso) adds the sum of the absolute values of the weights to the loss, and this can drive some weights to exactly zero, which acts as automatic feature selection. Option C describes L2.

Concept Q25 Answer: B#

What does an L2 penalty (L2 regularisation) do?

  • A. Removes features that have zero variance
  • B. Shrinks all the weights smaller, but never forces one to exactly zero ✓ correct answer
  • C. It can push some weights to exactly zero, removing those features from the prediction entirely
  • D. Converts categorical features into numeric ones

Why: L2 (Ridge) adds the sum of the squared weights to the loss. It shrinks all the weights towards zero but does not make any of them exactly zero. Option C describes L1.

Question 3 Comparing the two scalers#

Give one advantage and one disadvantage of Min-Max normalisation, and one advantage and one disadvantage of Standardisation.

Solution

Min-Max normalisation

Advantage: the result always sits in a known range \([0, 1]\), and the shape of the original distribution is kept. It is simple to read: 0 is the smallest value and 1 is the largest.

Disadvantage: it is very sensitive to outliers. One extreme value defines the min or the max, and then all the other values get squeezed into a small part of the \([0, 1]\) range.

Standardisation

Advantage: it is much less distorted by outliers than min-max, because the data is centred on the mean and measured in standard deviations. It suits models that expect centred data, such as logistic regression, SVM and PCA.

Disadvantage: the result has no fixed range (values can be below −3 or above 3), so it does not fit when a bounded range is needed. The mean and the standard deviation are themselves still pulled by very extreme outliers.

Watch out: One advantage and one disadvantage are needed for each scaler. Other correct points are accepted, for example min-max keeps the exact zero entries of sparse data, or standardisation does not give a bounded range.

Question 5 Adjusted R²#

A cubic model with three engineered features (\(x\), \(x^2\), \(x^3\)) is fitted on \(n = 10\) months and reaches \(R^2 = 0.94\). Compute the Adjusted R².

Solution

Here \(n = 10\), \(p = 3\) (three predictors), \(R^2 = 0.94\).

$$R^2_{adj} = 1 - \left[\frac{(1 - R^2)(n - 1)}{n - p - 1}\right] = 1 - \left[\frac{(1 - 0.94)(10 - 1)}{10 - 3 - 1}\right]$$ $$= 1 - \frac{0.06 \cdot 9}{6} = 1 - \frac{0.54}{6} = 1 - 0.09 = 0.91$$
Final answer: \(R^2_{adj} = 0.91\)
Watch out: \(p\) is the number of predictors (3), not the degree of the polynomial plus one, and not the number of rows. The denominator is \(n - p - 1 = 6\).

Question 6 Multiple choice: building the polynomial features#

A single feature \(X_1\) is expanded with PolynomialFeatures(degree=2). Which is the resulting set of columns?

  • A. \([\,X_1,\; X_1^2\,]\) — two columns, no bias term
  • B. \([\,1,\; X_1,\; X_1^2\,]\) — a bias column of ones (1), then \(X_1\), then \(X_1^2\) ✓ correct answer
  • C. \([\,X_1,\; X_2,\; X_1^2\,]\) — \(X_1\) paired with a second original feature
  • D. \([\,1,\; X_1,\; X_2,\; X_1^2,\; X_2^2\,]\) — five columns from two original features
Solution

With one input feature and degree=2, PolynomialFeatures builds all powers up to 2 and adds, by default (include_bias=True), a column of ones for the intercept \(\beta_0\):

$$[\,1,\; X_1,\; X_1^2\,]$$

A is missing the bias column. C and D use a second original feature \(X_2\), but the question has only \(X_1\).

Final answer: B

Question 7 What is Adjusted R²?#

What is Adjusted R², and why do we need it for a model like this one, instead of just using \(R^2\)?

Solution

Adjusted \(R^2\) is \(R^2\) with a penalty for the number of predictors \(p\) in the model.

Plain \(R^2\) can never go down when we add another feature, even a useless one, so a polynomial model with more and more terms always looks better and better. That rewards overfitting.

Adjusted \(R^2\) only goes up if the new feature improves the fit by more than chance would, and it goes down if the feature adds nothing. That makes it the fair way to compare models with a different number of features (for example degree 2 against degree 3).

Question 8 Sigmoid probability: 3 keywords#

\(\beta_0 = -3\), \(\beta_1 = 0.6\). What is the probability that an email with 3 suspicious keywords is spam?

Solution

First the exponent: \(\beta_0 + \beta_1 x = -3 + 0.6 \cdot 3 = -1.2\).

$$P = \frac{1}{1 + e^{-(-1.2)}} = \frac{1}{1 + e^{1.2}} = \frac{1}{1 + 3.320} \approx 0.231$$
Final answer: \(P \approx 0.231\), about 23.1% (below 50%, so not spam)
Watch out: The exponent is \(-(\beta_0 + \beta_1 x)\). Here \(\beta_0 + \beta_1 x\) is negative, so the exponent becomes positive (\(e^{+1.2}\)). A probability must be between 0 and 1.

Question 9 Sigmoid probability: 8 keywords#

Same model. What is the probability that an email with 8 suspicious keywords is spam?

Solution

\(\beta_0 + \beta_1 x = -3 + 0.6 \cdot 8 = -3 + 4.8 = 1.8\).

$$P = \frac{1}{1 + e^{-1.8}} = \frac{1}{1 + 0.165} \approx 0.858$$
Final answer: \(P \approx 0.858\), about 85.8% (above 50%, so spam)

★ Bonus Working backwards: the 80% point#

Find the number of suspicious keywords \(x\) at which the filter is exactly 80% sure the email is spam.

Solution

Use the formula for the \(x\) at any probability \(p\), with \(p = 0.8\):

$$\ln\!\left(\frac{p}{1-p}\right) = \ln\!\left(\frac{0.8}{0.2}\right) = \ln 4 \approx 1.386$$ $$x_{(0.8)} = \frac{\ln 4 - \beta_0}{\beta_1} = \frac{1.386 - (-3)}{0.6} = \frac{4.386}{0.6} \approx 7.31$$

Check: \(-3 + 0.6 \cdot 7.31 = 1.386\) and \(\frac{1}{1 + e^{-1.386}} = \frac{1}{1 + 0.25} = 0.8\). ✓

Final answer: \(x \approx 7.31\) keywords
Watch out: Do not forget to subtract \(\beta_0\), which is negative, so it becomes \(+3\) in the numerator.

Question 12 KNN: breaking a tie#

You run KNN with \(k = 4\) and the four nearest neighbours split exactly 2–2 between the two classes. What should you do to break the tie?

Solution

The tie happens because \(k\) is even. The standard fix is to change \(k\) to an odd number (for example \(k = 3\) or \(k = 5\)). With two classes and an odd \(k\), a tie can never happen.

Other acceptable ways: use distance-weighted voting (closer neighbours get a bigger vote), or give the class of the single nearest neighbour.

Question 13 SVM: which side, how far, support vector#

The boundary is \(6x_1 + 8x_2 - 48 = 0\). Applicants \(P = (10, 2)\) and \(Q = (3, 3)\). (a) Which side is each on? (b) How far is each from the boundary? (c) Which is more likely to be a support vector?

Solution

Here \(w = (6, 8)\) and \(b = -48\), so \(\lVert w \rVert = \sqrt{6^2 + 8^2} = \sqrt{100} = 10\).

(a) Put each point into \(w \cdot x + b\). The sign gives the side:

$$P: \; 6 \cdot 10 + 8 \cdot 2 - 48 = 60 + 16 - 48 = 28 \;(>0)$$ $$Q: \; 6 \cdot 3 + 8 \cdot 3 - 48 = 18 + 24 - 48 = -6 \;(<0)$$

P is on the positive side and Q is on the negative side. They are on opposite sides of the boundary.

(b) Divide by \(\lVert w \rVert\):

$$\text{Distance}(P) = \frac{|28|}{10} = 2.8 \qquad \text{Distance}(Q) = \frac{|-6|}{10} = 0.6$$

(c) Support vectors are the points closest to the boundary, because they are the ones that define the margin. Q (0.6) is much closer than P (2.8), so Q is the more likely support vector.

Final answer: (a) P positive side, Q negative side  |  (b) 2.8 and 0.6  |  (c) Q
Watch out: Distance is always positive (absolute value), the sign only tells the side. Do not forget to divide by \(\lVert w \rVert = 10\); \(28\) and \(-6\) alone are not distances.

Question 14 Classification tree: Gini, weighted Gini, gain#

14 tickets: 8 escalated and 6 not. The question “does the ticket contain the word ‘urgent’?” splits them into 6 rows (5 escalated, 1 not) and 8 rows (3 escalated, 5 not). (a) Gini of the parent. (b) Gini of each child. (c) Weighted Gini and the gain. (d) A rival question has a gain of 0.08. Which does the tree ask?

Solution

(a) Parent: 8 of 14 escalated, 6 of 14 not:

$$G(\text{parent}) = 1 - \left(\tfrac{8}{14}\right)^2 - \left(\tfrac{6}{14}\right)^2 = 1 - \frac{64 + 36}{196} = \frac{96}{196} \approx 0.490$$

(b) Children:

$$G(\text{yes}) = 1 - \left(\tfrac{5}{6}\right)^2 - \left(\tfrac{1}{6}\right)^2 = 1 - \frac{26}{36} = \frac{10}{36} \approx 0.278$$ $$G(\text{no}) = 1 - \left(\tfrac{3}{8}\right)^2 - \left(\tfrac{5}{8}\right)^2 = 1 - \frac{34}{64} = \frac{30}{64} \approx 0.469$$

(c) Weight each child by its share of the rows:

$$G_{\text{split}} = \frac{6}{14}\cdot 0.278 + \frac{8}{14}\cdot 0.469 \approx 0.119 + 0.268 = 0.387$$ $$\text{Gain} = 0.490 - 0.387 \approx 0.103$$

(d) The tree keeps the split with the larger gain. \(0.103 > 0.08\), so it asks the ‘urgent’ question.

Final answer: (a) 0.490  |  (b) 0.278 and 0.469  |  (c) 0.387, gain 0.103  |  (d) the ‘urgent’ question
Watch out: The children must be weighted by \(\frac{6}{14}\) and \(\frac{8}{14}\), not averaged simply as \(\frac{1}{2}\) and \(\frac{1}{2}\).

Question 15 Regression tree: MSE, weighted MSE, gain#

Six calls with \(y = 5, 7, 15, 17, 19, 21\). Issues \(x = 1, 2, 4, 5, 7, 8\). Premium: no, yes, no, yes, yes, yes. (a) \(\bar{y}\), SSE and MSE of the parent. (b) Split A: “issues \(\le 3\)?” (c) Split B: “premium member?” (d) Which split, and what do the leaves predict?

Solution

(a) Parent node.

$$\bar{y} = \frac{5 + 7 + 15 + 17 + 19 + 21}{6} = \frac{84}{6} = 14$$ $$SSE = (-9)^2 + (-7)^2 + 1^2 + 3^2 + 5^2 + 7^2 = 81 + 49 + 1 + 9 + 25 + 49 = 214 \qquad \text{MSE} = \frac{214}{6} \approx 35.67$$

(b) Split A: issues \(\le 3\)

childcalls\(y\)meanSSEMSE
issues \(\le 3\)1, 25, 76\(1 + 1 = 2\)1
issues \(> 3\)3, 4, 5, 615, 17, 19, 2118\(9 + 1 + 1 + 9 = 20\)5
$$\text{MSE}_{\text{split A}} = \frac{2}{6}\cdot 1 + \frac{4}{6}\cdot 5 = 3.667 \qquad \text{Gain}_A = 35.667 - 3.667 = 32$$

(c) Split B: premium member?

childcalls\(y\)meanSSEMSE
premium = no1, 35, 1510\(25 + 25 = 50\)25
premium = yes2, 4, 5, 67, 17, 19, 2116\(81 + 1 + 9 + 25 = 116\)29
$$\text{MSE}_{\text{split B}} = \frac{2}{6}\cdot 25 + \frac{4}{6}\cdot 29 = 27.667 \qquad \text{Gain}_B = 35.667 - 27.667 = 8$$

(d) Split A has the bigger gain (32 against 8), so the tree splits on “issues \(\le 3\)?”. Each leaf predicts the mean of its rows: 6 minutes for issues \(\le 3\) and 18 minutes for issues \(> 3\).

Final answer: Parent MSE \(\approx 35.67\)  |  Gain A = 32, Gain B = 8  |  split on issues \(\le 3\); leaves predict 6 and 18
Watch out: In a regression tree each leaf predicts the mean of the \(y\) values in it (not a class). The two children are weighted by their number of rows, as in the classification tree.

Question 16 PCA: variance, projection, explained variance#

Four drivers: \(x_1 = 5, 15, 15, 25\); \(x_2 = 10, 30, 50, 30\); \(x_3 = 5, 15, 15, 5\). (a) Variance of each column. (b) Total variance. (c) \(PC_1 = (0.6, 0.8, 0)\): project the four drivers, take the variance of the new values and find its share of the total.

Solution

(a) Variance of a column: \(s^2 = \frac{\sum (x - \bar{x})^2}{n}\), with \(n = 4\).
