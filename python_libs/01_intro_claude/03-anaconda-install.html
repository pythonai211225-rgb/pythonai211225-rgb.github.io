Anaconda & Setup

Anaconda is a free, open-source Python distribution that comes with Jupyter Notebook, NumPy, Pandas, Matplotlib, and hundreds of other Data Science packages — pre-installed and ready to go.

Anaconda Installation Jupyter Python Distribution
What is Anaconda?

Anaconda — The Data Science Platform

Anaconda is an open-source Python and R distribution designed specifically for scientific computing and Data Science. It solves a major problem: instead of manually installing Python, then pip, then NumPy, then Pandas, then Jupyter one by one, Anaconda installs everything at once.

📦

What's Included

Python, Jupyter Notebook, NumPy, Pandas, Matplotlib, Scikit-learn, SciPy, and 300+ more pre-installed packages ready to import.

🛡️

Environment Management

Anaconda handles package versions and compatibility automatically using conda — its own package manager that avoids version conflicts.

🚀

Anaconda Navigator

A graphical desktop app that lets you launch Jupyter Notebook, VS Code, Spyder and other tools with a single click — no terminal needed.

🆓

Free & Open Source

The Individual Edition is completely free. Used by over 35 million Data Scientists worldwide. Download from anaconda.com.

Installing Anaconda

Step-by-Step Installation

  1. Download Anaconda Go to anaconda.com/download and click the Download button. Choose the version for your OS (Windows / macOS / Linux). Select the latest Python 3.x version.
  2. Run the Installer Open the downloaded installer (.exe on Windows). Click through the setup wizard — accept the license agreement and keep the default installation path.
  3. Choose Installation Type Select "Just Me" (recommended) for a single-user install, or "All Users" if installing for everyone. Keep the default destination folder.
  4. Advanced Options You may optionally check "Add Anaconda to my PATH" but it's safer to use Anaconda Prompt instead. Click Install and wait for completion (~3–5 minutes).
  5. Open Anaconda Navigator After installation completes, launch Anaconda Navigator from the Start Menu (Windows) or Applications folder (macOS). You'll see a dashboard of tools.
  6. Launch Jupyter Notebook In Anaconda Navigator, find the Jupyter Notebook tile and click Launch. Your default browser will open at localhost:8888.
After Launch

What You'll See After Launching

After clicking Launch, two things happen:

💻

Terminal Window Opens

A black terminal/command prompt window appears showing the Jupyter server logs. Do not close this window — it keeps the server running.

🌐

Browser Opens at localhost:8888

Your browser opens the Jupyter Dashboard — a file explorer showing your home directory. Click any .ipynb file to open it, or click New → Python 3 to create a new notebook.

Creating a new notebook: Click New (top right) → Python 3 (ipykernel). A new browser tab opens with a blank notebook, ready for your first cell.
Verify Installation

Test That Everything Works

Once you have a new notebook open, type this in the first cell and press Ctrl + Enter:

Python 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

print("NumPy version:", np.__version__)
print("Pandas version:", pd.__version__)
print("✅ Everything is working!")
NumPy version: 1.26.4 Pandas version: 2.2.1 ✅ Everything is working!
If you see the version numbers printed without any errors — your installation is complete and you are ready to start doing Data Science with Python!
