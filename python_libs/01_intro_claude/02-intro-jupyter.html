What is Jupyter?

Jupyter Notebook — Overview

Jupyter Notebook is an open-source web application used for Data Science and scientific computing. It lets you create and share documents that contain live code, equations, visualizations, and narrative text.

Key idea: Instead of writing a .py file and running it, you write code in small blocks called cells and run each one independently — seeing the output immediately below.

Jupyter is the standard environment for Data Science work because it makes exploration, experimentation, and presentation all happen in one document.

Two Components

How Jupyter Works — 2 Parts

Every time you launch Jupyter, two things start running together:

🖥️

1 — The Jupyter Server

A local Python server that runs silently in the background. It executes your code when you press Run. You can see it running in the terminal or command prompt as a black window.

🌐

2 — The Jupyter UI

A web interface that opens automatically in your browser at localhost:8888. This is where you write, organize, and run your notebooks. It communicates with the server behind the scenes.

Remember: Jupyter runs locally on your computer — it is not a website on the internet. The browser is just used as the user interface. Your code runs on your machine.
The .ipynb File

Notebook Files

Jupyter notebooks are saved as .ipynb files (IPython Notebook). These files contain all your cells — code, outputs, and text — stored as JSON.

File Type Extension Contains Run with
Regular Python script .py Code only python script.py
Jupyter Notebook .ipynb Code + outputs + text Jupyter Notebook
