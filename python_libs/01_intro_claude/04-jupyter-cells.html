Topic 1 of 6

Edit Mode vs Command Mode

Every cell in Jupyter can be in one of two modes. The colored border on the left side of the cell tells you which mode you are in.

✏️

Edit Mode — Green Border

You are typing inside the cell. You can write and edit code. Enter edit mode by clicking inside a cell or pressing Enter.

🎮

Command Mode — Blue Border

You are navigating between cells. Keyboard shortcuts work here (like pressing B to add a cell below). Enter command mode by pressing Esc.

Tip: Press Esc to go from Edit → Command mode. Press Enter to go from Command → Edit mode.

How to Run a Cell

A cell is the basic building block of a Jupyter Notebook. Each cell holds a piece of code or text, and you run them one by one or all at once.

ShortcutActionWhen to use
Ctrl + EnterRun current cell, stay on itExperimenting — re-run the same cell multiple times
Shift + EnterRun current cell, move to nextWorking through a notebook top to bottom
Alt + EnterRun cell, insert new cell belowAdding new code after the current cell
▶ Run (toolbar)Run current cellWhen you prefer using the mouse
Most common: Ctrl + Enter — run the cell and stay on it. Great for experimenting and re-running the same cell.
Topic 3 of 6

Execution Order — The [ ] Counter

On the left side of each code cell you will see brackets like [ ], [1], [*]. These show the execution state.

⬜

[ ] — Not Run Yet

The cell has not been executed since the kernel started. No output will show until you run it.

⏳

[*] — Currently Running

The cell is executing right now. Useful for slow operations — you know it has not crashed, it is just working.

✅

[3] — Executed (3rd)

The number shows the order this cell was run. If you re-run a cell, its number updates to the latest count.

⚠️

Order Matters!

Variables created in one cell are available in later cells — but only if that cell has been run. Running cells out of order can cause errors.

Important: Cell execution order is determined by when you run the cell, not its position in the notebook. A cell at the bottom could have a lower number than a cell at the top if you ran them in that order.
Topic 4 of 6

Cell Position vs Execution Order

The position of a cell in the notebook does not determine when it runs. Only the order you click run matters.

Cell A — position 1, run 2nd 
# [2] — this was run second
x = 10
print(x)  # prints 10
10
Cell B — position 2, run 1st 
# [1] — this was run first
x = 5
print(x)  # prints 5
5
After running Cell B first (sets x=5), then Cell A (sets x=10) — x is now 10 globally. The cell order in the notebook does not matter, only execution order does.

Topic 6 of 6

Markdown — Text in Your Notebook

Jupyter cells can be either Code or Markdown. Markdown cells let you write formatted text — headers, bold, lists — to document and explain your code.

Markdown 
# Big Heading
## Smaller Heading

**Bold text**  and  *italic text*

- Bullet point 1
- Bullet point 2

1. Numbered list item
2. Another item

`inline code`  or  ```python code block```
📝

How to Create a Markdown Cell

In Command Mode, press M. Or use the dropdown in the toolbar that says "Code" — change it to "Markdown".

▶️

How to Render Markdown

Press Ctrl + Enter or Shift + Enter — same as running code. The raw text becomes formatted, rendered output.

Best practice: Always start a notebook with a Markdown cell that explains what the notebook is about. Include the date, your name, and the topic.
