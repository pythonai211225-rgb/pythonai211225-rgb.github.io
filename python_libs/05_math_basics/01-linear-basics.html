Linear Algebra Basics

Every straight line can be written as $$y = mx + b$$ — two numbers control everything: the slope m (how steep) and the intercept b (where it hits the y-axis). We plot lines with Matplotlib, find where two lines meet — the junction point — and then let SymPy solve it for us with Eq + solve.

Linear Basics 01 / 08 · The Equation
y = mx + b
Two numbers describe every straight line
y = m·x + b m m — slopeHow much y changes when x grows by 1. Positive → the line climbs, negative → it falls, zero → flat. b b — y-interceptThe value of y when x = 0. This is exactly where the line hits the y-axis: the point (0, b). one line per (m, b) → straight line
$$y = mx + b$$

Pick a value for x, multiply it by the slope m, add the intercept b — and you get y. Do this for every x and the points form a perfectly straight line. Example — the line from our lesson:

$$y = 0.8x - 2 \qquad\Longrightarrow\qquad m = 0.8,\;\; b = -2$$

Linear Basics 02 / 08 · Steepness
m — the slope
Rise over run: how fast the line climbs or falls
m = Δy / Δx m > 0 climbs · m < 0 falls → number

The slope measures how much y changes for every step in x. Take any two points on the line — the slope is the vertical change (rise) divided by the horizontal change (run):

$$m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\text{rise}}{\text{run}}$$

For y = 0.8x − 2: moving from x = 0 to x = 5 takes y from −2 up to 2, so m = (2 − (−2)) / (5 − 0) = 4 / 5 = 0.8. It does not matter which two points you pick — a straight line has the same slope everywhere.

Linear Basics 03 / 08 · Starting Height
b — the y-intercept
Where the line hits the y-axis
x = 0 → y = b the point (0, b) → crossing height

Set x = 0 in the equation and the slope term disappears — whatever is left is exactly the height where the line crosses (hits) the y-axis:

$$x = 0 \;\Longrightarrow\; y = m\cdot 0 + b = b \qquad\Longrightarrow\qquad \text{the line passes through } (0,\, b)$$

For y = 0.8x − 2 the intercept is b = −2, so the line hits the y-axis at the point (0, −2) — two units below the origin. Changing b slides the whole line up or down without rotating it; the slope stays the same.

💡 Reading a graph: to find b, look where the line crosses the vertical axis. To find m, walk 1 step right and count how far the line went up (or down).

Linear Basics 04 / 08 · Matplotlib
Plot a line
np.linspace → compute y → plt.plot
np.linspace(start, stop, n) · plt.plot(x, y) vectorized — no loop → line chart

To draw y = 0.8x − 2 we only need many x values and their matching y values. np.linspace builds the x array, and because NumPy is vectorized, 0.8 * x_values - 2 computes all the y values at once. axhline / axvline draw the two axes so we can see where the line hits them.

python
import numpy as np
import matplotlib.pyplot as plt

def linear_function(x):
    y = 0.8 * x - 2       # m = 0.8, b = -2
    return y

x_values = np.linspace(-15, 35, 20)   # 20 points from -15 to 35
y_values = linear_function(x_values)   # vectorized — all at once

plt.axhline(0, color='black', linewidth=0.8, linestyle='--')  # x-axis
plt.axvline(0, color='black', linewidth=0.8, linestyle='--')  # y-axis
plt.plot(x_values, y_values, color='green')
plt.title('y = 0.8x - 2')
plt.xlim(-10, 20)
plt.ylim(-20, 20)
plt.grid(color='gray', linestyle='--', linewidth=0.5)
plt.show()
Result — what plt.show() draws
  1. Build x valuesnp.linspace(-15, 35, 20) → 20 evenly-spaced numbers
  2. Compute y for every x0.8 * x_values - 2 — NumPy applies it element-wise
  3. Draw axes, line, gridaxhline / axvline for the axes, plot for the line, grid for readability
🔎 On the chart, check both stars of this lesson: the line crosses the y-axis at (0, −2) — that is b — and climbs 0.8 up for every 1 step right — that is m.
Linear Basics 05 / 08 · Two Equations
The junction point
Where two lines meet — one (x, y) that satisfies both
2 equations · 2 unknowns same y at the crossing → one point (x, y)

Two lines with different slopes always cross exactly once. The junction (intersection) point is the one (x, y) pair that sits on both lines. Our system from the lesson:

$$\begin{cases} x + y = 5 \\ 2x - y = 1 \end{cases} \;\Longrightarrow\; \begin{cases} y = -x + 5 \\ y = 2x - 1 \end{cases}$$

At the junction both lines have the same y, so we set them equal and solve for x by hand:

$$-x + 5 = 2x - 1 \;\Longrightarrow\; 6 = 3x \;\Longrightarrow\; x = 2,\quad y = -2 + 5 = 3 \;\Longrightarrow\; \boxed{(2,\,3)}$$

Now draw both lines, mark the junction we found with scatter, and label it with annotate — exactly like in class:

python
x_values = np.linspace(-15, 35, 20)
y_values1 = -1 * x_values + 5
y_values2 = 2 * x_values - 1

plt.axhline(0, color='black', linewidth=0.8, linestyle='--')
plt.axvline(0, color='black', linewidth=0.8, linestyle='--')
plt.plot(x_values, y_values1, color='green', label='y = -x + 5')
plt.plot(x_values, y_values2, color='red', label='y = 2x - 1')

plt.scatter(2, 3, color='blue', zorder=5)      # the junction we found by algebra
plt.annotate("(2, 3)", (2, 3), xytext=(1, 6), fontsize=10, color='blue')

plt.title('Junction')
plt.xlim(-10, 20)
plt.ylim(-20, 20)
plt.grid(color='gray', linestyle='--', linewidth=0.5)
plt.legend()
plt.show()
✍️ Here we solved the algebra by hand and hard-coded (2, 3). On the next page SymPy does the solving for us — no manual algebra.

Linear Basics 06 / 08 · Symbolic Math
sympy — Eq & solve
Python does the algebra for you
solve(Eq(left, right), x) symbols symbols('x')Creates a symbolic variable — a mathematical unknown, not a Python value. SymPy manipulates it algebraically. Eq Eq(left, right)Builds the equation left = right. In Python = assigns and == compares, so SymPy needs its own way to say "equals". solve solve(eq, x)Finds the value(s) of x that make the equation true. Returns a list — take solution[0] for the first answer. → list of solutions

sympy is a symbolic math library — it solves equations exactly, with algebra, the way you would on paper. Three building blocks: symbols declares the unknown, Eq writes the equation, solve finds the answer. Our mission — the same system from the previous page:

$$\begin{cases} y = -x + 5 \\ y = 2x - 1 \end{cases}$$

On the previous page we solved -x + 5 = 2x - 1 by hand and hard-coded (2, 3). Now let Eq + solve do that algebra for us, and feed the answer straight into scatter / annotate:

python
from sympy import symbols, Eq, solve

x = symbols('x')
eq1 = -x + 5                       # line 1: y = -x + 5
eq2 = 2 * x - 1                    # line 2: y = 2x - 1
solution = solve(Eq(eq1, eq2), x)  # set them equal → [2]

x_junc = float(solution[0])        # 2.0  — no hand algebra!
y_junc = -1 * x_junc + 5           # plug back into line 1 → 3.0

# same chart as before — but the point comes from sympy
plt.plot(x_values, y_values1, color='green', label='y = -x + 5')
plt.plot(x_values, y_values2, color='red', label='y = 2x - 1')
plt.scatter(x_junc, y_junc, color='blue', zorder=5)
plt.annotate(f"({x_junc}, {y_junc})", (x_junc, y_junc),
             xytext=(x_junc - 1, y_junc + 3), fontsize=10, color='blue')
plt.legend()
plt.show()
$$\texttt{solve} \;\Longrightarrow\; [\,2\,] \;\Longrightarrow\; x = 2,\quad y = -2 + 5 = 3 \;\Longrightarrow\; \boxed{(2,\,3)}$$
Result — the junction found by sympy
⚠️ Why Eq and not == ? In Python -x + 5 == 2*x - 1 is a comparison that answers True/False. Eq(-x + 5, 2*x - 1) builds a real equation object that solve can work on.
🧠 solve always returns a list (an equation can have several solutions). Grab the first one with solution[0] and convert with float() to use it in plots.
Linear Basics 07 / 08 · Edge Cases
Special cases
Parallel lines never meet + solving 3 unknowns
same m, different b → parallel no junction! solve → [ ] (empty)

Parallel lines have the same slope but different intercepts — they climb at the same rate, so the gap between them never closes and there is no junction point:

$$\begin{cases} y = 2x + 5 \\ y = 2x + 7 \end{cases} \;\Longrightarrow\; 2x + 5 = 2x + 7 \;\Longrightarrow\; 5 = 7\;\;❌\;\text{ no solution}$$
python
y_values1 = 2 * x_values + 5
y_values2 = 2 * x_values + 7   # same slope 2 → parallel

print(solve(Eq(2*x + 5, 2*x + 7), x))   # [] ← empty list, no solution
Graph — parallel lines from the equations

Bonus — 3 unknowns: the same idea scales up. Three equations with three unknowns usually meet at a single (x, y, z). Hand SymPy a tuple of equations and a tuple of unknowns:

python
from sympy import symbols, Eq, solve

x, y, z = symbols('x y z')     # three unknowns at once

eq1 = Eq(x + y + z, 6)
eq2 = Eq(2 * x - y + z, 3)
eq3 = Eq(x + 2 * y - z, 2)

solution = solve((eq1, eq2, eq3), (x, y, z))
print(f"The solution is: {solution}")
# The solution is: {x: 1, y: 2, z: 3}
🧭 Rule of thumb: different slopes → exactly 1 junction · same slope, different b → 0 (parallel) · same slope, same b → the same line, infinite common points.
