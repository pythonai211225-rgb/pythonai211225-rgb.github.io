Solution Steps - The Work Plan

A step-by-step plan for the Pandas exercise on the previous page: how to find the duplicate books, decide which row to keep, and remap every sale to the surviving book. These are hints - the pandas tools you need at each step, not the full code

Phase A · clean books Phase B · repair sales
Before you start

The id that links the two files

Each book is identified by book_id, and every row in books_sales.csv points at a book through that same book_id.
So when a duplicate book is removed, its book_id disappears - and any sale still pointing at it must be redirected to the book_id that was kept. A duplicate is detected by a repeated catalog_number

Phase A · Clean the books table

books.csv - remove the duplicates

  • Find the duplicate books. Find every book whose catalog_number appears more than once. Show all the duplicate rows (not just the extras), then sort by catalog_number so each duplicate pair sits together df.duplicated(subset='catalog_number', keep=False)
  • Count the filled fields in each row. For every row, count how many values are not empty (Not-NaN). Add a new helper column - e.g. non_nan_count - holding that count per row df.notna().sum(axis=1)
  • Keep the more complete row. For each duplicated catalog_number, keep the row with the highest non_nan_count (most filled fields). The other row - the one with more NaNs - is the one to remove sort_values + drop_duplicates(keep='first')
Phase B · Repair the sales table

books_sales.csv - redirect the sales

Goal: every book_id of a removed book must be replaced with the book_id of the book that was kept for the same catalog_number

  • Pair each removed book with its kept book. Do an inner join between the removed rows and the kept rows on catalog_number. Each pair gives you two ids for the same book - the old one and the new one pd.merge(removed, kept, on='catalog_number', how='inner')
  • Read off the old id and the new id. From the merged table, take book_id_removed (the old, deleted id) and book_id_kept (the surviving id) for every duplicate pair
  • Build a mapping from old id → new id. Turn those two columns into a dictionary: each removed book_id maps to the kept book_id dict(zip(book_id_removed, book_id_kept))
  • Apply the mapping to the sales table. Go over books_sales.csv and replace every old book_id using the mapping. Ids that are not in the mapping stay unchanged. Now every sale is attributed to a surviving book only sales['book_id'].replace(mapping)
