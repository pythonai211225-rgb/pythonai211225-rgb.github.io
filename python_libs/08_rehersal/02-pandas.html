Two CSV files describe a bookstore. The books.csv file lists books, but some appear twice. The books_sales.csv file records sales that point at books by their id. Your job: remove the duplicate books, then repair the sales file so every sale points at the correct remaining book

The Task

What you need to do

Some books appear in duplicate.
You can spot a duplicate because the same catalog_number shows up twice in books.csv

  • Remove duplicate books. For each duplicated catalog_number, delete the row that has more empty (NaN) fields. Keep the row that is more complete
  • Fix the sales file. In books_sales.csv, every sale that pointed at a deleted book_id must now point at the book_id that was kept
Worked example: Suppose the books table has a duplicate for the book with book_id = 3 and book_id = 5 (same catalog_number), and row 5 has more NaN columns:
  1. Delete the book with book_id = 5 from books.csv
  2. In books_sales.csv, replace every book_id = 5 with book_id = 3
